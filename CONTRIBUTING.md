# Contributing to Rin

Rin is an open-source project and welcomes contributions.

Before contributing:
1. Understand the existing architecture.
2. Read the language documentation.
3. Avoid breaking existing syntax.
4. Add tests for new behavior.
5. Update documentation for language changes.

Language changes should include specification, grammar/parser impact,
runtime behavior, tests, documentation, and examples where appropriate.

Pull requests should explain what changed, why it changed, compatibility
impact, and tests performed.

Do not copy third-party code without verifying license compatibility.
