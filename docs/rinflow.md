# RinFlow

RinFlow هو طبقة تنفيذ التدفّق المهيكل (structured execution flow) لتشغيل
[الأنابيب](./pipelines.md)، الأحداث، التقدّم (progress)، والتشخيص.

يبني RinFlow فوق نفس أساس [الشروط والحلقات](./control-flow.md) و
[الدوال](./functions.md)، لكنه يضيف طبقة أحداث/تقدّم حول تنفيذ سلسلة
[أنابيب](./pipelines.md) أو [حاويات](./containers.md) كاملة.
