# Autoload — التحميل الكسول للحاويات والمكتبات

بدل `@import` مسبق لكل شيء، تسجّل «محمِّلات» تُستدعى **فقط حين يُذكر اسم غير معرَّف** (متغيّر أو حاوية أو فضاء أسماء)، فيُحمَّل ملفه ثم يُكمَل التعبير كأن الاسم كان معرَّفاً أصلاً.
إضافة بحتة: بلا محمِّلات لا يتغيّر شيء ولا كلفة تُذكر (علم `autoloadActive_` يبقى `false`). المحرّك في `app/src/main/cpp/rin_autoload.cpp`.

```rin
Autoload.dir("src");            // أي اسم غائب X ← src/X.rin (أو src/X.rcl)
print Shop.total();              // يُحمَّل src/Shop.rin عند هذه اللحظة، ثم يُنفَّذ النداء
```

## الدوال
| الدالة | تفعل |
|---|---|
| `Autoload.dir(path, opts?)` | محمِّل مجلد. الاسم `a.b` ← `path/a/b.rin` ثم `path/a.b.rin` ثم `.rcl` بنفس الترتيب. `opts`: `ext:[".rin",".rcl"]` (الافتراضي الاثنان) · `prefix:"app_"` (شرط أن يبدأ الاسم به ويُجرَّد منه: `app_users` ← `users.rin`، والملف نفسه يعرّف `app_users`). يعيد عدد المحمِّلات |
| `Autoload.register(fn, prepend?)` | محمِّل دالة `fn(name)` يعرّف الاسم بأي طريقة (عادةً `Autoload.include`). `prepend=true` يضعه أولاً. يعيد عدد المحمِّلات |
| `Autoload.unregister(fn)` | يزيل محمِّلاً بعينه؛ `true`/`false` |
| `Autoload.include(path)` | ينفّذ ملف `.rin` أو `.rcl` **مرة واحدة** في النطاق العام؛ `true` إن نُفِّذ الآن، `false` إن غاب أو نُفِّذ سابقاً |
| `Autoload.load(name)` | يشغّل المحمِّلات الآن؛ `true` إن صار الاسم معرَّفاً (أو كان). أسماء فيها `..` أو `/` أو فارغة تُرفض بـ`false` |
| `Autoload.loaded()` · `Autoload.isLoaded(name)` | الأسماء التي حُمِّلت تلقائياً بالترتيب · هل حُمِّل اسم |
| `Autoload.loaders()` | عدد المحمِّلات |
| `Autoload.clear()` | يزيل كل المحمِّلات وسجلّ الملفات المنفَّذة؛ يعيد عدد ما أُزيل |

## متى يُعترَض؟
- قراءة متغيّر غائب: `print cfg["mode"]`.
- فضاء الأسماء: قراءة `Shop.items`، كتابة `Shop.items = 5`، نداء `Shop.total()` — أول مقطع من المسار هو الذي يُحمَّل.
- نداء مسار منقوط `Shop.total()` عبر `invokeCallee` حين لا يوجد native بهذا الاسم.
- يعمل بنفس السلوك في المفسّر الشجري وRinVM.
- **لا يُعترَض**: نداء دالة غائبة `foo()` (يبقى `E0006`)، ولا دوال `container.*` على اسم غائب.
- متغيّر أو صنف أو native موجود بنفس الاسم يغلب دائماً (لا يُسأل المحمِّل أصلاً).

## القواعد
- المحمِّلات بترتيب التسجيل **حتى يصير الاسم معرَّفاً**؛ لا يُشغَّل الباقي بعد النجاح.
- أخطاء المحمِّل تصعد كما هي (لا تُبتلع). خطأ داخل ملف محمَّل يصل `E0028` باسم الاسم والمسار والسطر.
- الاسم الجاري تحميله لا يُعاد تحميله من داخل نفسه (لا دوران لانهائي)، وأقصى عمق تحميل متداخل 16.
- ملف نُفِّذ مرة لا يُنفَّذ ثانية (لو لم يعرّف الاسم المطلوب يسقط الطلب إلى المحمِّل التالي).
- الأمان: أسماء محمِّل المجلد تُنقّى (حروف/أرقام/`_`/`-`/`.` فقط، بلا `..` ولا `/`)، والمسارات تمرّ بـ`resolvePath` المعزول، و`Autoload.include` يرفض `..`.
- حالة كل مفسّر مستقلة.
- الاختبار: `tests/print/autoload.rin`.

## مثال: مشروع بمجلدات
```
src/Shop.rin        @container=Shop ... .end/container
src/cfg.rin         let cfg = {mode: "dev"};
src/util/strings.rin
```
```rin
Autoload.dir("src");
print Shop.items;                  // يحمّل Shop.rin
print cfg["mode"];                 // يحمّل cfg.rin
Autoload.load("util.strings");     // src/util/strings.rin
Autoload.register(fun(name) {       // محمِّل مخصّص
    if (name == "Plugin") { Autoload.include("plugins/p1.rin"); }
});
```
