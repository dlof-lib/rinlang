# دوال الملفات وقواعد البيانات (rin_extra_natives12.cpp)

| الدالة | الوصف |
|---|---|
| `fileSync(path)` → `true` | `fsync`: يُلزم نظام التشغيل بكتابة الملف (أو المجلد) على القرص فعلاً. خطأ إن لم يوجد. |
| `fileRename(from, to)` → `true` | إعادة تسمية **ذرّية** (POSIX `rename(2)`)، تستبدل الوجهة إن وُجدت. |
| `fileSize(path)` → رقم | حجم الملف بالبايت (خطأ إن لم يوجد). |
| `fileLock(path)` → `bool` | قفل حصري استشاري غير حاجب (`flock`/`_locking`). ينشئ الملف إن لم يوجد. `true` = أخذناه (أو نحمله أصلاً)، `false` = عند عملية أخرى. |
| `fileUnlock(path)` → `bool` | يحرّر قفل هذه العملية؛ `false` إن لم تكن تحمله. |
| `fileIsLocked(path)` → `bool` | هل الملف مقفول (هنا أو عند عملية أخرى)؟ لا ينشئ الملف (غير موجود = `false`). |
| `findByRange(coll, field, lo, hi)` → مصفوفة | مستندات `field` فيها ضمن `[lo, hi]` شاملة، مرتّبة تصاعدياً، مع `_id`. `nil` = حدّ مفتوح. أرقام أو نصوص (تواريخ ISO) من نوع الحدّ. `coll` = doc/datalist/table (اسم أو Easy_key أو مسار). مسح O(n) مرتّب، وليس فهرساً. |

ملاحظات: القفل استشاري (لا يمنع برنامجاً لا يتعاون معه) ويُحرَّر تلقائياً بانتهاء العملية. على Windows تُستعمل `_commit`/`_locking` (لم تُختبر هناك). المسارات تمرّ بنفس `resolvePath` كبقية دوال الملفات.
`regex` موجود أصلاً كدوال (`regexTest/regexFind/regexFindAll/regexReplace/...`)؛ ولا يدخل في RCSQL لأن رموزه خارج الرموز الخمسة المسموحة، فاستعمله على نتائج `sql(...)`.
