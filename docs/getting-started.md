# البدء السريع (Getting Started)

قم بتثبيت/بناء بيئة تشغيل Rin، أنشئ ملف مصدر `.rin`، وشغّله عبر runtime الخاص بـ Rin.

## أول برنامج

```rin
let name = "Rin";
print "Hello, " + name + "!";

if (name == "Rin") {
    print "أهلاً بك في Rin!";
}
```

جرّب [`samples/showcase.rin`](../samples/showcase.rin) للاطّلاع على جولة سريعة تجمع
كل المفاهيم الموثّقة في [`language-reference.md`](./language-reference.md).
