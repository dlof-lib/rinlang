وثيقة rdoc الشاملة — Documentation Container#

المرجع الكامل للغة توثيق الحزم README.rdoc. للاطلاع السريع على الصيغ راجع rdoc.md، ولنموذج يعمل rdoc/README.rdoc.

1. المفهوم#

rdoc لهجة توثيق مستقلة عن Markdown تُعرَض داخل Rin عبر DocumentationContainer. تضيف لـMarkdown حاويات تخطيط، بلوكات بيانات، استدعاء روابط، دفع وتبرّع، فيديو، أقواس بأنواع، إعدادات صفحة، شريطاً متحركاً، وميزات خاصة بالحزم وتوثيق الدوال.

مبادئ ثابتة:

  • الفتح والإغلاق متناظران: كل رمز له بداية ونهاية.
  • الخطأ مرئي: أي قيمة أو بنية غير صالحة تظهر شريحة حمراء بدل أن تُبتلع.
  • آمن افتراضياً: https فقط للدفع والوسائط، وتأكيد قبل أي رابط دفع، وحدود صارمة (القسم 12).
  • متوافق للخلف: بدون الترويسة يبقى المستند Markdown خالصاً.

2. التفعيل#

يبدأ المستند بترويسة، وتُضاف تلقائياً لأي README.rdoc داخل الحزم:

؛؛؛ rdoc
title: اسم المكتبة
version: 1.0.0
؛؛؛

مفاتيح هذا البلوك (title وversion…) تصبح متغيّرات {{title}} و{{version}}. في حزمة تحتوي README.md وREADME.rdoc معاً يتقدّم README.rdoc.

6. العناصر السطرية#

استدعاء العنصر *"…"*#

يستدعي رابطاً معرَّفاً في مكان آخر: بـid=(…) داخل [* *]، أو في بلوك مراجع، أو مباشرة @user / @user/lib (روابط Rin القانونية).

الصيغة الناتج
*"repo"* رابط بتسمية العنصر
*"repo\|نص"* رابط بنص مخصص
*"repo\|نص\|button"* زر (button أو soft أو outline أو solid)

معرّف غير معروف يظهر «مرجع مفقود».

الدفع والتبرّع ؛: … :؛#

مزوّد|هدف[|مبلغ عملة][|نص][|type=(donate|pay|subscribe)] — الهدف اسم مستخدم أو رابط https. المزوّدون: paypal patreon kofi coffee github liberapay opencollective wise وurl (أي رابط https). مزوّدو نسخ العنوان btc eth usdt ltc sol xmr iban copy: بلا شبكة، والنقر ينسخ القيمة.

يعمل داخل [* … *] أيضاً: [*ادعمنا/؛:paypal|user|5 USD:؛*] أو [*تبرّع/donate=(patreon|user)*]. الزر يعرض المضيف الحقيقي، والنقر يفتح نافذة تأكيد.

الفيديو :; … ;:#

[video|web] https://…[|عنوان][|key=(قيمة)…]. على سطر مستقل: مشغّل بملصق تشغيل (لا شبكة قبل النقر)، وداخل فقرة: زر يفتح الرابط. JavaScript مسموح لمضيفي الفيديو الموثوقين فقط (YouTube وVimeo وDailymotion)، والتنقل الرئيسي محصور بمضيف التضمين.

يوتيوب الاحترافي (تفاصيل كل الخيارات في rdoc.md):

  • صيغ الروابط: watch · youtu.be · shorts · live · embed · playlist · music.youtube.com؛ وقت البدء من الرابط (?t=1m30s).
  • خيارات: start end autoplay mute loop captions lang related controls privacy thumb ratio height.
  • نسبة أبعاد حقيقية (16:9، وshorts بـ9:16)، وملصق بزر تشغيل أحمر، وصورة مصغّرة اختيارية (thumb=(true)).
  • ↗ فتح في يوتيوب، ✕ إغلاق، ملء الشاشة، وإيقاف المشغّل عند مغادرة الشاشة.
  • الخصوصية افتراضياً عبر youtube-nocookie.com، وتحميل عبر iframe بأصل https صحيح.
  • معرّف غير صالح، end قبل start، أو خيار يوتيوب على رابط آخر: خطأ مرئي ويلتقطه validate().

9. توثيق الحزم والدوال#

بطاقة الحزمة#

؛؛؛ حزمة
name: example-lib
version: 1.0.0
description: وصف قصير.
author: @example
license: MIT
requires: rin>=1.0
platforms: android, linux, web
keywords: media, embed
repo: https://github.com/dlof-lib/rinlang
؛؛؛

name وversion إلزاميان (version بصيغة 1.2.3 أو v2 أو 1.0.0-beta.1). repo وhomepage https فقط. إن غاب install يُستنتج rin install <name>. المفاتيح تصبح متغيّرات: {{name}} {{version}}.

التبعيات#

؛؛؛ تبعيات
@example/core = ^1.2 | النواة
json-utils = >=1.0
؛؛؛

القيود: * أو 1.2.3 أو مع ^ ~ >= <= > < =. أسماء @user/lib تصبح روابط.

توثيق دالة#

::: دالة example_open(url, title)
تفتح رابط وسائط وتعيد صفحة HTML.

@param url (نص): رابط الوسائط
@param title: عنوان الصفحة
@return: نص HTML
@throws: unsupported
@since: 1.0
@example
```kotlin
warp page = example_open(link, "عرض");
```
:::

التوجيهات: @param (اسم (نوع): وصف) · @return/@returns · @throws · @since · @deprecated · @see معرّف · @example (ولها أسماء عربية: معامل، يعيد، يرمي، منذ، متوقف، انظر، مثال). يقارن الفحص @param بمعاملات التوقيع. ::: فهرس-الدوال يجمع كل التواقيع، و::: تثبيت يعرض أوامر قابلة للنسخ.

10. الفحص validate()#

يعيد List<RdocIssue> بحقول line وseverity (error/warning) وmessage، ويغطي:

  • أسوار: ::: أو ؛؛؛ غير مغلقة أو زائدة، أنواع مجهولة، عمق يتجاوز 4، حجم المستند.
  • مراجع *"…"* مفقودة، ومعرّفات id مكرّرة.
  • دفع ووسائط غير صالحة أو غير https، وأقواس بقيم غير صالحة أو خيارات ستايل خاطئة.
  • إعدادات الصفحة (قيمة خاطئة، مفتاح مجهول أو مكرّر) وخيارات الشريط.
  • الحزمة والتبعيات وتوثيق الدوال (القسم 9).
