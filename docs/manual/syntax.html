الفواصل#

كل عبارة (statement) تنتهي بفاصلة منقوطة ;. الكتل { ... } لا تحتاج فاصلة بعد }.

الحرفيات (Literals)#

النوع مثال
رقم 5, 3.14
نص "hello"
نص قالبي `hello ${name}`
منطقي true, false
عدمي nil
مصفوفة [1, 2, 3]
قاموس (map) {"x": 1, "y": 2}

النصوص القالبية — متغيّرات داخل النص#

بدل دمج النصوص بـ +، اكتب النص بين علامتَي backtick (`) وضع أي متغيّر أو تعبير داخل ${ ... }:

let name = "Rin";
let age = 3;
print `hello ${name}`;            // hello Rin
print `بعد سنة: ${age + 1}`;       // بعد سنة: 4

الطريقة القديمة بـ + ما زالت تعمل كما هي:

print "hello " + name; // hello Rin

التفاصيل الكاملة والأمثلة في template-strings.md.

المعرِّفات والكلمات السياقية#

المعرّف العادي (اسم متغيّر/دالة) يبدأ بحرف أو _. كلمات مثل class/struct/enum/ export/state/route/row/document/warp/container/plus.condition هي كلمات سياقية غير محجوزة عالميًا — المحلِّل يتعرّف عليها فقط عندما تظهر في بداية عبارة وتتبعها البنية المتوقَّعة (مثلًا معرِّف مباشرة بعد class)، وإلا فهي اسم متغيّر عادي بلا أي تعارض:

let class = 5;      // صالح تمامًا: "class" هنا مجرد اسم متغيّر
print class + 1;    // 6

العوامل (Operators)#

الفئة العوامل
حسابية + - * / %
مقارنة == != > < >= <=
منطقية and, or, ! (ليست &&/\|\| — هذه غير مدعومة إطلاقًا)
إسناد =
فهرسة arr[i], map["key"]
وصول حقل obj.field 
print true and false;  // false
print true or false;   // true
print !true;           // false
print 10 % 3;           // 1

الكتل والنطاق#

أي { ... } يفتح نطاقًا (Environment) جديدًا. المتغيّرات المعرَّفة بـ let بداخله لا تُرى خارجه.

البنية العامة @name.<kind>=<name> ... .end/name#

كل بيانات الواجهة/الحاويات في اللغة (@view, @element, @loop, @container، @Object، ...) تتبع نفس الشكل العام: كلمة تبدأ بـ @، نوع فرعي اختياري بعد .، اسم بعد =، جسم، ثم .end/<الاسم نفسه> (أو .end/<الاسم>.<النوع> لبعض الأنواع المتخصِّصة). التفاصيل الكاملة لكل بيان في الصفحات المخصَّصة له (انظر "انظر أيضًا" أدناه).

كل كتلة @… يمكن أيضًا أن تُفتح بـ { على سطر الترويسة وتُغلق بـ } (أو }=name) بدل .end/… — التفاصيل وقواعد منع التعارض في block-frames.md.

print وshow#

show مرادف كامل لـ print بلا أي فرق في السلوك (جزء من عائلة الكلمات الإنجليزية المبسَّطة make/show/create/run):

print "a";
show "a"; // نفس الأثر تمامًا
