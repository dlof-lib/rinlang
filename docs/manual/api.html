api.md — واجهة C المسطَّحة (Embedding API)#

طبقة C خالصة (extern "C") لتضمين محرّك Rin في أي تطبيق مضيف (أندرويد عبر JNI — انظر android.md — أو أي تطبيق C/C++ آخر مباشرة). كل نتيجة نصيّة مُخصَّصة بـmalloc، تُحرَّر دائمًا عبر rin_free_string().

rin_c_api.h — تنفيذ عام (بلا واجهة)#

char* rin_run(const char* source, const char* basePath);
void  rin_free_string(char* s);
const char* rin_engine_version(void);

RinSession* rin_session_create(const char* basePath);
char*       rin_session_run(RinSession* session, const char* source);
void        rin_session_free(RinSession* session);

rin_run تشغيل لمرة واحدة يُرجع كل مخرجات print/show كنص واحد (basePath يُستخدَم لحلّ مسارات @import النسبية، انظر cross-file-containers.md). rin_session_* نسخة تحتفظ بحالة المفسِّر بين استدعاءات متعددة على نفس الجلسة (مفيد لـREPL تفاعلي).

شكل نتيجة rin_indsin_render_json/rin_indsin_session_render_json#

شجرة Fabric كاملة (kind/name/line/الهندسة/كل السمات المحلولة، بشكل تكراري) — أو {"error": "...", "line": N} إن فشل التحليل أو لم يوجد جذر @view/@element/@loop (انظر قسم "دمج @element بـindsin" في ../indsin.md). نسخة الجلسة تضيف أيضًا خطة الرسم الفعلية (paint، نفس مصفوفة DrawCommand من محرّك Dye — انظر rinflow.md لمفهوم مشابه في سياق مختلف).

شكل نتيجة rin_indsin_session_tap/...long_press/...double_tap/...hover#

{"ok": true, "handled": true, "targetId": 7, "changed": ["counter"], "fabric": { ... }}

handled يعني وُجد onTap= على العنصر المستهدَف فعلًا؛ changed أسماء كل Warp cell تغيّرت نتيجة تشغيله؛ error يظهر فقط إن وُجد المعالج لكنه فشل وقت التشغيل (وسائط خاطئة مثلًا).
