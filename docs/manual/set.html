set.md — Set: نوع المجموعة الأساسي#

Set نوع أصلي في المفسّر (بجانب array وmap): عناصر فريدة، بترتيب الإدراج، وبدلالة مرجعية (نسخ المتغير يشير لنفس المجموعة). التساوي تركيبي بلا اعتبار للترتيب. (مكتبة boat القديمة set() تبقى كما هي.)

الإنشاء#

let a = Set([1, 2, 2, 3]);   // Set{1, 2, 3}
Set();                       // فارغة
Set(1, 2, 3);                // كل وسيط عنصر
Set.of([1, 2]);              // Set{[1, 2]} — كل وسيط عنصر دائماً
Set.from("abc");             // Set{"a","b","c"} — مصفوفة/مجموعة/قاموس(مفاتيحه)/نص(أحرفه)

وسيط مفرد مصفوفة أو مجموعة أو قاموس يُفكَّك؛ النص المفرد عنصر واحد (استعمل Set.from لتفكيكه).

المعاملات#

المعنى
a + b اتحاد
a <= b / a < b جزئية / جزئية فعلية
== != تساوٍ بلا ترتيب

الطرفان يجب أن يكونا مجموعتين وإلا E0004. لا فهرسة: s[0] خطأ E0004 (استعمل s.has(x) أو s.toArray()[i]).

الطرق (s.add(x) ≡ Set.add(s, x))#

  • حجم/عضوية: size len length isEmpty has contains hasAll hasAny
  • تعديل في المكان: add(→ هل أُضيف؟) addAll(→ عدد الجديد) remove(→ هل وُجد؟) removeAll retain clear pop(أقدم عنصر)
  • جبر (يُرجع مجموعة جديدة): union intersect diff symDiff (تقبل عدة وسائط وأي قابل للتكرار)
  • علاقات: isSubset isSuperset isDisjoint equals
  • تحويل: toArray sorted join copy first last min max sum
  • دوال عليا: map filter each some every reduce

الصيغة الثابتة تقبل أي قابل للتكرار أولاً للعمليات غير المعدِّلة (Set.union([1],[2])).

تكامل مع بقية اللغة#

for (let x in s) (على لقطة) · let s: Set = ... · type(s) = "set" · len contains has remove empty join sum mean median variance stddev mode minOf maxOf product count · jsonEncode(s) ← مصفوفة · schema نوع "set".

ملاحظات#

  • البحث/الإضافة O(1) تقريباً للأرقام والنصوص والمنطقية؛ العناصر المركّبة (مصفوفة/قاموس...) تُقارَن بمسح خطّي، وتعديلها بعد الإدراج لا يُعاد فهرسته.
  • NaN لا يساوي نفسه فلا يُدمج. 0 و-0 عنصر واحد. 1 و"1" مختلفان.
  • تغيير سلوك: Set صار اسماً محجوزاً كدالة أصلية، فتعريف class Set يعطي الآن E0002 (لم يكن موجوداً في أي ملف بالمشروع).
  • التنفيذ: app/src/main/cpp/rin_set.cpp (يُضمَّن في rin_interpreter.cpp فلا تغيير في ملفات البناء).
