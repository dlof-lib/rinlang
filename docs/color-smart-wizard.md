# مربع اللون · الكتابة الذكية · معالج المشروع الجديد

## 1) مربع اللون في المحرر
- يكشف `ColorLiterals` الصيغ: `#rgb #rgba #rrggbb #rrggbbaa` (الشفافية في الآخر)، `rgb()/rgba()` (وصيغة `rgb(255 0 0 / 50%)`)، `hsl()/hsla()`، وأسماء CSS **داخل علامات اقتباس فقط** (`"tomato"`).
- الأوضاع (قائمة التحرير ← الكتابة الذكية ← معاينة الألوان): **مربع لون** (افتراضي) يُرسم بعد الكود إن وُجد فراغ، وإلا في نهاية السطر فلا يغطّي كوداً أبداً — مع شبكة شطرنج للألوان الشفافة · **تظليل الكود** بلونه مع نص متباين · إيقاف.
- الضغط على المربع يفتح منتقي ألوان (عجلة + سطوع + شفافية + hex) ويستبدل الكود محافظاً على صيغته وحالة أحرفه.
- في شريط التحديد: «تعديل اللون…» و«تبديل صيغة اللون» (hex → rgb → hsl).

## 2) الكتابة الذكية (`SmartEdit` + `SmartEditMenu`)
حالة الأحرف (UPPER/lower/Title/snake/kebab/camel/Pascal/CONSTANT) · زيادة/إنقاص الرقم · عكس true↔false وأمثالها ·
إحاطة التحديد بـ `() [] {} "" '' ` وفكّها (وكتابة قوس فوق تحديد تُحيطه تلقائياً — قابل للإيقاف) ·
توسيع التحديد تدريجياً (كلمة ← نص ← أقواس ← سطر ← الكل) · سطر جديد فوق/تحت بنفس الإزاحة ·
عكس الأسطر / إزالة المكرر / ترتيب رقمي. كل أمر استبدال واحد قابل للتراجع.

## 3) معالج «مشروع جديد» (`NewProjectActivity`)
القالب ← التفاصيل (اسم بتحقق لحظي، وصف، مطوّر، إصدار، خيارات القالب) ← المكتبات (بحث + توصيات؛ تُستورد أعلى `main.rin`) ← المراجعة (بنية المجلدات + شجرة حيّة).
البنية الناتجة: `main.rin` · `rin.project.json` · `README.md` · `.gitignore` · `src/utils.rin` · `tests/test_main.rin` (`rin test tests`) · `docs/` · `assets/`.
مشاريع الويب تتخطّى خطوة المكتبات.

## الاختبار
`tools/kotlin-tests/`: اختبارات للوحدات الخالصة (ColorTest / EditTest / BpTest) تُشغَّل بمترجم Kotlin 2.0.21؛ والمشاريع المولَّدة جُرّبت بـ `rin main.rin` و`rin test tests` فنجحت.
