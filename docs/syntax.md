# syntax.md — القواعد النحوية العامة

> كل مثال في هذا الملف جُرِّب فعليًا عبر مفسِّر Rin الحقيقي (`rin_lexer.cpp` +
> `rin_parser.cpp` + `rin_interpreter.cpp`) قبل كتابته هنا.

## التعليقات
```rin
// تعليق سطر واحد

/* تعليق
   متعدد الأسطر */
```

## الفواصل
كل عبارة (statement) تنتهي بفاصلة منقوطة `;`. الكتل `{ ... }` لا تحتاج فاصلة بعد `}`.

## الحرفيات (Literals)
| النوع | مثال |
|---|---|
| رقم | `5`, `3.14` |
| نص | `"hello"` |
| منطقي | `true`, `false` |
| عدمي | `nil` |
| مصفوفة | `[1, 2, 3]` |
| قاموس (map) | `{"x": 1, "y": 2}` |

لا يوجد **string interpolation** في اللغة — الدمج يتم عبر عامل `+` فقط:
```rin
let name = "Rin";
print "hello " + name; // hello Rin
```

## المعرِّفات والكلمات السياقية
المعرّف العادي (اسم متغيّر/دالة) يبدأ بحرف أو `_`. كلمات مثل `class`/`struct`/`enum`/
`export`/`state`/`route`/`row`/`document`/`warp`/`container`/`plus.condition` هي
**كلمات سياقية غير محجوزة عالميًا** — المحلِّل يتعرّف عليها فقط عندما تظهر في بداية
عبارة وتتبعها البنية المتوقَّعة (مثلًا معرِّف مباشرة بعد `class`)، وإلا فهي اسم متغيّر
عادي بلا أي تعارض:
```rin
let class = 5;      // صالح تمامًا: "class" هنا مجرد اسم متغيّر
print class + 1;    // 6
```

## العوامل (Operators)
| الفئة | العوامل |
|---|---|
| حسابية | `+ - * / %` |
| مقارنة | `== != > < >= <=` |
| منطقية | `and`, `or`, `!` (**ليست** `&&`/`\|\|` — هذه غير مدعومة إطلاقًا) |
| إسناد | `=` |
| فهرسة | `arr[i]`, `map["key"]` |
| وصول حقل | `obj.field` |

```rin
print true and false;  // false
print true or false;   // true
print !true;           // false
print 10 % 3;           // 1
```

## الكتل والنطاق
أي `{ ... }` يفتح نطاقًا (Environment) جديدًا. المتغيّرات المعرَّفة بـ `let` بداخله
لا تُرى خارجه.

## البنية العامة `@name.<kind>=<name> ... .end/name`
كل بيانات الواجهة/الحاويات في اللغة (`@view`, `@element`, `@loop`, `@container`،
`@Object`، ...) تتبع نفس الشكل العام: كلمة تبدأ بـ `@`، نوع فرعي اختياري بعد `.`،
اسم بعد `=`، جسم، ثم `.end/<الاسم نفسه>` (أو `.end/<الاسم>.<النوع>` لبعض الأنواع
المتخصِّصة). التفاصيل الكاملة لكل بيان في الصفحات المخصَّصة له (انظر "انظر أيضًا" أدناه).

## `print` و`show`
`show` مرادف كامل لـ `print` بلا أي فرق في السلوك (جزء من عائلة الكلمات الإنجليزية
المبسَّطة `make`/`show`/`create`/`run`):
```rin
print "a";
show "a"; // نفس الأثر تمامًا
```
