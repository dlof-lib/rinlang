# slab — هوية الوحدة ونقطة الدخول

`slab.*` مجموعة دوال مضمَّنة تعرّف الوحدة (الملف) الجارية، وأهمها **`slab.main()`**: هل هذا الملف
هو البرنامج الرئيسي أم مستورَد؟ وهي مبنية فوق [`RINTWIST`](./rintwist.md) بواجهة أقصر.

| الدالة | النتيجة |
|---|---|
| `slab.main()` | `true` إن كان الملف الجاري هو الرئيسي، `false` إن كان مستورَداً |
| `slab.main(fn, args...)` | يستدعي `fn(args...)` **فقط** عند كونه الرئيسي ويُرجع نتيجتها، وإلا `null` |
| `slab.name()` | اسم الملف الجاري بلا امتداد |
| `slab.path()` / `slab.dir()` | مسار الملف الجاري / مجلده |
| `slab.entry()` | مسار الملف الرئيسي (نقطة الدخول) |
| `slab.depth()` | عمق الاستيراد (`0` = الرئيسي) |
| `slab.stack()` | سلسلة الاستيراد من الرئيسي إلى الجاري |
| `slab.isImported()` | نفي `slab.main()` بصياغة أوضح |
| `slab.args()` | وسائط البرنامج (`RINTWIST.run.args`) |
| `slab.imports()` | مسارات الوحدات المستورَدة حتى الآن (مرتبة، بلا تكرار) |

## الاستعمال: ملف مكتبة وبرنامج في آن
```kotlin
// tool.rin
export fun area(w, h) { return w * h; }

if (slab.main()) {                 // يعمل فقط عند تشغيل الملف مباشرة: rin tool.rin
    print "self-test:", area(3, 4);
}
```
عند `import { area } from "./tool.rin";` من ملف آخر لا يُنفَّذ الاختبار الذاتي.

بصيغة الدالة: `slab.main(start, args...)` — تشغّل `start` فقط في الملف الرئيسي.

## دلالة الحارس: بحسب أصل الكود
`slab.main()` تحكم بحسب **الملف الذي كُتب فيه الكود** لا بحسب من يستدعيه: كل دالة (ومتغيّرة اللامبدا
والدالة المتداخلة وmethods الأصناف) تلتقط «أصلها» لحظة تعريفها، وتُجيب `slab.main()` بأصل الدالة الجارية.

| الكود | الجواب |
|---|---|
| مستوى الملف الرئيسي / دالة مكتوبة فيه | `true` |
| مستوى ملف مستورَد (وقت التحميل) | `false` |
| دالة مكتبة تستدعيها الرئيسية لاحقاً (أيضاً المتداخلة وmethods) | `false` |
| دالة كُتبت في الرئيسي وتُمرَّر إلى مكتبة فتستدعيها | `true` |

```kotlin
// lib.rin
export fun amMain() { return slab.main(); }
// main.rin
import { amMain } from "./lib.rin";
print amMain();        // false — الدالة كُتبت في مكتبة
print slab.main();     // true
```
- `slab.main(fn)` يقبل دالة Rin أو اسم دالة مضمَّنة (نص)، ويرفض غير ذلك بخطأ `E0004`.
- `slab.name/path/dir/depth/stack` تصف **مرحلة التنفيذ** الجارية (لا أصل الدالة)؛ التقطها عند التحميل
  إن احتجتها من داخل دوالك: `export let ME = slab.name();`.

## حالات الخطأ
| الحالة | الخطأ |
|---|---|
| `slab.main(42)` (وسيط أول ليس دالة) | `E0004` |
| وسائط زائدة لدوال الهوية (`slab.name(1)`) | خطأ عدد الوسائط |

## توحيد مفاتيح الاستيراد
المسارات النسبية الصريحة (`./` و`../`) تُوحَّد نسبةً لمجلد المستورِد قبل منع التكرار وكشف الدورات،
فاستيراد الملف نفسه بكتابتين مختلفتين (`./b.rin` من ملف مجاور و`./sub/b.rin` من الرئيسي) يُعدّ ملفاً واحداً.
