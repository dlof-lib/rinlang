# env.md — ربط Rin بملف `.env`

```rin
Env.load();                         // يقرأ ".env" (اختياري: غيابه لا يرمي خطأ)
let key  = Env.require("API_KEY");  // يرمي خطأ واضحاً إن لم يوجد
let port = Env.int("PORT", 8080);   // تحويل مكتوب مع قيمة افتراضية
```

## الدوال
| الدالة | المعنى |
|---|---|
| `Env.load(path?, override?)` | يقرأ الملف ويضبط متغيّرات العملية، ويُرجع قاموس ما طُبّق. `path` نص أو **مصفوفة** مسارات (اللاحق يغلب، مثل `[".env", ".env.local"]`). مسار صريح غير موجود ← `E0036`. متغيّر النظام الموجود يغلب الملف ما لم `override=true` |
| `Env.parse(text)` | يحلّل نص `.env` إلى قاموس بلا أي أثر جانبي |
| `Env.get(key, default?)` | نص أو `default` (افتراضياً `nil`) |
| `Env.require(key)` | كـ `get` لكن يرمي `E0007` إن لم يوجد |
| `Env.has(key)` · `Env.set(k, v)` · `Env.unset(k)` | وجود / ضبط / حذف (على العملية فقط، لا يكتب الملف) |
| `Env.all()` · `Env.loaded()` | كل بيئة العملية (قاموس) / أسماء المفاتيح التي حمّلها `Env.load` |
| `Env.int / float / bool / list (key, default?)` | تحويل؛ قيمة غير صالحة ← `E0005`. `bool` يقبل true/false/1/0/yes/no/on/off. `list(key, sep=",", default?)` يقصّ ويتجاهل الفارغ |

## الصيغة
`KEY=VALUE` · `export KEY=VALUE` · أسطر `# تعليق` · `"..."` (هروب `\n \t \" \\ \$` وتدعم أسطراً متعددة) · `'...'` حرفي · غير مقتبس يُقصّ ويُحذف تعليق ` #` في آخره.
توسعة `$VAR` و`${VAR}` و`${VAR:-افتراضي}` من مفاتيح سابقة في الملف ثم بيئة العملية. التعريف المكرر: الأخير يغلب. الأسطر غير الصالحة تُتجاهل.

## ملاحظات
- لا تضع `.env` في Git (أضِفه إلى `.gitignore`)؛ `Env.all()` يكشف كل البيئة فلا تطبعه.
- المسار النسبي يُحلَّل مثل `readFile`. الاختبار: `tests/verification/env_basic.rin`.
- التنفيذ: `app/src/main/cpp/rin_env.cpp` (يُضمَّن في `rin_interpreter.cpp` فلا تغيير في ملفات البناء).
