# مرجع الواجهة البرمجية (API Reference)

مرجع واجهات Rin 1.0 الثابتة على مستوى runtime. يجب التحقق من كل واجهة مقابل
تنفيذها الفعلي.

الواجهات البرمجية تُبنى فوق نفس مفاهيم اللغة الموثّقة في
[`language-reference.md`](./language-reference.md): استدعاء [الدوال](./functions.md)
القياسية من [`standard-library.md`](./standard-library.md)، تمرير [كائنات](./objects.md)
وقواميس، والعمل مع [الحاويات](./containers.md) لتخزين/استرجاع البيانات عبر
[`storage.md`](./storage.md) و[`http.md`](./http.md).
