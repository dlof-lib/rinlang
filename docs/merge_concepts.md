# دمج المفاهيم المتكاملة (Merge Concepts)

أربعة دمجات كبيرة تجمع مفاهيم كانت منفصلة في اللغة، فتعمل معاً كنظام واحد. كلها **إضافات بحتة**:
كل صيغة جديدة كانت خطأً سابقاً أو اسماً جديداً، ولا يتغيّر أي كود موجود (اختُبرت `rintests.rin` وكل اختبارات `tests/print`).

| الدمج | ما يجمعه | الصيغة |
|---|---|---|
| معاملة موحَّدة | docStore + حقول الحاويات + `try/finally` + `!?` | `@tx a, b { ... }` |
| مصبّ الأنابيب | `\|>` + `$` (print) | `x \|> f \|> $` · `__tap(v, fn)` |
| الحاويات مع Set | `@اسم.doc` + `#[ ]` + جبر المجموعات | `docIdSet` · `docFieldSet` · `docsWhereIn` |
| Set مع الإدخال | `?!` + `#[ ]` | `?!("لون؟ ", #["red" "green"])` |

## 1) `@tx` — معاملة موحَّدة
قبل ذلك كانت المعاملات منفصلتين: `beginTransaction/rollbackTransaction` للمستندات فقط، و`container.transaction(names, fn)` لحقول الحاويات فقط.
`@tx` تلتقط **الاثنين معاً** في لقطة عميقة واحدة، وتستعيدهما معاً عند أي خطأ ثم **تعيد رمي الخطأ نفسه**.

```rin
@tx bank, ledger {                       // أسماء الحاويات اختيارية: بلا أسماء = المستندات فقط
    setField("bank", "bal", 0);
    insertDoc("users", "u4", {name: "x"});
    !? "فشل التحويل";                    // أو أي خطأ تنفيذ — يتراجع الجميع
}
```

- **النجاح:** تُعتمد التغييرات. **الفشل (`!?` أو خطأ تنفيذ):** تُستعاد مستندات كل المجموعات وحقول الحاويات المسمّاة، ثم يُعاد رمي الخطأ فيلتقطه `try/catch` خارجي أو `@fail`.
- **متداخلة:** كل `@tx` لها لقطتها؛ فشل الداخلية يتراجع لنقطتها فقط، والخارجية تتابع وتُعتمد.
- **`break`/`continue`/`^` داخلها** تُغلق الكتلة بنجاح (تُعتمد التغييرات) لأن الإغلاق في `finally`.
- **الحدود:** حقول الحاويات الدالّية (`fun`) لا تُلتقط. حاوية غير موجودة = خطأ قبل أي تنفيذ. `exit(n)` داخل الكتلة لا يُعدّ فشلاً (تُعتمد التغييرات).
- `txDepth()` تعيد عدد كتل `@tx` المفتوحة. تقنياً: `__tx_begin` + `try{...} catch{__tx_fail; rethrow} finally{__tx_end}`.

## 2) `|> $` — الطباعة كمصبّ داخل الأنبوب
`$` بعد `|>` تطبع القيمة **وتمرّرها** فلا تنكسر السلسلة (≡ `__tap`):

```rin
let n = [3 1 2] |> sort |> $ "مرتّبة" |> len;     // يطبع:  مرتّبة: [1, 2, 3]   ثم n = 3
data |> __tap(fun(v) { $ "n =", len(v); }) |> mean;      // __tap(v, fn): يستدعي fn(v) ويمرّر v
```

`__tap(v)` يطبع · `__tap(v, "وسم")` يطبع `وسم: v` · `__tap(v, fn)` يستدعي `fn(v)`. كلها تعيد `v`.
الاسم `__tap` داخلي عمداً كي لا يصطدم بـ `fun tap` في `lib/compose.og.rin`؛ للاستعمال اليومي اكتب `|> $`.

## 3) الحاويات مع Set
الدوال التي تعيد **Set** فتعمل معها `+` اتحاد · `*` تقاطع · `-` فرق · `.has()`:

```rin
docIdSet("users") - docFieldSet("orders", "user")        // مستخدمون بلا طلبات   (Set{"u2"})
docIdSet("users") * docFieldSet("orders", "user")        // لديهم طلبات
docFieldSet("users", "city")                             // القيم المميّزة للحقل
docsWhereIn("users", "city", #["بيروت" "صيدا"])          // المستندات (كمصفوفة) التي حقلها ∈ Set
```

## 4) Set مع الإدخال
Set كمُدقِّق = **القيم المسموحة** (القبول إن كانت القيمة عضواً، والرفض برسالة تسرد المتاح):

```rin
let c = ?!("لون؟ ", #["red" "green"]);
let n = inputNumber("رقم؟ ", #[1 2 3]);
input("بيانات", "Settings", {theme: #["dark" "light"]});   // في المخطّط: Set = choose
```

## مثال يجمع الكل
```rin
@start { @users.doc  document id="u1" fields={ city: "بيروت" };  .end/doc }
@fail  { $ "فشل:", programError(); }
@tx { insertDoc("users", "u2", {city: "صيدا"}); !? "إلغاء"; }       // يتراجع، ثم يُشغَّل @fail
```
