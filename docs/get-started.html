دليل البدء

اختر طريقك إلى Rin

ثلاث طرق حقيقية لتشغيل نفس المحرّك: من الهاتف مباشرة بلا حاسوب، من سطر الأوامر على لينكس، أو داخل المتصفح عبر WebAssembly.

الطريق الأول: تطبيق أندرويد

بيئة تطوير كاملة داخل الهاتف: محرّر شيفرة، تشغيل فوري، وتصدير الناتج كملف APK — بلا حاسوب أو تثبيت إضافي.

01

ثبّت التطبيق

حمّل ملف APK من صفحة الإصدارات (Releases) في مستودع GitHub، أو ابنِه بنفسك عبر Gradle من مجلد app/.

02

أنشئ مشروعاً

من الشاشة الرئيسية أنشئ مشروعاً جديداً، وابدأ الكتابة في المحرّر — تلوين صياغة، إكمال تلقائي، وتشخيص أخطاء فوري.

03

صدِّر التطبيق

من شاشة تصدير APK حدِّد الاسم، الأيقونة، وإصدار SDK، واحصل على ملف APK جاهز للتثبيت أو المشاركة.

الطريق الثاني: سطر أوامر لينكس

مُفسِّر مستقل تماماً عن أندرويد/NDK، يبني نفس ملفات المحرّك الحقيقية (rin_lexer.cpp / rin_parser.cpp / rin_interpreter.cpp) كملف تنفيذي واحد.

01

ثبّت المتطلبات

CMake ومترجم ++C، إضافة إلى zlib للضغط الحقيقي المستخدم داخل المحرّك.

sudo apt install cmake g++ zlib1g-dev   # Debian / Ubuntu
02

ابنِ المُفسِّر

cd cli/linux
./build.sh
# أو يدوياً:
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
# الناتج: build/rin
03

اكتب أول برنامج وشغّله

// hello.rin
let name = "Rin";
print "مرحباً، " + name;
./build/rin hello.rin
# مرحباً، Rin

الطريق الثالث: داخل المتصفح عبر WebAssembly

نفس محرّك Rin (لا نسخة مصغَّرة) يُصدَّر إلى WebAssembly ويعمل داخل صفحة ويب مباشرة. هذا الموقع نفسه فيه صفحة المحرّر — محرِّر مباشر بلا تثبيت، يكفي بناء المحرّك مرّة واحدة محلياً: 

bash docs/assets/engine/build-engine.sh

يحتاج ذلك Emscripten SDK فقط (تفاصيل الخطوة في docs/assets/engine/README.md)؛ بعدها تكتشف صفحة المحرّر ملفَّي rin.js/rin.wasm تلقائياً. مسار مختلف وأشمل موجود في مجلد web/ من المستودع نفسه (./web/build_rinhtml_wasm.sh) لتشغيل صفحات RinHTML الكاملة القائمة على شجرة @view — راجع web/index.html وweb/site.rin على GitHub لتفاصيله.

الربط مع لغات أخرى

مجلد bindings/ يبني المحرّك كمكتبة مشتركة (librin.so / .dylib / .dll) بواجهة C ثابتة، مستقلة عن أندرويد/NDK، مع أمثلة جاهزة لاستدعائها من C وPython (عبر ctypes) وNode.js (عبر ffi-napi).
