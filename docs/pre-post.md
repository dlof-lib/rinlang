# pre-post.md — `pre` و`post` (ما قبل / ما بعد): عقد انتقال حول الإسناد

> كل مثال هنا جُرِّب فعليًا عبر المفسِّر (انظر `tests/verification/pre_post_basic.rin` و`examples/pre_post_demo.rin`).

`accept` يسأل عن **القيمة الجديدة وحدها**. لكن كثيرًا من القواعد تتعلّق بـ **الانتقال** نفسه: من أين أخرج؟ وإلى أين وصلت؟ وكم قفزت؟
هذان النوعان يسألان عن الانتقال من جهتَيه:

| الكلمة | متى تسأل؟ | ماذا يرى الشرط؟ | إن كُذِّب الشرط |
|---|---|---|---|
| `pre`  (ما قبل)  | **قبل** الكتابة، والعالم ما زال على القيمة القديمة | اسم المتغيّر = القيمة **القديمة** | لا تُكتب شيئًا |
| `post` (ما بعد) | **بعد** الكتابة، والعالم يحمل القيمة الجديدة فعلًا | اسم المتغيّر = القيمة **الجديدة** | تُلغى الكتابة ويُعاد ما كان |

في **كلا الشرطين** يتوفّر الاسمان `old` (القيمة السابقة) و`new` (القيمة المكتوبة)، فلا تحتاج إلى حفظ القديمة بنفسك.
كلاهما من عائلة المتغيرات الحيّة ([`living-variables.md`](./living-variables.md)): **كلمتان سياقيتان غير محجوزتان**؛ `let pre = 1;`
و`fun f(post){...}` ما زالا صالحين تمامًا، وبرنامج لا يستعملهما لا يدفع أي كلفة.

## الصيغة

```
pre  x = v if RULE [post RULE2] [strict];
post x = v if RULE [pre  RULE2] [strict];
```
- `if` يكتب شرط نوع المتغيّر (`pre` ← قبل، `post` ← بعد). الشرط الآخر اختياري ويُكتب بالكلمة المقابلة: `pre lvl = 1 if old < 5 post new <= old + 1;`
- الافتراضي **صامت**: الكتابة الملغاة تُتجاهل و`x.ok` تصير `false`. و`strict` يحوّلها إلى خطأ `E0051`.
- القيمة الابتدائية ليست «انتقالًا»: لا تُسأل عنها `pre`. أما `post` فتُسأل عنها (حيث `old` و`new` نفس القيمة) فيفشل التصريح بـ `E0051` إن خالفت قاعدتها.

## `pre` — هل يجوز أن أخرج من الحالة الحالية؟

```rin
pre door = "closed" if old != "locked";
door = "open";    print door;     // open
door = "locked";  print door;     // locked
door = "open";    print door;     // locked  ← محجوب: القيمة القديمة locked
print door.ok;                    // false
```
مناسب لآلات الحالات: «لا تغادر `done`»، «لا تعدّل الطلب بعد `shipped`».

## `post` — هل الحالة التي وصلتُ إليها مقبولة؟

```rin
post stock = 10 if new >= 0 and new <= old + 100;     // لا سالب، ولا قفزة فوق 100
stock = 50;   print stock;        // 50
stock = -5;   print stock;        // 50   ← تراجع
stock = 500;  print stock;        // 50   ← القفزة أكبر من 100
```
`post` يرى الحالة بعد الكتابة، فيصلح للقواعد النسبية (`new >= old` عدّاد لا ينقص، `new <= old + 100` حدّ للقفزة) ولما يعتمد على متغيرات أخرى.

## الاثنان معًا

```rin
pre lvl = 1 if old < 5 post new <= old + 1;   // لا خروج بعد 5، ولا قفزة أكثر من 1
lvl = 2; lvl = 4;  print lvl;     // 2   (post: 2→4 قفزة 2)
inc lvl; inc lvl; inc lvl;        // 3, 4, 5
inc lvl; print lvl;               // 5   (pre: القديمة 5 ليست < 5)
```

## الخصائص (للقراءة فقط)

آخر **محاولة** كتابة تُوصَف بزوج `(pre → post)`:

| الخاصية | المعنى |
|---|---|
| `x.pre` | القيمة قبل آخر محاولة (`nil` قبل أول محاولة) |
| `x.post` | القيمة التي حاولت آخر كتابة وضعها (ابتدائيًا: القيمة الأولى) |
| `x.ok` | هل نجحت آخر محاولة؟ |
| `x.accepted` / `x.rejected` | عدّادا النجاح والرفض (المحاولات فقط، لا القيمة الابتدائية) |
| `x.refused` | آخر قيمة رُفضت |
| `x.kind` | `"pre"` أو `"post"` (بحسب كلمة التصريح) · `x.vitals` خريطة بكل شيء |

نجحت المحاولة ⇒ `x.post == x`. رُفضت ⇒ `x.pre == x` و`x.post` هي القيمة المرفوضة. ولخدمة `if`:
```rin
stock = 500;
if (!stock.ok) { print "refused " + str(stock.post) + ", kept " + str(stock.pre); }   // refused 500, kept 50
```
(حقل بيانات حقيقي بنفس الاسم، كمفتاح `pre` في قاموس، يغلب الخاصية.)

## يعمل مع بقية اللغة

- `inc`/`dec` تمرّان من الشرطين.
- `bell x { ... }` يرنّ فقط عند **النجاح** الفعلي؛ الكتابة الملغاة لا ترنّ ولا تسجَّل في تاريخ `tape` ولا في `x.writes`.
- `trial { ... abort; }` يعيد قيمة المتغيّر **وعدّاداته** إلى حالها.
- النوعان محليّان للنطاق؛ والشرط يُقيَّم في نطاق التصريح فيرى متغيراته.
- النوع واحد لكل متغيّر: لا يُجمع `pre`/`post` مع `gauge`/`tape`/`accept` (الجمع بين شرطَي قبل وبعد يتمّ بالصيغة أعلاه).

## الأخطاء

| الكود | متى |
|---|---|
| `E0051` | رفض في `strict` (قبل أو بعد) · قيمة ابتدائية تخالف شرط `post` |
| `E0012` | `pre`/`post` بلا `if` |
| `E0013` | شرط مكرّر، أو مُعدِّل في غير مكانه (مثل `else` أو `post` بعد `post`) |
| `E0046` | خاصية لا تخص هذا النوع (مثل `x.pre` على متغيّر عادي له جرس فقط) |

## حدود معروفة
`old`/`new` تحجبان أي متغيّر بنفس الاسم داخل الشرط فقط · الشرط يُقيَّم عند كل إسناد (كلفته كلفة تعبيره) ·
كتابة `post` المؤقتة خام (لا تُطلق خطّافات `state` ولا الروابط إلا عند النجاح) · مترجم `rinc` (Rin → C) لا يدعم هذه الصيغ بعد (مثل بقية المتغيرات الحيّة).
