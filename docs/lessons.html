01

المتغيّرات والدوال

let لتعريف متغيّر، fun لتعريف دالة، وصياغة أقواس قريبة من C/JavaScript — بلا فاصلة منقوطة إلزامية في كل موضع.

basics.rin
let x = 10;
let name = "Rin";
print "Hello, " + name + "!";

if (x > 5) {
    print "big";
} else {
    print "small";
}

fun fib(n) {
    if (n < 2) { return n; }
    return fib(n - 1) + fib(n - 2);
}
print fib(10);
→ Hello, Rin!
→ big
→ 55
▶ جرّب هذا المثال في المحرّر

تمرين

عدِّل fib(10) إلى fib(15) وتوقّع الناتج قبل تشغيله. ثم اكتب دالة factorial(n) بنفس أسلوب الاستدعاء الذاتي (recursion).

02

المصفوفات والقواميس

مدمجة في اللغة مباشرة بدوال قياسية عامة: push / pop / sort / keys.

collections.rin
let arr = [1, 2, 3];
push(arr, 4);
print pop(arr);
print sort([3, 1, 2]);

let m = {name: "Rin", age: 2};
print m["name"];
print keys(m);
→ 4
→ [1, 2, 3]
→ Rin
→ [name, age]
▶ جرّب هذا المثال في المحرّر

تمرين

أنشئ قاموساً person بحقلَي name وcity، ثم اطبع كل قيمة بسطر عبر التكرار على keys(person) (سنغطّي for..in في الدرس 05 كطريقة أقصر).

03

الأصناف والوراثة

class وextends وsuper بالمعنى المعتاد؛ استدعاء كائن.دالة() يعمل تماماً كما تتوقّع.

classes.rin
class Animal {
    fun speak() { return "..."; }
}
class Dog extends Animal {
    fun speak() { return "Woof " + super.speak(); }
}
let a = Dog();
print a.speak();
→ Woof ...

تمرين

أضف صنفاً ثالثاً Cat extends Animal بصوت مختلف، وأنشئ مصفوفة من Dog() وCat() واطبع صوت كل عنصر.

04

الدوال المجهولة والإغلاقات

fun(params) { body } كتعبير، قابل للإسناد أو التمرير أو النداء الفوري — ولكل تكرارة حلقة إغلاقها الخاص، لا متغيّراً مشتركاً.

closures.rin
let fns = [];
for (let i = 0; i < 3; i = i + 1) {
    fns[len(fns)] = fun() { return i; };
}
print fns[0]();
print fns[1]();
print fns[2]();

fun makeAdder(n) { return fun(x) { return x + n; }; }
print makeAdder(3)(4);
→ 0
→ 1
→ 2
→ 7
▶ جرّب هذا المثال في المحرّر
لماذا هذا مهم: قبل إصلاح مسجَّل في آخر ما وصل إلى المحرّك، كانت كل الدوال المجهولة الثلاث تشترك في نفس المتغيّر i فتطبع 3 3 3. الآن لكل تكرارة بيئتها الخاصة.
05

التكرار for ... in

على مصفوفة (كل عنصر)، قاموس (كل مفتاح)، أو نص (كل حرف) — بلا فهرس عددي يدوي.

forin.rin
for (let x in [10, 20, 30]) { print x; }

let m = {"a": 1, "b": 2};
for (let k in m) { print k + "=" + m[k]; }

for (let c in "abc") { print c; }
→ 10 20 30
→ a=1 b=2
→ a b c
▶ جرّب هذا المثال في المحرّر

تمرين

عُد إلى قاموس person من الدرس 02 واطبع كل مفتاح وقيمته بسطر عبر for (let k in person).

06

الحاويات @container

وحدة تنظيمية تُجمِّع بيانات ومنطقاً مرتبطين ببعضهما داخل حدود واضحة، بدل تفريقها بين متغيّرات ودوال متناثرة. قابلة للتجميع داخل @Containers.Group.

container.rin
@container=my_data
    text title = "بيانات رين";
    print title;

    Section=numbers
        let a = 10;
        let b = 4;
        print Addition(a, b);
    .end/Section
.end/container
→ بيانات رين
→ 14
▶ جرّب هذا المثال في المحرّر

الأسلوب المبسّط: container("Home") تُعيد وصفاً مختصراً للحاوية، وcontainer("Home", "title") تقرأ حقلاً منها مباشرة (تُعيد nil بدل الانهيار إن لم يوجد). التفاصيل في docs/simple-style.md من المستودع.

تمرين

أضف قسماً ثانياً Section=greeting داخل نفس الحاوية يطبع تحية باستخدام title من القسم الأول.

07

قاعدة بيانات NoSQL المدمجة

مخزن وثائق (documents) بلا أي اتصال خارجي أو استيراد إضافي — أنشئ حاوية وثائق بـ @container.doc، ثم أدرج/استعلم عنها مباشرة بدوال اللغة الأساسية نفسها.

users.rin
@container.doc=users
    document id="u1" fields={ name: "سارة", age: 28 };
.end/container.doc

insertDoc("users", "u3", { name: "منى" });
print queryDocs("users", "city", "الرياض");
▶ جرّب هذا المثال في المحرّر

تمرين

أضف حقل city إلى وثيقة u1، ثم أعد تشغيل queryDocs بنفس القيمة وقارن الناتج.

08

أنابيب |>

بدل تعشيش الاستدعاءات f(g(h(x)))، الأنبوب يمرّر ناتج كل خطوة إلى التي تليها بترتيب القراءة الطبيعي — داخل حاويات @container.pipe المخصَّصة لهذا الغرض.

pipe.rin
@container.pipe=sales_pipeline
    let raw = [1, 2, 3, 4, 5];
    let result = raw |> normalize() |> mean();
    print result;
.end/container.pipe
▶ جرّب هذا المثال في المحرّر

تمرين

أضف خطوة ثالثة إلى الأنبوب (مثلاً دالة تُقرِّب الناتج)، والاحظ كيف يبقى الترتيب مقروءاً من اليمين لليسار بلا تعشيش أقواس.
