# val — قيمة تفاعلية (Reactive Value)

> كل مثال هنا جُرِّب فعلياً عبر المفسِّر (انظر `tests/print/val_*.rin` و`examples/val_demo.rin`).

`val` متغيّر **يحسب نفسه ويُحدِّث نفسه**: تكتب تعبيراً مرة واحدة، فيتتبّع المفسِّر كل ما يقرؤه التعبير، وعند تغيّر أي منها يُعاد الحساب **تلقائياً (دفعياً)** وتُرنّ الأجراس إن تغيّرت النتيجة فعلاً.
كلمة سياقية غير محجوزة كباقي الأسرة (`val x = ...` فقط؛ `let val = 1;` يبقى صالحاً)، وبرنامج لا يستعملها لا يدفع أي كلفة.

```kotlin
let price = 10;  let qty = 2;
val total = price * qty;                  // 20
bell total (old, new) { print old + " -> " + new; }
price = 15;                               // يرنّ: 20 -> 30
print total;                              // 30
```

## الفرق عن `lens`
| | `lens` | `val` |
|---|---|---|
| الحساب | عند **كل قراءة** | **مرة** عند كل تغيّر في اعتماداته، ثم يُخزَّن |
| الأجراس | لا | نعم (عند التغيّر الفعلي) |
| ما يعتمد عليه | يُعاد تقييمه | `val` أخرى تتسلسل خلفه بترتيب صحيح |
| ذاكرة/مدى/شرط/وسم | لا | `keep` · `within` · `when` · `as` |

## الصيغة
```kotlin
val NAME = EXPR [lazy] [when COND] [keep N] [within A to B [strict|wrap]] [as TITLE] [about TEXT] [unit TEXT];
touch NAME;      // إعادة حساب قسرية
unval NAME;      // فكّ التفاعل: تبقى القيمة الحالية كمتغيّر عادي
```
المُعدِّلات بأي ترتيب. للقراءة فقط: الإسناد إليها `E0045` (وكذلك `x[i] = ..` و`x.f = ..`).

## كيف يعمل
- **تتبّع اعتماديات ديناميكي**: كل متغيّر أو حقل حاوية (`c.f` / `getField`) يُقرأ أثناء الحساب (حتى داخل دالة تستدعيها) يصير اعتماداً. تُبنى القائمة من جديد عند كل حساب، فالشرط `a ? b : c` يتبع ما قُرئ فعلاً.
- **ترتيب طوبولوجي بلا glitches**: في الشكل الماسي `x → b, c → d` تُحسب `d` **مرة واحدة** بعد اكتمال `b` و`c`، ولا تُحسب `val` إن لم يتغيّر أي من اعتماداتها.
- **التغيّر الفعلي فقط**: إن أعاد الحساب القيمة نفسها فلا كتابة ولا جرس ولا تحديث لما بعدها. إسناد قيمة مساوية للمصدر لا يحسب شيئاً.
- **المصدر قد يكون أي شيء**: `let`، أو `tape` (حتى `undo`/`redo`)، `gauge`، `accept`/`pre`/`post` (الإسناد المرفوض لا يحدّث شيئاً)، `lens`، `val` أخرى، حقل حاوية (من داخلها أو `shop.stock = 3` أو `setField`)، ومحتوى مصفوفة/قاموس عبر `x[i] = ..` أو `x.f = ..`.

## المُعدِّلات
| المُعدِّل | الأثر |
|---|---|
| `lazy` | لا يُحسب إلا عند القراءة (يُعلَّم `stale` عند تغيّر اعتماد)؛ يُحسب مرة واحدة مهما تغيّر المصدر قبلها |
| `when COND` | ما دام الشرط كاذباً **تتجمّد** القيمة (`held`)، وتستيقظ حين يصدق (الشرط نفسه اعتماد) |
| `keep N` | يتذكّر آخر N قيمة سابقة: `x.past` (للقراءة؛ لا `undo`) |
| `within A to B [strict\|wrap]` | يقيّد النتيجة كـ `gauge` (`clamp` افتراضي) |
| `as/about/unit` | تسمية ووصف ووحدة كـ `label/define`: `x.label` `x.about` `x.unit` `x.info` |

## الخصائص
`x.kind` (= `val`) · `x.deps` أسماء ما يقرؤه · `x.runs` عدد الحسابات · `x.stale` · `x.lazy` · `x.held` · `x.past` (مع `keep`) · `x.vitals`،
وعلى أي متغيّر: **`x.dependents`** = أسماء الـ vals التي تقرؤه.

## التكامل مع بقية الأسرة
- **`bell`**: يعمل على `val` (يرنّ عند تغيّر النتيجة) وعلى مصادرها كالمعتاد. الترتيب: جرس المصدر ثم تحديث الـ vals.
- **`trial`**: التراجع يعيد المصدر **و**القيمة المخزَّنة معاً (وتُعاد الاشتراكات)؛ لا رنين عند التراجع، ويبقى `val` تفاعلياً بعده.
- **`@tx`**: التراجع يستعيد حقول الحاويات ثم يحدّث الـ vals التي تقرؤها.
- **`containerType`**: كتابة مرفوضة بنوع/مدى/`check` لا تحدّث شيئاً؛ والمقبولة تحدّث الـ vals.
- **حاويات**: `val` داخل `@container` تقرأ حقولها كمتغيّرات محلية؛ وخارجها `getField("c","f")` أو `c.f`.
- **`label/define`** عبر `as/about/unit`، **`gauge`** عبر `within`، **`tape`** عبر `keep` (ذاكرة للقراءة فقط).

## الأخطاء
| الكود | المعنى |
|---|---|
| E0045 | إسناد إلى `val`، أو `val` تعتمد على نفسها (مباشرة أو عبر `val` أخرى) |
| E0044 | خارج مدى `strict` عند حساب `val` (يصل إلى من كتب المصدر، بعد أن كُتب المصدر) |
| E0046 | `touch`/`unval` على غير `val`، أو خاصية خاطئة |
| E0047 | تحديثات متسلسلة لا تنتهي (أجراس/vals تكتب بعضها، عمق 64) |

## حدود معروفة
- دوال تعدّل في المكان (`push()` وأخواتها) لا تمرّ بالإسناد فلا تُحدِّث الـ vals؛ استعمل `x[len(x)] = v` أو `touch`.
- إعادة تعريف المصدر بـ `let` جديدة بنفس الاسم تنهي حياته (واشتراكات الـ vals فيه).
- `shop.value.runs` (خصائص حيّة عبر مسار namespace) غير متاحة؛ اقرأ الخاصية من داخل الحاوية أو عبر متغيّر محلي.
- مترجم `rinc` (Rin → C) وRinVM لا يدعمان هذه الصيغة بعد (كباقي المتغيرات الحيّة).
