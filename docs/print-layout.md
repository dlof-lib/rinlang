# مسافات · تنسيق · تعليم · تخطيط — سمات `print` الجديدة

إضافة بحتة: لا يتغيّر أي كود قديم. كل السمات اختيارية، تعمل في اللهجتين (`print x box=true;` و`print(x, box=true);`)
وتُفكَّك في المحلل إلى نداء واحد `__pfx(...)` فتعمل على المفسّر الشجري وRinVM بلا تعديل فيهما.
تُطبَّق على النص الناتج، ثم تعمل بعدها السمات القديمة (`upper` `width` `level` `label` `repeat` وتنسيق الخط).
العرض يُحسب بالخلايا (العربية والحركات والرموز العريضة وأكواد ANSI تُحسب صحيحاً).

## 1) المسافات
| السمة | الأثر |
|---|---|
| `indent=4` أو `indent="> "` | إزاحة كل سطر (رقم = مسافات، نص = بادئة) |
| `gap=3` | مسافات بين القيم (بديل `sep`، ولا يجتمعان) |
| `pad=2` | مسافة داخلية يمين ويسار كل سطر (مع `box` الافتراضي 1) |
| `before=1` / `after=1` | أسطر فارغة قبل/بعد الكتلة |
| `trim=true` | قصّ مسافات طرفَي كل سطر |
| `squeeze=true` | ضغط تتابع المسافات إلى واحدة |
| `visible=true` | إظهار المسافات: `·` مسافة، `→` Tab، `␍` |

## 2) التنسيق
- `fmt="..."` للأرقام: `[+][0][عرض][,][.دقة][نوع]` — الأنواع `f` `%` `e` `x` `X` `b` `o` `k`(مختصر K/M/B/T)،
  وأسماء جاهزة `money` `percent` `int` `compact`. مثال: `fmt=",.2"` ← `1,234.50`، `fmt="05"` ← `00007`، `fmt=".1%"`.
- `case="upper|lower|title|sentence|swap|snake|kebab|camel"`.
- `wrap=n` التفاف الكلمات عند عرض n · `cut=n` اقتطاع بـ `…`.

## 3) التعليم
- `mark="bullet|dash|arrow|check|cross|star|dot|plus|circle|square|warn|num|alpha|none"` أو أي نص (`mark="[ ]"`)؛ `true` = نقطة.
  بادئة لكل سطر غير فارغ، والأسطر الملتفّة تُزاح تعليقاً (hanging)، و`num` ترقيم محاذى.
- `hl="كلمة"` أو `hl=["a","b"]` يحيط التطابقات بعلامات، و`hlwrap="[]"` يغيّرها (الافتراضي `«»`؛ أو `["<b>","</b>"]`).

## 4) التخطيط
- `box=true|"single|double|round|bold|ascii"` إطار حول الكتلة، و`title="..."` عنوان في الحافة (يتطلب `box`).
- `cols=n` توزيع القيم (وعناصر المصفوفة) على n أعمدة بمحاذاة تلقائية (الأعمدة الرقمية يميناً)، و`colgap=n`.
- `page=n` مع `place="left|center|right"` وضع الكتلة داخل عرض صفحة.

```rin
print "Hello\nWorld" box="double" title="Greeting";
print [1, 22, 333, 4, 5, 6] cols=3;
print 1234567.891 fmt=",.2" indent=4;
print "one\ntwo" mark="num";
print "find the needle" hl="needle";
```

## دوال
`layoutText(value, {…نفس السمات…, sep, pretty})` تعيد النص منسّقاً دون طباعة · `fmtNumber(n, spec)` · `showSpaces(s)`.

## ملاحظات
- أسماء السمات الجديدة تُقرأ كسمات فقط بعد قيم `print` (أو داخل قوسي الاستدعاء قبلها `=`)؛ المتغيرات بهذه الأسماء تعمل في بقية الكود.
- `place` يتطلب `page` و`title` يتطلب `box`، وإلا خطأ صريح.
- `before`/`after` أسطر فارغة عادية تقع بعد رمز `level`/`label` إن وُجدا.
- الاختبار: `tests/print/print_layout.rin`.

## ميزات إضافية
| السمة | الأثر |
|---|---|
| `table=true` أو `table="round"` | جدول بإطار وفاصل عنوان: مصفوفة قواميس (المفاتيح عنوان) أو مصفوفة صفوف (الأول عنوان)؛ الأعمدة الرقمية يميناً؛ يقبل أنماط `box` |
| `leader="."` + `page=n` | نقاط قيادة: القيم أزواجاً (اسم، قيمة) تُملأ بين الاثنين حتى عرض الصفحة |
| `inalign="left\|center\|right"` | محاذاة الأسطر داخل الكتلة (مفيدة مع `box`) |
| `numbers=true` أو `numbers=10` | عمود أرقام الأسطر (يبدأ من 1 أو من الرقم المعطى) |
| `rule="="` أو `rule=true` | خط فاصل بعرض الكتلة أعلاها وأسفلها |
| `shadow=true` | ظل (`░`) للكتلة/الإطار |
| `beside=true` | القيم كتل متعددة الأسطر جنباً إلى جنب (`colgap`/`gap` للفاصل) |
| `justify=true` | ضبط النص (يتطلب `wrap`) — كل أسطر الفقرة عدا الأخير |
| `cutat="end\|start\|middle"` | موضع `…` في الاقتطاع (يتطلب `cut`) |

```rin
print [{name: "Ali", qty: 3}, {name: "Sara", qty: 12}] table=true;
print "Coffee", 3.5, "Cake", 12 leader="." page=24 fmt=".2";
print "A\nB", "1\n2" beside=true colgap=4;
```

## ميزات إضافية (2)
| السمة | الأثر |
|---|---|
| `tree=true` أو `tree="ascii"` | شجرة لقاموس/مصفوفة متداخلة (`├─ └─ │`) |
| `bars=n` | مخطط أعمدة أفقي بأقصى عرض n (`true` = 20): قاموس اسم←رقم، أو مصفوفة أرقام، أو أزواج `[اسم, رقم]` |
| `diff=true` | فرق الأسطر بين قيمتين نصيتين: `-` محذوف · `+` مضاف · مسافتان لثابت |
| `tabs=n` | توسيع Tab إلى مواقف كل n خلايا |
| `dedent=true` | إزالة الإزاحة المشتركة من كل الأسطر |
| `maxlines=n` | الاكتفاء بأول n سطر ثم `… (+k more)` |
| `ends=true` | علامة `¶` عند نهاية كل سطر (لكشف المسافات الزائدة) |
| `ruler=true` | مسطرة أعمدة فوق الكتلة (للتحقق من المحاذاة) |
| `focus="كلمة"` | `▶` أمام الأسطر التي تحويها ومسافتان لغيرها |
| `hlcase=false` | جعل `hl` غير حسّاس لحالة الأحرف (ASCII) |

```rin
print {name: "app", deps: {a: 1}} tree=true;
print {Mon: 4, Tue: 9} bars=10;
print "a\nb", "a\nc" diff=true;
```
