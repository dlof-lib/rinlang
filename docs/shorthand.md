# الرموز المختصرة (Shorthand Symbols)

رموز من حرف واحد تختصر المفاهيم الأكثر استعمالاً. كل رمز **مرادف حرفي كامل** للكلمة الأصلية
(نفس التوكن في المحلل)، فيرث كل صيغها وسماتها، ولا يغيّر أي كود موجود.

| الرمز | يساوي | مثال |
|-------|-------|------|
| `$`   | `print` / `show` | `$ "مرحبا";` |
| `?!`  | `input(...)` (إدخال) | `let a = ?!("اسمك؟ ");` |
| `!?`  | `throw` (رمي خطأ) | `!? "خطأ";` |
| `&`   | `let` | `& x = 5;` |
| `^`   | `return` | `^ a + b;` |
| `@start { }` / `@end { }` | بداية الكود / نهاية الكود | `@end { $ "انتهى"; }` |
| `@اسم.نوع` | `@container.نوع=اسم` | `@app.doc` |
| `#[ ]` | مجموعة `Set` حرفية | `#[1 2 3]` |
| (مسافة) | فاصلة `,` في القوائم/القواميس | `[1 2 3]` · `{a: 1 b: 2}` |

## `$` — طباعة

```rin
let n = 3;
$ "مرحبا";                      // مرحبا
$ "a", "b", "c" sep="-";        // a-b-c
$ `قيمة n = ${n}`;              // قيمة n = 3
$ "x" if=(n > 5);               // لا يطبع
$ "نهاية" end="|";              // بلا سطر جديد
$.log.info("معلومة");           // نظام Log
$.image(...);                   // صيغ print.* كلها تعمل
```

- كل سمات `print` تعمل كما هي: `sep= end= if= level= label= repeat= pretty= upper= lower= width= align= color= bg= bold ...`
- داخل النصوص والقوالب لا يتغيّر شيء: `${...}` تبقى تعبير استيفاء، و`\$` تبقى رمز دولار حرفي.
- خارج النصوص كان `$` خطأ E0011، فلا تعارض مع أي كود قديم. لا يصلح `$` اسماً لمتغير.
- التلوين: المحرر داخل التطبيق وإضافة VS Code يلوّنان `$` ككلمة مفتاحية.

## `?!` — إدخال

استدعاء عادي لـ `input` (docs/input.md)، فيرث توقيعاته كلها: `?!(prompt, validator, target, key)`.

```rin
let name = ?!("ما اسمك؟ ");
let age  = toNumber(?!("عمرك؟ "));
```

- يُفهم كإدخال فقط حين لا يسبقه ما ينتهي بقيمة (معرّف/رقم/نص/`)`/`]`)، لذلك الشرط الثلاثي القديم
  `cond ?!x : y` يعمل كما كان حرفياً.
- اكتبه دائماً بأقواس: `?!("...")`.

## `!?` — رمي خطأ

مرادف `throw` (نفس التوكن)، فيعمل مع `try/catch` والحارس `when`:

```rin
try {
    !? "خطأ مخصص";
} catch (e) {
    $ "التقط:", e.message;
}
!? "مشروط" when (n < 0);
```

- `!` متبوعة مباشرة بـ `?` لم تكن صالحة في أي كود قديم، فلا تعارض.

## `&` — تعريف متغير · `^` — إرجاع

مرادفان حرفيان لـ `let` و`return` (نفس التوكن):

```rin
fun add(a, b) { ^ a + b; }
& x = add(2, 3);
for (& i = 0; i < 2; i = i + 1) { $ i; }
```

## الفاصلة الاختيارية في القوائم والقواميس

الفاصلة `,` اختيارية داخل `[ ]` و`{ }` الحرفية؛ تكفي المسافة (أو السطر الجديد):

```rin
let a = [1 2 3];                        // ≡ [1, 2, 3]
let m = [[1 2] [3 4]];                  // قوائم متداخلة
let d = {name: "Ali" age: 30 ok: true}; // ≡ {name: "Ali", age: 30, ok: true}
let e = {k: [4 5] nested: {p: 1 q: 2}};
```

الفاصلة نفسها ما زالت تعمل ويمكن خلطها: `[1, 2 3, 4]`.

**حدود يجب معرفتها** (حالات كانت تُقرأ تتمّةً للعنصر السابق، وبقيت كذلك):
- عنصر يبدأ بـ `-` أو `(`: `[1 -2]` = `[-1]` (طرح)، و`[f (x)]` استدعاء → اكتب فاصلة أو أقواساً: `[1, -2]` · `[1 (-2)]`.
- داخل القوائم الحرفية، `[` تسبقها مسافة تبدأ عنصراً جديداً لا فهرسة: `[a [0]]` = عنصران؛ للفهرسة اكتبها ملاصقة `a[0]`.

## الأقواس تختار المفهوم

| الأقواس | المفهوم | مثال |
|---|---|---|
| `[ ]` | قائمة (array) | `[1 2 3]` |
| `{ }` | قاموس (map) | `{a: 1 b: 2}` |
| `#[ ]` | مجموعة (Set) | `#[1 2 2 3]` ← `Set{1, 2, 3}` |

`#[ ... ]` تُفكَّك إلى `Set([ ... ])` (docs/set.md)، فتعمل معها الفاصلة الاختيارية والتداخل وكل عمليات
المجموعة (`+` اتحاد · `*` تقاطع · `-` فرق · `.has()` ...):

```rin
let s = #[1 2 2 3];       // Set{1, 2, 3}
$ s + #[3 4];             // Set{1, 2, 3, 4}
let box = {tags: #["x" "y" "x"] list: [1 2]};
```

`#[` متبوعة مباشرة بقوس كانت خطأ E0011، فلا تعارض مع أي كود موجود. (لا يوجد في اللغة نوع Tuple أو غيره بعد،
فلم أُضف أقواساً لها.)

## الحاوية: `@الاسم.النوع`

الاسم بعد `@` والنوع بعد النقطة، بلا مسافات — بدل `@container.doc=app`:

```rin
@users.doc                                   // ≡ @container.doc=users
    document id="u1" fields={ name: "سارة" };
.end/container.doc                           // أو .end/doc أو .end;

@orders.doc {                                // بأقواس: يُغلق بـ }
    document id="o1" fields={ total: 120 };
}

@team.data                                   // ≡ @container.data=team
    let name = "rin";
.end;
```

- **الأنواع:** `doc` `table` `data` `api` `pipe` `sql` `list` `datalist` `object` `portal` `block` `sticker` `aukt` `chatbot` `make`، و`container` للحاوية العامة (`@app.container`).
- **الإغلاق:** كل الصيغ تعمل: `.end/container.doc` · `.end/doc` (جديد) · `.end;` · `}`.
- **لا تعارض:** الصيغ القديمة كلها كما هي. إن كان الاسم نفسه كلمة وسم (`doc` `table` `data` `make` `Rin` ...) فلا يُفعَّل الاختصار؛ اكتب الاسم نصاً: `@"data".doc`.
- ملاحظة: `.end/doc` صارت تُقبل أيضاً لإغلاق `@container.doc=name` (كانت خطأً سابقاً).

## بداية الكود ونهايته: `@start` · `@end` · `@ok` · `@fail` · `exit()`

كتل على مستوى الملف الأعلى، تُنفَّذ في مكان ثابت بصرف النظر عن موضعها في الملف:

| الكتلة | متى تُنفَّذ |
|---|---|
| `@start { }` | أولاً، قبل أي شيء |
| `@end { }` | **دائماً** في النهاية (نجاح، خطأ، أو `exit()`) |
| `@ok { }` | في النهاية **عند النجاح فقط** |
| `@fail { }` | في النهاية **عند الفشل فقط** |

```rin
@start {
    let db = openDb();
    fun tag(s) { ^ "[" + s + "]"; }
}
@ok   { $ "تم بنجاح في", programTime(), "ms"; }
@fail { $ "فشل:", programError(); }
@end  { closeDb(db); }                   // تنظيف مضمون دائماً

$ tag("جسم البرنامج");
if (bad) { exit(2); }                    // ينهي فوراً بعد تنفيذ كتل النهاية
```

**دوال الحالة** (متاحة في كتل النهاية): `programFailed()` · `programError()` · `programExitCode()` · `programTime()` (ms منذ بدء التشغيل).
**`exit(code?)`** متاحة في أي مكان: تنهي البرنامج فوراً (تمرّ على `finally` وكتل النهاية). `exit()` أو `exit(0)` = نجاح، وغير الصفر = فشل (`@fail`).

- **`@start`:** عباراتها تُدمَج في النطاق الأعلى فمتغيراتها ودوالها مرئية لبقية الملف.
- **ترتيب النهاية:** عكسي (آخر كتلة مسجَّلة تُنفَّذ أولاً) كما يُغلَق المورد الأحدث أولاً. تُسجَّل كتل النهاية بعد انتهاء `@start`، فإن فشلت `@start` لا يُنفَّذ تنظيف لما لم يبدأ.
- **النطاق:** كتل النهاية ترى كل متغيرات الملف وتعدّلها (حتى المعرَّفة بعد موضعها). `^` داخلها تُنهي تلك الكتلة فقط.
- **أخطاء داخل كتلة نهاية:** تُطبع ولا تمنع بقية الكتل، ويصبح البرنامج فاشلاً.
- **المكتبات:** كتل النهاية في ملف مستورد بـ `@import` تُسجَّل وتُنفَّذ مع نهاية البرنامج الرئيسي.
- **حدود:** `exit(n)` يجعل `programFailed()` صحيحة لكن رمز خروج الطرفية يبقى 1 (قراءة الرقم عبر `programExitCode()`). خارج المستوى الأعلى خطأ E0011. `@start/@end/@ok/@fail` و`exit` كانت غير موجودة، فلا تعارض.
- تقنياً: كل كتلة نهاية = دالة داخلية `__end_N` + `__atexit("__end_N", mode)` ينفّذها `Interpreter::run`.
