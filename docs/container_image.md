# `{{%s-t%}}` — رسم الحاوية كصورة ثم طباعتها فوراً

توجيه من سطر واحد يرسم **بطاقة صورة** للحاوية (العنوان = الاسم + النوع، سطر لكل حقل بلون حسب نوع قيمته: رقم/نص/منطقي/مركّب، ثم مستندات المجموعة إن وُجدت)
ثم **يطبعها في الطرفية فوراً** (ألوان 24-bit على طرفية تدعمها، وإلا ASCII تلقائياً). يستعمل نظام الرسم الموجود (`img*`، docs/image-draw.md) بلا اعتماد جديد.

```rin
@bank.container
    let owner = "Sara";  let bal = 150.5;
    {{%s-t%}}                                  // بلا اسم = الحاوية المفتوحة حالياً (حقولها حتى هذه النقطة)
.end;
{{%s-t bank%}}                                 // بالاسم (معرّف أو "نص")
{{%s-t users cols=60 save="users.png"%}}       // خيارات key=قيمة (رقم · "نص" · true/false) ← خريطة خيارات
```

يُختزل في المحلّل إلى `printContainer(name?, {opts});` (لا تحتاج `;` بعده). لا تعارض مع كود قديم: `{{%` لم تكن تركيباً صالحاً، وهي على سطر واحد فقط.

## الدوال المقابلة
| الدالة | تفعل |
|---|---|
| `containerImage(name?, opts?)` | ترسم البطاقة وتعيد **معرّف لوحة** (تستعمل معه `imgSave/imgPrint/imgResize/imgFree` ...) |
| `printContainer(name?, opts?)` | ترسم ثم تطبع فوراً ثم تحرّر اللوحة؛ تعيد `nil` (أو المعرّف مع `keep:true`) |

**الخيارات:** `cols` (عرض الطباعة بالأعمدة) · `mode` (`auto|color|blocks|ascii`) · `save` (يحفظ PNG/BMP/PPM قبل الطباعة) · `keep` ·
`docs` (أقصى عدد مستندات، 12) · `maxValue` (أقصى طول للقيمة، 60) · وكل خيارات `imgFromText`: `size` `padding` `fg` `bg` `wrap` `minWidth` `title`.

## حدود
- الدوال لا تُرسم كحقول. النص العربي في الصور تقريبي (لا خط عربي مضمَّن — انظر docs/image-draw.md).
- لا يُحفظ شيء إلا مع `save`. الحاوية غير الموجودة = خطأ E0014 قابل للالتقاط.
- الاختبار: `tests/print/container_image.rin` (يكتب `container_image_users.png` في مجلد التشغيل).
- التلوين في المحرر: التوجيه يُلوَّن عاماً كأقواس/معامل؛ تلوين خاص له لم يُضَف بعد.
