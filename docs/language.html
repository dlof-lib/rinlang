لغة Rin، من المتغيّر الأول إلى الحاوية الكاملة

كل مثال في هذه الصفحة شيفرة Rin حقيقية — إما من أمثلة المشروع نفسه، أو مُنفَّذة فعلياً على المحرّك أثناء إعداد هذه الصفحة، مع ناتجها كما هو.

الأساسيات

متغيّرات، شروط، حلقات، ودوال — بصياغة قريبة من C/JavaScript، بلا فاصلة منقوطة اختيارية.

basics.rin
let x = 10;
let name = "Rin";
print "Hello, " + name + "!";

if (x > 5) {
    print "big";
} else {
    print "small";
}

fun fib(n) {
    if (n < 2) { return n; }
    return fib(n - 1) + fib(n - 2);
}
print fib(10);   // 55

المصفوفات والقواميس

مدمجة في اللغة مباشرة بدوال قياسية عامة: push / pop / sort / keys.

collections.rin
let arr = [1, 2, 3];
push(arr, 4);
print pop(arr);           // 4
print sort([3, 1, 2]);   // [1, 2, 3]

let m = {name: "Rin", age: 2};
print m["name"];       // Rin
print keys(m);          // [name, age]

الأصناف والوراثة

class وextends وsuper بالمعنى المعتاد؛ استدعاء كائن.دالة() على متغيّر عادي يعمل تماماً كما تتوقّع.

classes.rin
class Animal {
    fun speak() { return "..."; }
}
class Dog extends Animal {
    fun speak() { return "Woof " + super.speak(); }
}
let a = Dog();
print a.speak();
→ Woof ...

الدوال المجهولة والإغلاقات

fun(params) { body } كتعبير، قابل للإسناد أو التمرير أو النداء الفوري — ولكل تكرارة حلقة إغلاقها الخاص، لا متغيّراً مشتركاً.

closures.rin
let fns = [];
for (let i = 0; i < 3; i = i + 1) {
    fns[len(fns)] = fun() { return i; };
}
print fns[0]();
print fns[1]();
print fns[2]();

fun makeAdder(n) { return fun(x) { return x + n; }; }
print makeAdder(3)(4);
→ 0
→ 1
→ 2
→ 7

التكرار for ... in

على مصفوفة (كل عنصر)، قاموس (كل مفتاح)، أو نص (كل حرف) — بلا فهرس عددي يدوي.

forin.rin
for (let x in [10, 20, 30]) { print x; }

let m = {"a": 1, "b": 2};
for (let k in m) { print k + "=" + m[k]; }

for (let c in "abc") { print c; }
→ 10 20 30
→ a=1 b=2
→ a b c

الحاويات @container

وحدة تنظيمية تُجمِّع بيانات ومنطقاً؛ قابلة للتجميع داخل @Containers.Group، وقابلة لاستدعاء بعضها البعض.

groups.rin
@Containers.Group=my_group
    @container=g1
        text label = "عنصر";
    .end/container
.end/Containers.Group

الأسلوب المبسّط: بدل عدّة دوال منخفضة المستوى، container("Home") تُعيد وصفاً مختصراً للحاوية، وcontainer("Home", "title") تقرأ حقلاً منها مباشرة (تُعيد nil بدل الانهيار إن لم يوجد).

قاعدة بيانات NoSQL

مخزن وثائق مدمج، بلا أي استيراد أو اتصال خارجي.

docs.rin
@container.doc=users
    document id="u1" fields={ name: "سارة", age: 28 };
.end/container.doc

print insertDoc("users", "u3", { name: "منى" });
print queryDocs("users", "city", "الرياض");

الأنابيب |>

تمرير ناتج خطوة إلى التي تليها بترتيب القراءة، داخل @container.pipe.

pipe.rin
@container.pipe=sales_pipeline
    let raw = [1, 2, 3, 4, 5];
    let result = raw |> normalize() |> mean();
    print result;
.end/container.pipe

المكتبات و@import

عشرات مكتبات lib/*.og.rin مضمَّنة في المحرّك مباشرة — رياضيات، نصوص، تحقّق، عُدّة نظام، فيزياء، وأخرى — تُستورَد بسطر واحد، باسم مستعار اختياري.

imports.rin
@import "lib/math.og.rin";
@import "lib/data.og.rin" as data;

من بين هذه المكتبات langkit.og.rin: عُدّة لبناء لغة برمجة مصغّرة خاصة بك فوق Rin نفسها — محلِّل لفظي، مُحلِّل تركيبي، وشجرة AST جاهزة.
