# dialog — حوار متغيّر للحاوية (Variable Dialog)

> كل مثال هنا جُرِّب فعلياً عبر المفسِّر (انظر `tests/print/dialog_*.rin` و`examples/dialog_demo.rin`).

`dialog` متغيّر حيّ من عائلة [`val`](./val.md): **رسالته تحسب نفسها وتتحدّث** كلما تغيّر شيء من حقول الحاوية التي تقرؤها، وله **حالة** (مفتوح/مغلق) و**نتيجة** (أي زرّ اختاره المستخدم) و**معالج رد** `reply`. صُمِّم للحاويات: تعلن الحاوية حوارها بجانب حقولها، ويراه الخارج بمسار واحد `shop.low`.
كلمة سياقية غير محجوزة كباقي الأسرة (`dialog x = ...` فقط؛ `let dialog = 1;` يبقى صالحاً).

```kotlin
@shop.container
    let stock = 10;
    let name = "قلم";
    dialog low = "المخزون من " + name + " منخفض: " + stock
        title "تنبيه المخزون" tone "warn" buttons ["إعادة طلب", "تجاهل"]
        opens when stock < 5;                      // يُفتح تلقائياً عند انخفاض المخزون
    reply low (r) { print "قرار المخزون:", r; }
.end;

shop.stock = 3;          // الشرط صدق => الحوار صار مفتوحاً، ورسالته: "المخزون من قلم منخفض: 3"
close shop.low 1;        // يرنّ reply بالنتيجة "إعادة طلب"
```

## الصيغة
```kotlin
dialog NAME = MESSAGE [title T] [buttons LIST] [tone T] [focus N] [opens when COND] [lazy] [when COND] [keep N];
open NAME;                   // افتح (فتح حوار مفتوح لا أثر له)
close NAME [RESULT];         // أغلق؛ RESULT = رقم الزر (1..) أو نصه، وبلا RESULT = أُغلق بلا اختيار (تجاهل)
ask NAME;                    // افتح + ارسم الحوار + اقرأ الاختيار + أغلق (انظر «ask في الطرفية»)
reply NAME (result) { ... }  // يُستدعى عند كل إغلاق؛ result = نص الزر المختار أو nil إن تُجوهل
```
المُعدِّلات بأي ترتيب. `NAME` في `open/close/ask/reply` قد يكون **مساراً مؤهَّلاً** `shop.low` (حاوية.حوار).

| المُعدِّل | الأثر |
|---|---|
| `MESSAGE` | تعبير الرسالة — **تفاعلي**: كل متغيّر/حقل حاوية يقرؤه يصير اعتماداً، فتتحدّث الرسالة وترنّ `bell` عند تغيّرها |
| `title T` | عنوان الحوار (يُقيَّم عند كل قراءة فيتبع الحاوية أيضاً) |
| `buttons LIST` | قائمة نصوص الأزرار. الافتراضي `["حسناً"]`، و`["نعم", "لا"]` لنغمة `ask` |
| `tone T` | `info` (افتراضي) · `warn` · `error` · `success` · `ask` (مرادفات: `warning` `danger` `ok` `confirm`) |
| `focus N` | الزر المختار عند الضغط على Enter في `ask` (افتراضي 1) |
| `opens when COND` | **فتح تلقائي** عند انتقال الشرط من كاذب إلى صادق (الشرط اعتماد كالرسالة). لا يُغلق تلقائياً، ولا يجتمع مع `lazy` |
| `lazy` · `when COND` · `keep N` | كما في `val`: حساب عند القراءة / تجميد الرسالة ما دام الشرط كاذباً / ذاكرة `d.past` لآخر N رسالة |

## قيمة المتغيّر وخصائصه
قيمة `d` نفسها هي **نص الرسالة الحالية** (`print d` يطبعها، و`getField("shop","low")` تقرؤها).

| الخاصية | المعنى |
|---|---|
| `d.open` | هل هو مفتوح الآن |
| `d.text` · `d.title` · `d.tone` · `d.buttons` · `d.focus` | الحالة الحالية لمكوّناته (تتبع الحاوية) |
| `d.result` | نص آخر زر اختاره المستخدم، أو `nil` (لم يُغلق بعد / أُغلق بلا اختيار) |
| `d.choice` | رقم ذلك الزر (من 1)، و`0` = لا اختيار |
| `d.opens` · `d.closes` | عدد مرات الفتح والإغلاق |
| `d.info` | خريطة بكل ما سبق |
| `d.kind` (= `dialog`) · `d.deps` · `d.runs` · `d.past` · `d.vitals` · `d.dependents` | كما في `val` |

من خارج الحاوية تعمل الخصائص عبر المسار: `shop.low.open` · `shop.low.result` ... (وهذا يفتح أيضاً `shop.total.runs` لأي `val`).

## التحكم من خارج الحاوية (دوال)
| الدالة | تعيد |
|---|---|
| `dialogs("shop")` | أسماء حوارات الحاوية (مرتّبة) |
| `dialogOpen("shop", "low")` | `true` (هو مفتوح الآن) |
| `dialogClose("shop", "low" [, result])` | نتيجة الإغلاق (`d.result`) |
| `dialogAsk("shop", "low")` | نتيجة `ask` |
| `dialogInfo("shop", "low")` | خريطة `d.info` |

## `ask` في الطرفية
`ask` يرسم الحوار نصاً ثم يقرأ سطراً: **رقم الزر** أو **نصه**؛ **Enter** (أو نهاية الإدخال) = الزر `focus`؛ يُعاد السؤال حتى 3 مرات عند إدخال غير صالح ثم يُغلق بلا اختيار.
```
╭─ ⚠ تأكيد الحذف
│ هل تريد حذف المشروع؟
│
│ [1] حذف   [2] إلغاء
╰─
› [1-2] (2):
```

## التكامل مع بقية الأسرة
- **`bell d (old, new)`**: يرنّ عند تغيّر **الرسالة** فعلياً (لا عند الفتح/الإغلاق؛ هذان لـ `reply`).
- **`trial`**: فتح الحوار وإغلاقه ونتيجته تتراجع مع التجربة (ويرجع `d.open` كما كان) — لكن ما طُبع بـ `ask` لا يُسحب.
- **`touch d;`** إعادة حساب الرسالة قسراً · **`unval d;`** تجميد الرسالة الحالية (يبقى حواراً).
- **الإسناد** `d = ...` مرفوض `E0045` (الرسالة محسوبة)؛ غيّر ما تقرؤه.
- **`@container`**: الحوار حقل حيّ للحاوية؛ خارجها `shop.low` (الرسالة) أو الدوال أعلاه.

## الأخطاء
| الكود | المعنى |
|---|---|
| E0046 | `open/close/ask/reply` على غير حوار، أو رقم/نص زر غير موجود في `close`، أو `tone`/`focus` غير صالح |
| E0004 | `buttons` ليست قائمة، أو `tone` ليس نصاً |
| E0045 | إسناد إلى `dialog` أو حوار يعتمد على نفسه |
| E0047 | `reply` يُعيد فتح حواره بلا نهاية (عمق 16) |

## حدود معروفة
- الرسم نصّي في الطرفية فقط؛ لا ربط مباشر بعنصر `@view.Dialog` في indsin (استعمل `d.open` كشرط `open=` عبر المسار أو `dialogInfo`).
- `opens when` لا يغلق تلقائياً: أغلقه بـ `close` أو من `reply`.
- لا يجتمع `opens when` مع `lazy`، ولا يُستعمل `within/strict/wrap` مع `dialog`.
- مترجم `rinc` وRinVM لا يدعمان هذه الصيغة بعد (كباقي المتغيرات الحيّة).
