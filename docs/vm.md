# RinVM — آلة Rin الافتراضية (بايتكود)

محرك تنفيذ حقيقي بجانب المفسّر الشجري. يغطي اللغة كلها؛ المخرجات مطابقة للمفسّر.

## الاستخدام
    rin --vm file.rin            # أي برنامج على RinVM
    rin vm file.rin [--disasm] [--stats] [--no-run]
    rinvm prog.rin               # RinVM افتراضياً؛ rinvm --interp للمفسّر الشجري
    RIN_ENGINE=vm rin file.rin   # عبر متغير بيئة
    rin vm-legacy file.rin       # آلة toolchain التجريبية القديمة

## الملفات
- `app/src/main/cpp/rin_bcvm.h` — مجموعة التعليمات (`RIN_VM_OPS`)، `Proto`، الواجهة.
- `rin_bcvm_compiler.cpp` — AST → بايتكود + المفكّك.
- `rin_bcvm_exec.cpp` — حلقة التنفيذ، الإطارات، المعالجات (try/goal)، علامات الحلقات.

## التصميم
آلة مكدّس مع بيئات (Environment) للمتغيرات كي تبقى دلالات المتغيرات الحيّة والإغلاقات والـ OOP مطابقة تماماً.
`break/continue/return/throw` تعمل من أي عمق عبر علامات حلقات ومكدّس معالجات. أوامر `Tick` تُصدَر فقط عند تفعيل `--budget`.
الاستدعاء الداخلي السريع (`CallNamed`) يكرّر ترتيب `invokeCallee`.

## حدود صريحة
- المتغيرات في Environments وليست خانات مكدّس.
- استدعاء دوال الأعضاء وردود النداء من الدوال الأصلية يستخدم تشغيلاً متداخلاً (تعاود C++).
- العبارات التصريحية (log/state/text/…) تُفوَّض للمحرك عبر `ExecStmt` وتُنفَّذ كتلها وتعابيرها الداخلية على الآلة.
- البايتكود داخل الذاكرة مرتبط بالـ AST؛ لا ملف بايتكود مستقل.
