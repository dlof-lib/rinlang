# rdoc — Documentation Container

`README.rdoc` لهجة مستقلة عن Markdown. تُفعَّل بترويسة في أول الملف (وتُضاف تلقائياً لأي `README.rdoc` داخل الحزم):

```text
؛؛؛ rdoc
title: اسم
؛؛؛
```

بدون الترويسة يبقى المستند Markdown خالصاً. القاعدة العامة: **الفتح والإغلاق متناظران**، والخطأ **يظهر مرئياً** (شريحة حمراء) ولا يُبتلع.

## الرموز

| الرمز | الوظيفة | مثال |
|---|---|---|
| `:::` … `:::` | حاويات تخطيط متداخلة (حتى 4). الأنواع: note/ملاحظة، tip/نصيحة، important/مهم، warning/تحذير، danger/خطر، success/نجاح، quote/اقتباس، steps/خطوات، card/بطاقة، spoiler/مخفي | `::: تحذير عنوان` |
| `؛؛؛` … `؛؛؛` | بلوكات بيانات: `rdoc`/`meta` (صامت)، `مراجع` (تعريفات `معرّف = رابط \| تسمية`)، `حقائق` (بطاقة مفتاح: قيمة) | `؛؛؛ حقائق` |
| `*"…"*` | استدعاء رابط عنصر: معرّف من `id=(…)` أو `مراجع`، أو `@user` / `@user/lib` (روابط Rin القانونية)، وبعد `\|` نص مخصّص | `*"install\|نزّل"*` |
| `؛:` … `:؛` | دفع/تبرّع: `مزوّد\|هدف[\|مبلغ عملة][\|نص][\|type=(donate\|pay\|subscribe)]`. المزوّدون: paypal, patreon, kofi, coffee, github, liberapay, opencollective, url | `؛:paypal\|user\|5 USD:؛` |
| `:;` … `;:` | فيديو/ويب فيو: `[video\|web] https://…[\|عنوان][\|height=(dp)]`. على سطر مستقل = مشغّل، داخل فقرة = زر | `:;video https://youtu.be/ID;:` |
| `[نوع: قيمة]` | أقواس مربّعة بأنواع (انظر جدول الأنواع أدناه، ولها أسماء عربية) | `[progress: 70\|إنجاز]` |
| `{{مفتاح}}` | متغيّر من بلوك `meta` (خارج كتل الكود؛ `\{{x}}` حرفية) | `{{version}}` |
| `؛؛ نص` | تعليق سطر كامل لا يُعرض | `؛؛ ملاحظة للمحرر` |
| `= عنوان` | عناوين بديلة عن `#` (من `=` إلى `======`) | `== قسم` |

داخل `[* … *]` أضف `؛:…:؛` أو `donate=(…)` / `pay=(…)` كجزء، وأضف `id=(…)` ليصبح الزر قابلاً للاستدعاء عبر `*"…"*`.

## أنواع إضافية

- **حاويات:** `فهرس`/toc (تلقائي من عناوين المستند)، `تغييرات`/changelog (`+` `~` `!` `-`)، `جدول-زمني`/timeline (`تاريخ: نص`)، `أسئلة`/faq (`س:` و`ج:` أو `Q:` و`A:`).
- **بلوكات `؛؛؛`:** `روابط` (`تسمية = رابط أو معرّف \| أيقونة`)، `شارات` (`تسمية: قيمة \| لون`)، `دعم` (سطر دفع لكل بند)، إضافة إلى `حقائق` و`meta` و`مراجع`.
- **استدعاء العنصر:** `*"id\|نص\|button"*` — الجزء الثالث `button` أو `soft` أو `outline` أو `solid` يحوّله إلى زر.
- **الدفع:** مزوّدو نسخ العنوان `btc eth usdt ltc sol xmr iban copy` (لا شبكة، النقر ينسخ)، و`wise` ضمن المزوّدين.

## أنواع `[نوع: قيمة]`

| النوع (وأسماؤه العربية) | الصيغة | الناتج |
|---|---|---|
| `tag`/وسم · `user`/مستخدم · `lib`/مكتبة | `[tag: rin]` `[user: ahmad]` `[lib: @u/x]` | وسم / رابط ناشر / رابط مكتبة |
| `key`/مفتاح | `[key: Ctrl+Shift+P]` | مفاتيح لوحة (تُقسم على `+`) |
| `cmd`/أمر · `copy`/نسخ | `[cmd: rin run x]` · `[copy: نص\|تسمية]` | زر ينسخ للحافظة |
| `file`/ملف · `date`/تاريخ · `time`/وقت · `size`/حجم | `[size: 2 MB]` | شريحة معلومة |
| `version`/إصدار · `license`/ترخيص · `price`/سعر · `lang`/لغة | `[lang: rin]` | شارة (اللغة بلون هويتها) |
| `platform`/منصة | `[platform: android\|linux\|web]` | شريحة لكل منصة |
| `badge`/شارة | `[badge: build\|passing\|green]` | شارة ثنائية بأسلوب shields |
| `status`/حالة + اختصارات `ok` `warn` `error` `info` `new` `beta` `stable` `deprecated` | `[status: ok\|يعمل]` · `[warn: تجريبي]` | شريحة حالة ملونة |
| `progress`/تقدم · `rating`/تقييم · `count`/عدد · `color`/لون | `[progress: 70\|الإنجاز]` `[rating: 4.5]` `[count: 15420\|تنزيلات]` `[color: #22C88E]` | شريط / نجوم / رقم مختصر / عيّنة لون |
| `icon`/أيقونة | `[icon: rocket\|نص]` | أيقونة + نص |
| `link`/رابط · `download`/تحميل · `email`/بريد · `phone`/هاتف | `[link: https://…\|نص]` | رابط / زر تحميل / بريد / اتصال |
| `video`/فيديو · `web`/ويب · `pay`/دفع · `abbr`/اختصار · `note`/ملاحظة | `[video: https://…\|عنوان]` `[pay: paypal\|user]` `[abbr: HTML\|لغة الويب]` | زر وسائط / دفع / تلميح عند النقر |
| `place`/مكان · `coords`/إحداثيات | `[place: الرياض\|24.7136,46.6753]` · `[place: 21.42,39.82]` · `[place: اسم]` | 📍 يفتح OpenStreetMap (https) بالإحداثيات أو ببحث الاسم |
| `flag`/علم · `country`/دولة | `[flag: SA\|السعودية]` | علم من رمز الدولة (حرفان) + اسم |
| `address`/عنوان · `zone`/توقيت | `[address: …]` · `[zone: Asia/Riyadh]` / `[zone: UTC+3]` | عنوان (النقر ينسخ) / منطقة زمنية |
| `dim`/أبعاد · `distance`/مسافة · `weight`/وزن · `temp`/حرارة · `percent`/نسبة | `[dim: 1920x1080 px]` `[distance: 5 km]` `[weight: 2 kg]` `[temp: 25°C]` `[percent: 80%]` | قياسات بوحدات مُتحقَّق منها |
| `size`/حجم | `[size: 2 MB]` أو `[size: 1920x1080]` | حجم ملف (B…TB) أو أبعاد |
| `hash`/بصمة | `[hash: 9fceb02d…]` | أول 8 خانات، النقر ينسخ الكامل |

قيمة غير صالحة لنوع معروف تظهر شريحة حمراء ويلتقطها `validate()`؛ نوع غير معروف يبقى نصاً كما كُتب.

## ستايل الأقواس

بعد قيمة أي قوس أضف `|key=(قيمة)`:

| المفتاح | القيم | الأثر |
|---|---|---|
| `size` | `xs` `sm` `md` `lg` `xl` `xxl` أو `50%`–`300%` (وعربياً: صغير/متوسط/كبير/ضخم) | يكبّر/يصغّر القوس كله (كل الأنواع) |
| `style` | `soft` `outline` `solid` `ghost` (خفيف/إطار/ممتلئ/شفاف) | نمط الشريحة |
| `color` | hex أو اسم لون | لون الشريحة |
| `shape` | `pill` `round` `square` (كبسولة/مدور/مربع) | انحناء الزوايا |
| `icon` · `pos` | اسم أيقونة · `start`/`end` | أيقونة ومكانها |

مثال: `[tag: rin|size=(lg)|style=(solid)|color=(#7C5CFF)|shape=(pill)|icon=(star)|pos=(end)]`. اللون والنمط والشكل والأيقونة تعمل على الأنواع المرسومة كشرائح (tag، user، lib، file، date، place، flag، dim، وغيرها)؛ الحجم يعمل على الجميع. خيار غير صالح يظهر شريحة حمراء ويلتقطه `validate()`.

## إعدادات الصفحة `؛؛؛ صفحة`

بلوك صامت (لا يُعرض) يتحكم بالصفحة كلها: الحجم والمساحة والخلفية والألوان والمحاذاة. المفاتيح تُقبل أيضاً داخل `؛؛؛ rdoc`، ولها أسماء عربية.

```text
؛؛؛ صفحة
background: #0F1115,#1C1E25
bg-dir: diag
theme: dark
font-size: lg
padding: 20 16
؛؛؛
```

| المفتاح (وعربيه) | القيم | الأثر |
|---|---|---|
| `background` (خلفية) | لون، أو 2–6 ألوان (تدرّج)، أو لوحة `forest`/`harbor`/`lagoon` | خلفية بطاقة الصفحة (تغلب `Page_background`) |
| `bg-dir` (اتجاه-الخلفية) | `down` `up` `right` `left` `diag` `diag-rev` (أسفل/أعلى/يمين/يسار/قطري) | اتجاه التدرّج |
| `theme` (سمة) | `light` `dark` `auto` | يفرض الثيم على الصفحة كلها (شرائح، حاويات، جداول) |
| `text-color` · `heading-color` · `link-color` (لون-النص/العناوين/الروابط) | hex أو اسم لون | ألوان النص والعناوين والروابط |
| `font-size` (حجم-الخط) | `xs` `sm` `md` `lg` `xl` `xxl` أو `10`–`32` أو `70%`–`200%` (صغير/متوسط/كبير/ضخم) | حجم خط الجسم |
| `line-height` (تباعد-الأسطر) | `1.0`–`3.0` | مضاعف تباعد الأسطر |
| `letter-spacing` (تباعد-الحروف) | `-0.05`–`0.5` | تباعد الحروف (em) |
| `padding` (مساحة، حشوة) | 1–4 قيم `0`–`64`dp كـCSS: الكل / رأسي أفقي / أعلى أفقي أسفل / أعلى يمين أسفل يسار | مساحة داخل الصفحة |
| `radius` (زوايا) · `border` (إطار) | `0`–`48` · `لون سماكة` مثل `#7C5CFF 2` | زوايا الصفحة وإطارها |
| `max-width` (أقصى-عرض) | `240`–`1200`dp | يحدّ عرض الصفحة ويوسّطها في الشاشات العريضة |
| `align` (محاذاة) | `start` `center` `end` `justify` (بداية/وسط/نهاية/ضبط) | محاذاة النص (`justify` يحتاج Android 8+) |
| `direction` (اتجاه) | `rtl` `ltr` `auto` | اتجاه النص |
| `font` (خط) | `sans` `serif` `mono` | عائلة الخط |

قيمة غير صالحة أو مفتاح مكرّر أو مجهول يلتقطها `validate()` بأرقام الأسطر. مفتاح غير مضبوط يبقى على افتراضي التطبيق.

## الشريط المتحرك (marquee)

شريط خاص بـrdoc (غير `[*نص/marquee*]` القديم): عدة عناصر تمرّ في حبّة واحدة، ويُوقَف/يُستأنف بالنقر.

```text
::: شريط speed=(60) style=(solid) color=(#7C5CFF) icon=(star)
إصدار جديد متاح الآن
دعم أكثر من 10 منصات
:::

[marquee: خبر 1|خبر 2|speed=(45)|style=(outline)]
```

كل سطر في الحاوية (أو كل جزء `|` في القوس) عنصر. الخيارات `key=(قيمة)` في رأس الحاوية أو بعد النص في القوس:

| الخيار | القيم | الافتراضي |
|---|---|---|
| `speed` | `5`–`400` (dp/ثانية) | `50` |
| `dir` | أفقي: `left`/`right` (يسار/يمين) · **رأسي: `up`/`down` (أعلى/أسفل)** — اتجاه حركة النص | `left` |
| `height` | `24`–`400`dp — ارتفاع الصندوق الرأسي (تلقائي: 3 أسطر للتمرير، سطر للخطوة) | تلقائي |
| `mode` | `scroll` تمرير مستمر · `step` عنصر واحد ينزلق للتالي (تمرير/خطوة) — للرأسي فقط | `scroll` |
| `hold` | `0.5`–`30` ثانية — مدة بقاء العنصر في وضع `step` | `2` |
| `style` · `color` · `icon` · `size` | كما في ستايل الأقواس | `soft` |
| `sep` | فاصل بين العناصر (حتى 6 محارف) | `•` |
| `width` | `120`–`1200`dp | عرض الصفحة تقريباً |
| `pause` | `tap` (يوقف/يستأنف بالنقر، النص يخفت أثناء الإيقاف) · `none` | `tap` |
| `link` | رابط https أو معرّف عنصر (`id=(…)`) — النقر يفتحه ويعطّل الإيقاف | لا شيء |

خيار غير صالح أو شريط فارغ أو حاوية غير مغلقة يظهر شريحة حمراء ويلتقطه `validate()`. الخيارات `height` و`mode` و`hold` تتطلب `dir=(up)` أو `dir=(down)`.

**الشريط الرأسي:** كل عنصر سطر مستقل داخل صندوق ثابت الارتفاع، يتوسّط أفقياً ويُقصّ بـ`…` إن طال.

```text
::: شريط dir=(up) height=(72) style=(solid) color=(#7C5CFF)
خبر عاجل أول
خبر ثانٍ
خبر ثالث
:::

::: شريط dir=(down) mode=(step) hold=(2) style=(outline) color=(#22C88E)
عرض اليوم
خصم 20%
:::

[marquee: نص 1|نص 2|نص 3|dir=(up)|height=(60)]
```

## ميزات الحزم والتوثيق

| الميزة | الصيغة | الأثر |
|---|---|---|
| بطاقة الحزمة | `؛؛؛ حزمة` بمفاتيح name/version/description/author/license/requires/platforms/keywords/repo/homepage/install (وعربيها) | بطاقة + تُغذّي `{{name}}` `{{version}}` |
| التبعيات | `؛؛؛ تبعيات` بأسطر `@user/lib = ^1.2 \| ملاحظة` | بطاقة؛ أسماء `@user/lib` روابط؛ القيود `*` `^` `~` `>=` `<=` `>` `<` `=` |
| توثيق دالة | `::: دالة sig` (api/fn/class/صنف) + `@param` `@return` `@throws` `@since` `@deprecated` `@see` `@example` | بطاقة مرتّبة، التوقيع بخط ثابت |
| فهرس الدوال | `::: فهرس-الدوال` | قائمة بتواقيع كل `::: دالة` |
| تثبيت | `::: تثبيت` (سطر = أمر قابل للنسخ؛ فارغة = `rin install <name>`) | أوامر بنقرة نسخ |
| مثال | `::: مثال عنوان` | بطاقة مثال |
| أقواس | `[since: 1.0]` `[requires: rin>=1.0]` `[dep: @u/lib@^1.2]` `[install: name]` `[author: @u]` `[repo: https://…\|نص]` | شرائح حزم |

**فحص `validate()` الإضافي:** حزمة بلا name/version أو بصيغ غير صالحة، repo/homepage غير https، تبعيات مكرّرة أو بقيود غير صالحة، `@param` غير موجود في التوقيع أو معامل بلا توثيق، توجيه `@` مجهول.
**واجهة برمجية:** `extractPackageInfo(text)` و`crossCheckPackage(text, manifestName, manifestVersion)` لمقارنة README بـ`package.rin.json`.

## فيديو يوتيوب `:;video …;:`

يدعم كل صيغ الروابط: `watch?v=` · `youtu.be/ID` · `shorts/ID` · `live/ID` · `embed/ID` · `playlist?list=` · `music.youtube.com`. وقت البدء يُقرأ من الرابط (`?t=1m30s` أو `&start=90` أو `#t=2m`). المعرّف يجب أن يكون 11 خانة، وإلا ظهر خطأ.

```text
:;video https://youtu.be/ID?t=1m30s|عنوان|thumb=(true)|captions=(true)|lang=(ar)|end=(2:30);:
```

| الخيار | القيم | الافتراضي |
|---|---|---|
| `start` · `end` | `90` `90s` `1m30s` `1h2m3s` `1:30` `1:02:03` (ويجب `end` > `start`) | من الرابط · — |
| `autoplay` | `true`/`false` (نعم/لا) — يعمل بعد نقر الملصق | `true` |
| `mute` · `loop` · `controls` | `true`/`false` | `false` · `false` · `true` |
| `captions` · `lang` | ترجمة تلقائية · لغة الواجهة والترجمة (`ar` `en` `pt-br`) | `false` · — |
| `related` | `false` = مقاطع القناة نفسها فقط | `false` |
| `privacy` | `nocookie` (youtube-nocookie) · `standard` | `nocookie` |
| `thumb` | `true` يجلب الصورة المصغّرة من `i.ytimg.com` (اختياري؛ الافتراضي لا شبكة قبل النقر) | `false` |
| `ratio` | `16:9` `4:3` `9:16` `1:1` `21:9` أو رقم `0.4`–`3` | `16:9` (وshorts `9:16`) |
| `height` | `120`–`640`dp (بديل عن النسبة) | — |

- الارتفاع يُحسب من النسبة الحقيقية للعرض؛ shorts يظهر عمودياً بعرض 300dp.
- المشغّل: ↗ فتح في يوتيوب (بوقت البدء)، ✕ إغلاق، ملء الشاشة، ويتوقف ويُدمَّر عند مغادرة الشاشة (لا صوت خلفي).
- الصفحة تُحمَّل عبر iframe بأصل https وسياسة referrer صحيحة (تفادي خطأ 153)؛ إن فشل التحميل يظهر بديل «افتح الرابط».
- داخل الفقرة: زر «▶ العنوان · 1:30» يفتح الرابط بوقت البدء.
- خيارات يوتيوب على مضيف آخر تعطي خطأ «لروابط يوتيوب فقط»، ويلتقط `validate()` كل ذلك بالسبب.

## الحدود الصارمة

- عمق الحاويات ≤ 4، حجم المستند ≤ 400,000 حرف (يُقتطع مع تنبيه).
- `؛؛؛` غير المغلق ينتهي عند أول سطر فارغ (لا يبتلع بقية المستند)؛ `:::` غير المغلق يُعلَّم بخطأ.
- الدفع والوسائط: **https فقط**. مزوّد معروف مع رابط كامل يجب أن يطابق مضيفه؛ `url` يقبل أي https.
- زر الدفع يعرض المضيف الحقيقي، والنقر يفتح **نافذة تأكيد** قبل الانتقال.
- الفيديو: لا شبكة قبل النقر؛ WebView بلا وصول ملفات ولا محتوى مختلط؛ JavaScript فقط لمضيفي فيديو موثوقين (YouTube/Vimeo/Dailymotion)؛ التنقل محصور في مضيف التضمين.
- `DocumentationContainer.validate(text)` يفحص المستند ويعيد قائمة أخطاء بأرقام الأسطر: أسوار، مراجع مفقودة، معرّفات مكرّرة، دفع/وسائط غير صالحة.
