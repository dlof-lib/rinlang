# وثيقة rdoc الشاملة — Documentation Container

المرجع الكامل للغة توثيق الحزم `README.rdoc`. للاطلاع السريع على الصيغ راجع [`rdoc.md`](./rdoc.md)، ولنموذج يعمل [`rdoc/README.rdoc`](./rdoc/README.rdoc).

## 1. المفهوم

rdoc لهجة توثيق مستقلة عن Markdown تُعرَض داخل Rin عبر `DocumentationContainer`. تضيف لـMarkdown حاويات تخطيط، بلوكات بيانات، استدعاء روابط، دفع وتبرّع، فيديو، أقواس بأنواع، إعدادات صفحة، شريطاً متحركاً، وميزات خاصة بالحزم وتوثيق الدوال.

مبادئ ثابتة:

- **الفتح والإغلاق متناظران:** كل رمز له بداية ونهاية.
- **الخطأ مرئي:** أي قيمة أو بنية غير صالحة تظهر شريحة حمراء بدل أن تُبتلع.
- **آمن افتراضياً:** https فقط للدفع والوسائط، وتأكيد قبل أي رابط دفع، وحدود صارمة (القسم 12).
- **متوافق للخلف:** بدون الترويسة يبقى المستند Markdown خالصاً.

## 2. التفعيل

يبدأ المستند بترويسة، وتُضاف تلقائياً لأي `README.rdoc` داخل الحزم:

```text
؛؛؛ rdoc
title: اسم المكتبة
version: 1.0.0
؛؛؛
```

مفاتيح هذا البلوك (`title` و`version`…) تصبح متغيّرات `{{title}}` و`{{version}}`. في حزمة تحتوي README.md وREADME.rdoc معاً يتقدّم `README.rdoc`.

## 3. الرموز

| الرمز | الوظيفة |
|---|---|
| `:::` … `:::` | حاويات تخطيط متداخلة |
| `؛؛؛` … `؛؛؛` | بلوكات بيانات |
| `*"…"*` | استدعاء رابط عنصر |
| `؛:` … `:؛` | دفع وتبرّع |
| `:;` … `;:` | فيديو وويب فيو |
| `[نوع: قيمة]` | أقواس بأنواع وستايل |
| `{{مفتاح}}` | متغيّر من بلوك `meta` (`\{{x}}` حرفية) |
| `؛؛ نص` | تعليق سطر كامل لا يُعرض |
| `== عنوان` | عناوين بديلة عن `#` (من `=` إلى `======`) |

## 4. الحاويات `:::`

الصيغة: `::: نوع عنوان` ثم الجسم ثم `:::`. أي `:::` (بثلاث نقاط رأسية أو أكثر) يغلق أقرب حاوية، فيمكن استخدام `:::::` للخارجية للوضوح. عمق التعشيش الأقصى 4.

| النوع (وأسماؤه) | الاستخدام |
|---|---|
| `note`/ملاحظة · `tip`/نصيحة · `important`/مهم · `warning`/تحذير · `danger`/خطر · `success`/نجاح · `quote`/اقتباس | بطاقات تنبيه ملوّنة |
| `card`/بطاقة | بطاقة محايدة؛ نوع مجهول يظهر كبطاقة مع علامة خطأ |
| `steps`/خطوات | قائمة تُرقَّم تلقائياً |
| `spoiler`/مخفي/طي | قسم قابل للطي |
| `toc`/فهرس | فهرس تلقائي من عناوين المستند (`#` و`=`) |
| `changelog`/تغييرات | سطر `+` أضيف · `~` عُدّل · `!` أُصلح · `-` حُذف |
| `timeline`/جدول-زمني | سطر `تاريخ: نص` أو `مرحلة \| نص` |
| `faq`/أسئلة | `س:` سؤال و`ج:` جواب (أو `Q:` و`A:`) |
| `api`/دالة/صنف · `api-index`/فهرس-الدوال · `install`/تثبيت · `example`/مثال | توثيق الحزم (القسم 9) |
| `marquee`/شريط | الشريط المتحرك (القسم 8) |

## 5. بلوكات البيانات `؛؛؛`

يُغلق البلوك بـ`؛؛؛` أو بأول سطر فارغ (فلا يبتلع نسيانُ الإغلاق بقية المستند). أسطر تبدأ بـ`؛؛` تُهمَل داخله.

| البلوك | المحتوى | الظهور |
|---|---|---|
| `rdoc` / `meta` / `بيانات` | `مفتاح: قيمة` — يغذّي `{{مفتاح}}` | صامت |
| `مراجع` / `refs` | `معرّف = رابط \| تسمية` — تعريفات لـ`*"معرّف"*` | صامت |
| `صفحة` / `page` | إعدادات الصفحة (القسم 7) | صامت |
| `حقائق` | `مفتاح: قيمة` | بطاقة |
| `روابط` | `تسمية = رابط أو معرّف \| أيقونة` | أزرار |
| `شارات` | `تسمية: قيمة \| لون` | شارات ثنائية |
| `دعم` | سطر دفع/تبرّع لكل بند | أزرار دفع |
| `حزمة` / `package` | بطاقة الحزمة (القسم 9) | بطاقة |
| `تبعيات` / `deps` | تبعيات بقيود إصدار (القسم 9) | بطاقة |

## 6. العناصر السطرية

### استدعاء العنصر `*"…"*`

يستدعي رابطاً معرَّفاً في مكان آخر: بـ`id=(…)` داخل `[* *]`، أو في بلوك `مراجع`، أو مباشرة `@user` / `@user/lib` (روابط Rin القانونية).

| الصيغة | الناتج |
|---|---|
| `*"repo"*` | رابط بتسمية العنصر |
| `*"repo\|نص"*` | رابط بنص مخصص |
| `*"repo\|نص\|button"*` | زر (`button` أو `soft` أو `outline` أو `solid`) |

معرّف غير معروف يظهر «مرجع مفقود».

### الدفع والتبرّع `؛: … :؛`

`مزوّد|هدف[|مبلغ عملة][|نص][|type=(donate|pay|subscribe)]` — الهدف اسم مستخدم أو رابط https. المزوّدون: `paypal` `patreon` `kofi` `coffee` `github` `liberapay` `opencollective` `wise` و`url` (أي رابط https). مزوّدو نسخ العنوان `btc eth usdt ltc sol xmr iban copy`: بلا شبكة، والنقر ينسخ القيمة.

يعمل داخل `[* … *]` أيضاً: `[*ادعمنا/؛:paypal|user|5 USD:؛*]` أو `[*تبرّع/donate=(patreon|user)*]`. الزر يعرض المضيف الحقيقي، والنقر يفتح نافذة تأكيد.

### الفيديو `:; … ;:`

`[video|web] https://…[|عنوان][|key=(قيمة)…]`. على سطر مستقل: مشغّل بملصق تشغيل (لا شبكة قبل النقر)، وداخل فقرة: زر يفتح الرابط. JavaScript مسموح لمضيفي الفيديو الموثوقين فقط (YouTube وVimeo وDailymotion)، والتنقل الرئيسي محصور بمضيف التضمين.

**يوتيوب الاحترافي** (تفاصيل كل الخيارات في [`rdoc.md`](./rdoc.md)):

- صيغ الروابط: `watch` · `youtu.be` · `shorts` · `live` · `embed` · `playlist` · `music.youtube.com`؛ وقت البدء من الرابط (`?t=1m30s`).
- خيارات: `start` `end` `autoplay` `mute` `loop` `captions` `lang` `related` `controls` `privacy` `thumb` `ratio` `height`.
- نسبة أبعاد حقيقية (16:9، وshorts بـ9:16)، وملصق بزر تشغيل أحمر، وصورة مصغّرة اختيارية (`thumb=(true)`).
- ↗ فتح في يوتيوب، ✕ إغلاق، ملء الشاشة، وإيقاف المشغّل عند مغادرة الشاشة.
- الخصوصية افتراضياً عبر `youtube-nocookie.com`، وتحميل عبر iframe بأصل https صحيح.
- معرّف غير صالح، `end` قبل `start`، أو خيار يوتيوب على رابط آخر: خطأ مرئي ويلتقطه `validate()`.

## 7. الأقواس `[نوع: قيمة]`

| الفئة | الأنواع |
|---|---|
| وسوم وأشخاص | `tag`/وسم · `user`/مستخدم · `lib`/مكتبة · `author`/ناشر |
| نصوص وأوامر | `key`/مفتاح (`Ctrl+S` تُقسم) · `cmd`/أمر · `copy`/نسخ · `file`/ملف · `abbr`/اختصار · `note`/ملاحظة |
| معلومات | `date` · `time` · `size` (حجم أو أبعاد) · `version` · `license` · `price` · `lang` · `platform` · `hash` · `icon` · `count` · `color` · `rating` · `progress` |
| حالات | `status` + اختصارات `ok` `warn` `error` `info` `new` `beta` `stable` `deprecated` |
| روابط | `link` · `download` · `email` · `phone` · `video` · `web` · `pay` · `repo` · `badge` |
| أماكن وقياسات | `place`/`coords` (📍 OpenStreetMap) · `flag`/`country` · `address` · `zone` · `dim` · `distance` · `weight` · `temp` · `percent` |
| حزم | `since` · `requires` · `dep` · `install` |
| حركة | `marquee`/شريط |

كل نوع له أسماء عربية (مثل `وسم` و`مكان` و`أبعاد`). قيمة غير صالحة لنوع معروف تظهر شريحة حمراء؛ نوع غير معروف يبقى نصاً.

### ستايل الأقواس

بعد القيمة: `|key=(قيمة)`.

| المفتاح | القيم |
|---|---|
| `size` | `xs` `sm` `md` `lg` `xl` `xxl` أو `50%`–`300%` |
| `style` | `soft` `outline` `solid` `ghost` |
| `color` | hex أو اسم لون |
| `shape` | `pill` `round` `square` |
| `icon` · `pos` | اسم أيقونة · `start`/`end` |

مثال: `[tag: rin|size=(lg)|style=(solid)|color=(#7C5CFF)|shape=(pill)]`. الحجم يعمل على كل الأنواع؛ البقية على الأنواع المرسومة كشرائح.

## 8. الصفحة والشريط المتحرك

### إعدادات الصفحة `؛؛؛ صفحة`

```text
؛؛؛ صفحة
background: #0F1115,#1C1E25
bg-dir: diag
theme: dark
font-size: lg
line-height: 1.7
padding: 20 16
radius: 24
border: #7C5CFF 1
max-width: 720
؛؛؛
```

| المفتاح | القيم |
|---|---|
| `background` | لون، أو 2–6 ألوان، أو `forest`/`harbor`/`lagoon` |
| `bg-dir` | `down` `up` `right` `left` `diag` `diag-rev` |
| `theme` | `light` `dark` `auto` |
| `text-color` `heading-color` `link-color` | ألوان |
| `font-size` | `xs`–`xxl` أو `10`–`32` أو `70%`–`200%` |
| `line-height` · `letter-spacing` | `1.0`–`3.0` · `-0.05`–`0.5` |
| `padding` | 1–4 قيم `0`–`64` (كـCSS) |
| `radius` · `border` | `0`–`48` · `لون سماكة` |
| `max-width` | `240`–`1200` |
| `align` · `direction` · `font` | `start/center/end/justify` · `rtl/ltr/auto` · `sans/serif/mono` |

للمفاتيح أسماء عربية (خلفية، مساحة، حجم-الخط، محاذاة…) وتُقبل أيضاً داخل `؛؛؛ rdoc`.

### الشريط المتحرك

```text
::: شريط speed=(60) style=(solid) color=(#7C5CFF) icon=(star)
إصدار جديد متاح الآن
دعم أكثر من 10 منصات
:::

::: شريط dir=(up) height=(72) style=(outline)
خبر 1
خبر 2
:::

[marquee: نص 1|نص 2|dir=(down)|mode=(step)|hold=(2)]
```

| الخيار | القيم | الافتراضي |
|---|---|---|
| `speed` | `5`–`400` dp/ث | `50` |
| `dir` | أفقي `left`/`right` · رأسي `up`/`down` | `left` |
| `style` `color` `icon` `size` | كستايل الأقواس | `soft` |
| `sep` | فاصل (حتى 6 محارف) | `•` |
| `width` | `120`–`1200` | عرض الصفحة |
| `height` `mode` `hold` | رأسي فقط: `24`–`400` · `scroll`/`step` · `0.5`–`30` ث | تلقائي · `scroll` · `2` |
| `pause` | `tap` (نقر يوقف/يستأنف) · `none` | `tap` |
| `link` | رابط https أو معرّف عنصر (يعطّل الإيقاف) | — |

## 9. توثيق الحزم والدوال

### بطاقة الحزمة

```text
؛؛؛ حزمة
name: example-lib
version: 1.0.0
description: وصف قصير.
author: @example
license: MIT
requires: rin>=1.0
platforms: android, linux, web
keywords: media, embed
repo: https://github.com/dlof-lib/rinlang
؛؛؛
```

`name` و`version` إلزاميان (`version` بصيغة `1.2.3` أو `v2` أو `1.0.0-beta.1`). `repo` و`homepage` https فقط. إن غاب `install` يُستنتج `rin install <name>`. المفاتيح تصبح متغيّرات: `{{name}}` `{{version}}`.

### التبعيات

```text
؛؛؛ تبعيات
@example/core = ^1.2 | النواة
json-utils = >=1.0
؛؛؛
```

القيود: `*` أو `1.2.3` أو مع `^` `~` `>=` `<=` `>` `<` `=`. أسماء `@user/lib` تصبح روابط.

### توثيق دالة

````text
::: دالة example_open(url, title)
تفتح رابط وسائط وتعيد صفحة HTML.

@param url (نص): رابط الوسائط
@param title: عنوان الصفحة
@return: نص HTML
@throws: unsupported
@since: 1.0
@example
```rin
warp page = example_open(link, "عرض");
```
:::
````

التوجيهات: `@param` (`اسم (نوع): وصف`) · `@return`/`@returns` · `@throws` · `@since` · `@deprecated` · `@see معرّف` · `@example` (ولها أسماء عربية: معامل، يعيد، يرمي، منذ، متوقف، انظر، مثال). يقارن الفحص `@param` بمعاملات التوقيع. `::: فهرس-الدوال` يجمع كل التواقيع، و`::: تثبيت` يعرض أوامر قابلة للنسخ.

## 10. الفحص `validate()`

يعيد `List<RdocIssue>` بحقول `line` و`severity` (`error`/`warning`) و`message`، ويغطي:

- أسوار: `:::` أو `؛؛؛` غير مغلقة أو زائدة، أنواع مجهولة، عمق يتجاوز 4، حجم المستند.
- مراجع `*"…"*` مفقودة، ومعرّفات `id` مكرّرة.
- دفع ووسائط غير صالحة أو غير https، وأقواس بقيم غير صالحة أو خيارات ستايل خاطئة.
- إعدادات الصفحة (قيمة خاطئة، مفتاح مجهول أو مكرّر) وخيارات الشريط.
- الحزمة والتبعيات وتوثيق الدوال (القسم 9).

## 11. الدمج البرمجي

| الدالة | الغرض |
|---|---|
| `isRdocDocument(text)` · `ensureRdocHeader(text)` | كشف اللهجة وإضافة الترويسة |
| `splitReadmeSegments(md)` | يقسّم المستند لنصوص وجداول ومعاينات ووسائط |
| `applyTo(textView, md, …, rdoc = true)` | يرسم مقطعاً نصياً |
| `buildTableView(ctx, table, top, rdoc)` · `buildMediaView(ctx, media, top)` | جداول ومشغّل الوسائط |
| `extractMeta(md)` · `extractPageSettings(md)` · `applyPageContainer(view, page)` | بيانات الصفحة وتطبيقها على الحاوية |
| `extractPackageInfo(md)` · `crossCheckPackage(md, name, version)` | معلومات الحزمة ومقارنتها بـ`package.rin.json` |
| `validate(md)` | الفحص الكامل |

شاشة الحزمة تفعّل rdoc تلقائياً عند وجود الترويسة، وتطبّق `؛؛؛ صفحة` على بطاقة README.

## 13. من Markdown إلى rdoc

| Markdown | rdoc |
|---|---|
| `> **Note**` | `::: ملاحظة` … `:::` |
| قائمة مرقّمة للتثبيت | `::: خطوات` أو `::: تثبيت` |
| جدول للدوال | `::: دالة توقيع` مع `@param` |
| `[نص](رابط)` مكرر | `*"id"*` مرة واحدة التعريف |
| صورة شارات shields | `؛؛؛ شارات` أو `[badge: a\|b\|green]` |
| رابط تبرع عادي | `؛:paypal\|user:؛` |
| رابط يوتيوب | `:;video https://youtu.be/ID;:` |
