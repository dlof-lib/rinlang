> الصفحة الرسمية لكل ما يخص **الجمل الشرطية** والحلقات التكرارية في Rin 1.0.
> راجع أيضاً: [`syntax.md`](./syntax.md) للقواعد العامة، [`variables.md`](./variables.md)
> للتعرّف على المتغيرات المستخدمة داخل الشروط، [`functions.md`](./functions.md)
> لاستخدام `return` داخل الشروط، و[`language-reference.md`](./language-reference.md)
> كخريطة شاملة تربط كل هذه المفاهيم.

## 1) العامل الأساسي للشرط: `if` / `else`

```rin
if (x > 5) {
    print "big";
} else {
    print "small";
}
```

- الشرط `(condition)` يُقيَّم كتعبير منطقي (انظر [العوامل](#4-عوامل-المقارنة-والمنطق) أدناه).
- الفرع `else` اختياري تماماً.
- بما أنّ `else` يقبل أي **جملة** (statement) وليس فقط كتلة `{}`، يمكن تسلسل عدة شروط
  عبر `else if` لبناء سلسلة قرارات:

```rin
if (score >= 90) {
    print "ممتاز";
} else if (score >= 75) {
    print "جيد جداً";
} else if (score >= 60) {
    print "جيد";
} else {
    print "راسب";
}
```

## 1.1) الصيغة الإنجليزية المبسّطة (سهلة التعلّم): `when ... otherwise ...`

```rin
when (x > 5) {
    print "big";
} otherwise {
    print "small";
}
```

`when (condition) { ... } otherwise { ... }` مطابقة تماماً لـ
`if (condition) { ... } else { ... }` — نفس السلوك بالضبط، بلا أي فرق في المعنى؛
الفرق صياغي بحت لصالح من يتعلّم البرمجة لأول مرة عبر جملة إنجليزية طبيعية
("when x is greater than 5" = "عندما يكون x أكبر من 5"). الفرع `otherwise`
اختياري تماماً تماماً كـ `else`:

```rin
when (age >= 18) { print "بالغ"; }
```

ويمكن مزج الشكلين بحرّية داخل نفس البرنامج، بما أن كليهما ينتجان بالضبط نفس
الجملة الشرطية داخلياً:

```rin
if (x > 5) { print "big"; } else { print "small"; }     // if/else
when (x > 5) { print "big"; } otherwise { print "small"; } // when/otherwise -- نفس النتيجة تماماً
```

`when` و`otherwise` كلمتان **غير محجوزتين**: يمكن استخدامهما كأسماء متغيّرات
عادية في أي مكان آخر؛ تُفهم `when` كصياغة `if` فقط عند ظهورها مباشرة قبل `(`
في بداية عبارة.

> ملاحظة: هذه الصيغة تكمّل `if/else` ولا تلغيه؛ لسلاسل `else if` طويلة يبقى
> `if/else` (القسم 1 أعلاه) هو الأنسب حتى تكتمل صياغة `when/otherwise if` لاحقاً.

## 2) الشرط الثلاثي على مستوى الجملة: `plus.condition`

بديل صريح لـ `if/else` عندما تريد التعبير عن "قيمتين بديلتين" بأسلوب مضغوط، وكلتا
الكتلتين إلزاميتان (لا يوجد `plus.condition` بلا فرع بديل):

```rin
plus.condition (x > 5) {
    print "big";
} / {
    print "small";
}
```

استخدمه عندما يكون القرار ثنائياً بحتاً (لا سلسلة `else if`)؛ استخدم `if/else` العادية
لأي منطق أعقد. كلا الشكلين يتشاركان نفس عوامل المقارنة والمنطق أدناه.

## 3) الحلقات التكرارية

### `while`

```rin
let i = 0;
while (i < 5) {
    print i;
    i = i + 1;
}
```

`while` تكرّر جسمها طالما شرطها صحيح — هذا هو الرابط المباشر بين مفهوم **الشرط**
ومفهوم **التكرار**: أي تعبير منطقي صالح داخل `if` صالح أيضاً داخل `while`.

`rinopen (condition) { ... }` اسم بديل مطابق لـ `while` بفارق واحد: جسمها كتلة `{}`
إلزامية دائماً.

### `for`

حلقة على طراز C: تهيئة؛ شرط؛ زيادة — وتُبنى داخلياً من نفس عناصر `let` و`while`:

```rin
for (let i = 0; i < count; i = i + 1) {
    print i;
}
```

وهو شكل مكافئ تماماً لِـ:

```rin
let i = 0;
while (i < count) {
    print i;
    i = i + 1;
}
```

مما يوضّح كيف أن `for` و`while` و`let` مترابطة بنيوياً في اللغة، وليست مفاهيم منفصلة.

### `break` و `continue`

```rin
while (i < 10) {
    if (i == 5) { break; }      // خروج فوري من أقرب حلقة while محيطة
    if (i % 2 == 0) { i = i + 1; continue; } // تخطّي باقي الجسم والعودة لفحص الشرط
    print i;
    i = i + 1;
}
```

`break`/`continue` تعملان فقط داخل جسم حلقة (`while`/`for`)، ويكثر استخدامهما مع
شرط `if` داخلي لتحديد متى يُقطع أو يُتخطّى التكرار — رابط مباشر آخر بين
**الشروط** و**الحلقات**.

## 4) عوامل المقارنة والمنطق

هذه العوامل هي "لغة" كل شرط في اللغة (`if`, `plus.condition`, `while`, `for`):

| العامل | المعنى |
|---|---|
| `==` | يساوي |
| `!=` | لا يساوي |
| `<` `<=` `>` `>=` | مقارنة عددية |
| `and` | و منطقي (تقييم كسول: يتوقف إن كان الطرف الأيسر خاطئاً) |
| `or` | أو منطقي (تقييم كسول: يتوقف إن كان الطرف الأيسر صحيحاً) |
| `!` | نفي منطقي |

```rin
if (age >= 18 and hasId) {
    print "مسموح";
}

if (!isReady or retries > 3) {
    print "أعد المحاولة لاحقاً";
}
```

## 5) الشرط كقيمة تُستخدم مع بقية اللغة

القيمة الناتجة عن أي تعبير مقارنة (مثل `x > 5`) هي قيمة عادية من نوع منطقي، ويمكن
تخزينها في متغيّر بـ [`let`](./variables.md#1-تعريف-متغيّر-let) واستخدامها لاحقاً:

```rin
let isAdult = age >= 18;
if (isAdult) { print "بالغ"; }
```

وبما أن الشروط تُستخدم أيضاً داخل [الدوال](./functions.md) لاتخاذ قرار `return`
(كما في `fib`)، وداخل [الحاويات](./containers.md) والخطوط الأنبوبية
([`pipelines.md`](./pipelines.md)) لتصفية أو توجيه البيانات، فإن الشروط تمثّل
حلقة الوصل بين كل مفاهيم Rin الأخرى وليست ميزة معزولة.
