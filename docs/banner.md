# Banner

Banner مفهوم واجهة/تشغيل (UI/runtime) للإشعارات المعلوماتية، النجاح، التحذير،
الخطأ، والإجراءات. يُستخدم عادة كنتيجة لتقييم [شرط](./control-flow.md) داخل
[حاوية](./containers.md) أو [دالة](./functions.md) (مثال: إظهار بانر خطأ عند
فشل شرط تحقّق).
