# عائلة `#` — مفاهيم ودوال جديدة تبدأ بعلامة `#`

إضافة اختيارية بالكامل (additive): لم يتغيّر أي كود قديم، لأن `#` وحدها كانت خطأ في المحلّل قبل ذلك.
كل مفهوم/دالة/متغيّر جديد يبدأ بـ `#` ملاصقة للاسم. أي `#اسم` آخر يصلح اسم متغيّر: `let #total = 0;`.

## الحلقات

| الصيغة | المعنى |
|---|---|
| `#for (...) { }` · `#while (...) { }` · `#return v;` | مرادفات كاملة لـ `for` و`while` و`return` |
| `#for (let i #in 1 #to 4) { }` | مدى شامل للطرفين: 1 2 3 4 |
| `... #to 4 step 3` | خطوة بمقدار 3؛ الاتجاه يُستنتج من الطرفين (`10 #to 4 step 3` ← 10 7 4) |
| `#do { } #while (شرط);` | تنفّذ الجسم مرة على الأقل؛ `continue` تنتقل لفحص الشرط |
| `#done;` | خروج مبكر من أقرب حلقة (مثل `break`) |
| `#while (..) { } #done { }` | كتلة تُنفَّذ إذا انتهت الحلقة طبيعياً دون `break`/`#done;` (تعمل مع `while` و`for` و`for..in` و`#do`) |

## الدوال

- `#sed(نص, "s/قديم/جديد/g")` أو `#sed(نص, نمط, بديل[, "gi"])`: الافتراضي أول تطابق، `g` كل التطابقات، `i` تجاهل الحالة. في البديل: `&` التطابق كله، `\1..\9` المجموعات. تقبل مصفوفة نصوص أيضاً.
- `#sum(a, b, [..], {..})`: مجموع أرقام ومصفوفات وقيم قواميس متداخلة. `[1,2] |> #sum` تعمل في الأنابيب. `sum` القديمة بلا تغيير.
- `#diff(a, b)`: أرقام ← `a - b`. مصفوفات ← عناصر `a` الغائبة من `b`. قواميس ← `{مفتاح: [قيمة_a, قيمة_b]}` للمفاتيح المختلفة (`nil` للغائب).
- `#add(هدف, ...)`: أرقام ← مجموع. نص ← دمج. مصفوفة ← تضيف في مكانها. قاموس ← `#add(map, key, value)` أو `#add(map, otherMap)`.
- `#to(من, إلى[, خطوة])`: مصفوفة المدى الشامل.
- `#swap a, b;` أو `#swap(a, b);`: يبدّل متغيّرين أو `arr[i], arr[j]` أو `obj.f` فعلاً (يُفكَّك إلى `[a, b] = [b, a];` فيحترم `#ban` والمتغيرات الحيّة). `#swap(arr, i, j)` تبدّل عنصرين في مصفوفة (فهرس سالب مسموح) أو مفتاحين في قاموس، و`#swap(a, b)` كتعبير تُرجع `[b, a]`.

## المنع والتجاهل

- `#ban x;` · `#ban x, y;` يمنع أي كتابة لاحقة على متغيّر موجود وعلى محتواه المباشر (`x[i] =` و`x.f =`)؛ القراءة تبقى. الخطأ `E0043`. لا رجعة فيه.
- `#ban x = 5;` يعلن متغيّراً ممنوع التعديل من البداية.
- `#ignorance { ... }` أو `#ignorance عبارة` تتجاهل أي خطأ وقت التشغيل داخلها وتكمل البرنامج بصمت (`try { } catch { }` مختصر). `return` و`break` و`continue` تعمل عبرها كالمعتاد.

## الأخطاء

`#done { }` بعد غير حلقة، `#done;` خارج حلقة، `#do` بلا `#while`، `#swap` بلا هدفين: كلها أخطاء نحوية واضحة (E0011/E0012/E0013). أخطاء الأنواع في الدوال E0004 وبياناتها E0007/E0035.
