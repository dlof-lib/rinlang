# الأسهم والتبديل واختصار الخريطة وشكل القوائم

كلها **إضافات بحتة**: كل صيغة كانت خطأ بناء سابقاً، فلا يتغيّر أي كود موجود.

| الصيغة | المعنى | مثال |
|---|---|---|
| `a <== expr` | إسناد (مرادف حرفي لـ `=`) | `a <== 5;` |
| `expr ==> target` | إسناد معكوس، ويتسلسل | `a + 1 ==> b;` · `7 ==> a ==> b;` |
| `a <=> b` · `{a <=> b}` | تبديل القيمتين (≡ `[a, b] = [b, a]`) | `arr[0] <=> arr[2];` |
| `{X, A}` | خريطة بأسماء المتغيّرات مفتاحاً وقيمة (≡ `{X: X, A: A}`) | `{X, A: 9}` |
| `{{"[, ]"}}` | يضبط شكل طباعة القوائم: فتح، فاصل، إغلاق (≡ `listFormat("[, ]")`) | `{{"(, )"}}` ← `(1, 2, 3)` |

- **الأهداف المسموحة** في `==>` و`<=>`: متغيّر · `arr[i]` · `obj.field`.
- `{a <=> b}` بلا `;` داخلية تُقرأ تبديلاً؛ مع `;` تبقى كتلة عادية.
- **`{X, X}` و`{A,A}`**: المفتاح المكرّر يبقى مرة واحدة (آخر قيمة تغلب) → `{X: 1}`، ولا خطأ.
- **`{{"..."}}`** على سطر واحد؛ الفتح قبل أول فاصلة، ثم الفاصلة مع مسافاتها فاصلاً، والباقي إغلاقاً.
  `{{"[, ]"}}` يعيد الافتراضي. تؤثر في طباعة القوائم فقط (لا الخرائط). `listFormat(open, sep, close)` تعيد الشكل السابق نصاً.
