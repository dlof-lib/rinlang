# التخزين (Storage)

واجهات التخزين توفّر قدرات بيانات دائمة (persistent) يعرضها runtime الخاص بـ Rin،
وتُستخدم غالباً لحفظ نتيجة [حاوية](./containers.md) عبر `file`/`save`
(انظر [`containers.md`](./containers.md#1-حاوية-بيانات-container)) أو لتخزين
[كائنات](./objects.md)/مستندات NoSQL.
