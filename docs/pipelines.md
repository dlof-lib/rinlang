# pipelines.md — عامل الأنابيب `|>`

## الفكرة
`a |> f` تعني "مرِّر قيمة `a` كأول وسيط لِـ `f`" — يعادل تمامًا `f(a)`. يمكن سلسلة
عدة مراحل:
```rin
fun myDouble(x) { return x * 2; }
fun addOne(x) { return x + 1; }
print 5 |> myDouble |> addOne; // 11  == addOne(myDouble(5))
```
`f` يمكن أن تكون دالة مُعرَّفة من المستخدم أو دالة أصلية (native) — كلاهما يُستدعى
عبر نفس آلية الاستدعاء العادية.

## تمرير وسائط إضافية
إن احتاجت المرحلة وسائط إضافية غير القيمة القادمة من قبلها، تُكتب بين قوسين بعد
اسمها — القيمة القادمة من المرحلة السابقة تُقحَم تلقائيًا كأول وسيط:
```rin
let nums = [10, 20, 30, 5, 40];
fun filter(arr, pred) { let out = []; let i = 0; while (i < len(arr)) { if (pred(arr[i])) { push(out, arr[i]); } i = i + 1; } return out; }
fun isAdult(x) { return x > 18; }
print nums |> filter(isAdult); // [20, 30, 40]  == filter(nums, isAdult)
```

## العلاقة بـ `reckon`
`reckon` (انظر [`RECKON.md`](./RECKON.md)) هو صياغة مختصرة بسطرين مبنية فوق نفس
عامل `|>` بالضبط لعمليات إحصائية/تجميعية شائعة على مصفوفة واحدة — لا تحتاج
دوال `filter`/`map` مكتوبة يدويًا كما أعلاه.

## العلاقة بـ RinFlow
تشغيل برنامج عاديًا (عبر `print`/`Interpreter::run`) ينفِّذ سلسلة `|>` مباشرة بلا أي
تتبّع إضافي. تشغيله عبر `Interpreter::runProgramAsFlow(...)` (طبقة استضافة
اختيارية، انظر [`rinflow.md`](./rinflow.md)) يُنتج بالإضافة إلى ذلك رسمًا بيانيًا
(Graph) بمرحلة لكل حلقة `|>`، بلا أي تغيير في نتيجة الحساب نفسها.
