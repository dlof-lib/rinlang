# runtime.md — وقت تشغيل Rin (Rin Runtime) · المرجع الرسمي

> هذه الصفحة هي المرجع الرسمي لكيفية عمل وقت تشغيل Rin: بنيته، نموذج التنفيذ، الحدود والضمانات،
> التحسينات المضمونة، وطرق تضمينه. كل رقم هنا قيس على المفسِّر الحقيقي؛ ما لم يُقَس ذُكر صراحةً
> تحت «حدود معروفة». التفاصيل التاريخية للتقوية في [`runtime-hardening.md`](./runtime-hardening.md).

## 1. البنية

```
 مصدر .rin ──► Lexer ──► Parser ──► AST ──► Interpreter ──► النتيجة / RinError
 (rin_lexer)   (rin_parser)  (rin_ast.h)   (rin_interpreter)
                                   │
                                   └─► تشخيصات منسَّقة (diagnostics/)  ·  دوال أصلية (natives)
```

| الطبقة | الملف | المسؤولية |
|---|---|---|
| Lexer | `rin_lexer.cpp` | تحويل النص إلى رموز، بما فيها الأرقام العلمية والنصوص القالبية |
| Parser | `rin_parser.cpp` | شجرة AST، وإطارات الكتل (`{ }` / `.end`)، وحارس التعشيش `NestGuard` |
| Interpreter | `rin_interpreter.cpp` | مفسِّر يمشي على الشجرة (tree-walking) + بيئات متسلسلة + الدوال الأصلية |
| Diagnostics | `diagnostics/` | أكواد الأخطاء `Exxxx`، اقتباس السطر، اقتراحات «هل تقصد» |
| الواجهات | `rin_c_api.h` · `cli/linux/src/main.cpp` · `jni_bridge.cpp` | CLI، وC API، وأندرويد (JNI) |

كل الأهداف (Linux CLI · APK · WASM) تبني **نفس** ملفات المحرّك، فأي تحسين هنا ينعكس عليها جميعاً.

## 2. نموذج القيم والبيئات

- **`Value`**: `nil · number(double) · string · bool · function · array · map · instance · set`.
- المصفوفة والقاموس والمجموعة والكائن (`class`) **مرجعية** (`shared_ptr`)؛ و`struct` **قيمية** (تُنسخ عند الإسناد والتمرير).
- **`Environment`**: جدول متغيّرات + مؤشر للأب. البحث يصعد السلسلة حتى أول تعريف.
- المتغيّرات الحيّة (`stone/gauge/tape/lens/fuse/bell`) وحقول `state` في الحاويات تمرّ بمسار إسناد خاص يُطلق
  `on update` والروابط؛ المتغيّرات العادية لا تدفع كلفة هذا المسار.

## 3. نموذج التنفيذ

### 3.1 انتقال التحكّم (Flow) بدل الاستثناءات
`return` و`break` و`continue` تنتقل **كقيمة** `Flow` عبر `exec()`/`execBlockFlow()` وليست استثناءات C++
(الاستثناء ≈ 30µs). واجهة `execute()` القديمة تحوِّل `Flow` إلى الاستثناءات نفسها للمستدعين القدامى، فلا يكسر
ذلك أي مضيف. الاستثناءات تبقى لـ `throw` الخاص بالمستخدم والأخطاء فقط.

### 3.2 عمق الاستدعاء
| المضيف | الحد الافتراضي | ملاحظة |
|---|---|---|
| `rin` (CLI) | **10000** | المفسِّر يعمل على خيط بمكدّس 1GB (ذاكرة افتراضية، لا تُحجز إلا عند الاستخدام) |
| أندرويد / المضمَّن | 300 | يُرفع بـ `Interpreter::setDefaultMaxCallDepth(n)` قبل إنشاء المفسِّر، أو `setMaxCallDepth(n)` لمفسِّر بعينه |

تجاوز الحد يرمي `E0035` **قابلاً للالتقاط** بـ `try/catch` — لا انهيار ولا segfault.

### 3.3 حدّ التنفيذ (Execution Budget)
`setExecutionBudget(maxStatements)` يضع سقفاً لعدد العبارات؛ تجاوزه يوقف البرنامج برسالة
`Execution limit exceeded`. يستعمله Live Preview لحماية الواجهة من الحلقات اللانهائية، ويُنصح به لأي مضيف
يشغّل شيفرة غير موثوقة. القيمة `0` (الافتراضي) = بلا حد وبلا أي كلفة.

## 4. الضمانات (لا انهيار)

| الخطر | الضمان |
|---|---|
| تعشيش عميق جداً (آلاف `(` أو `-`) | `NestGuard` بحد 150 وحدة (≈ 75 مستوى) → خطأ `E0010` واضح |
| تكرار لانهائي | `E0035` قابل للالتقاط عند حد العمق |
| استثناء C++ قياسي من دالة أصلية (`bad_alloc`…) | يتحوّل في `invokeCallee` إلى `RinError` (`E0035`) قابل للالتقاط |
| وسائط ناقصة للدوال الأصلية | `E0007` بدل segfault |
| أخطاء وقت التشغيل | تحمل سطرها الصحيح (`file.rin:4:1`) لأن كل عقدة تعبير تُختم بسطرها |

## 5. التحسينات المضمونة في هذا الإصدار

> لا كلمات ولا دوال ولا متغيّرات جديدة في اللغة سوى **الصيغة العلمية للأرقام** (§5.3). كل ما عداها تحت الغطاء
> ونتائج البرامج القائمة متطابقة حرفياً.

### 5.1 القاموس `map` بفهرس تجزئة كسول
`MapData` ما زال قائمة أزواج **بترتيب الإدخال** (التكرار والطباعة والتصدير كما كانت)، وأُضيف إليه فهرس تجزئة
للمفاتيح البدائية (رقم/نص/منطقي/`nil`):

| العملية | قبل | بعد |
|---|---|---|
| `m[k]` / `m[k] = v` / `has(m, k)` / `remove(m, k)` / حرفي `{...}` | O(n) | O(1) تقريباً حين `size ≥ 12` |
| مفتاح مركّب (مصفوفة/قاموس/كائن) | O(n) | O(n) (بالمقارنة التركيبية كما كان) |

قواعد الدلالة (مطابقة تماماً لـ `valuesEqual`): لا مساواة بين أنواع مختلفة (`1` ≠ `"1"`)، و`-0 == 0`،
و`NaN` لا يُفهرَس. الفهرس **كسول**: يُبنى عند أول بحث، ويسقط تلقائياً عند أي تعديل يغيّر الحجم بطرق قديمة
(`push_back`/`erase`…)، ويتحقق `findIndex` من المفتاح الفعلي في الموضع فلا يعيد عنصراً خاطئاً أبداً.
للمطوّرين في C++: استعملوا `MapData::findValue/findIndex/put/append/eraseAt` بدل المسح الخطّي اليدوي.

### 5.2 تجميع النصوص `s = s + x`
العبارة المستقلة `s = s + <حرفي أو متغيّر أو جمع منها>` حين `s` نص عادي تُلحَق **في مكانها** بدل نسخ النص
كاملاً مرتين في كل تكرار (كان تربيعياً). تُطبَّق فقط حين يستحيل أن يغيّر الطرف الأيمن `s`، ولا توجد متغيّرات
حيّة، و`s` ليس حقلاً في حاوية؛ وإلا يُنفَّذ المسار الأصلي نفسه.

### 5.3 الأرقام العلمية
```kotlin
print 1e3;        // 1000
print 2.5e-2;     // 0.025
print 1E18 > 1e17;
```
يُستهلك الأس فقط إن تبعه رقم فعلاً (`e` أو `E`، وإشارة اختيارية)، فلا تتأثر الأسماء الملاصقة للأرقام.

### 5.4 ما قيس
قيست على الجهاز نفسه، `-O2`، نواة واحدة، **قبل → بعد** (القيم النهائية في `tests/bench/`):

| الاختبار | قبل | بعد |
|---|---|---|
| 20 ألف إدراج + قراءة في قاموس (`map_big.rin`) | 1.2–2.2 ث | 0.06–0.08 ث |
| 60 ألف إلحاق نص (`str_cat.rin`) | 0.25–0.31 ث | 0.04–0.05 ث |
| `fib(24)` (`fib.rin`) | ≈0.10 ث | ≈0.10 ث (لم يتغيّر) |

التفاصيل في [`tests/bench/results.md`](../tests/bench/results.md). استدعاء الدوال لم يُحسَّن في هذا الإصدار.

### 5.5 حدود قابلة للضبط من سطر الأوامر
```kotlin
rin --budget=N    file.rin     سقف عدد العبارات (0 = بلا حد)
```
تُعطى قبل اسم الملف فقط حتى لا تلتبس بوسائط البرنامج. جُرّب عمق 49990 بلا انهيار.

## 6. التضمين

| الواجهة | الاستعمال |
|---|---|
| CLI | `rin file.rin` · `rin` (طرفية تفاعلية) · `rin pkg ...` |
| C API (`rin_c_api.h`) | `rin_run(source, basePath)` لتشغيل لمرة واحدة · `rin_session_create/run/free` لجلسة تحتفظ بحالتها · `rin_engine_version()` · حرّر النصوص المعادة بـ `rin_free_string` |
| C++ مباشر | `rin::Interpreter` + `setMaxCallDepth` + `setExecutionBudget` |
| أندرويد | `jni_bridge.cpp` (حد العمق 300 افتراضياً) |

## 8. حدود معروفة

- المفسِّر يمشي على الشجرة (لا bytecode ولا JIT)، فالحلقات العددية الثقيلة أبطأ من اللغات المترجمة.
- `Value` بنية عريضة (نص + عدة مؤشرات)؛ نسخها أغلى من لغات القيم المضغوطة.
- مفاتيح القاموس المركّبة تُبحث خطّياً.
- `s = s + x` المُسرَّع يخص العبارة المستقلة؛ داخل تعبير أكبر أو مع طرف أيمن فيه استدعاء يبقى المسار الأصلي.
- `rinc` وتلوين المحرّرات لم يتغيّرا.
