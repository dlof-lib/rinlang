# Rin Web Resources — الخطوط والفيديو

## 1. الخطوط

يمكن لعناصر UI استخدام خط من ملف محلي داخل المشروع أو من عنوان إنترنت.

### خط محلي
```rin
@view.Text=title text="مرحباً" font_local="fonts/MyFont.ttf" size=22; .end/view
```

المسار النسبي يبدأ من جذر المشروع. ويمكن استخدام `file://` أو مسار مطلق عندما يكون ذلك متاحاً في بيئة التشغيل.

### خط من الإنترنت
```rin
@view.Text=title text="مرحباً" font_url="https://example.com/fonts/MyFont.ttf" size=22; .end/view
```

يتم تنزيل الخط مرة واحدة إلى ذاكرة التخزين المؤقت للتطبيق، ثم يعاد استخدامه. إذا فشل الاتصال يبقى الخط الاحتياطي فعالاً.

يمكن وضع `font_local` أو `font_url` مباشرة على عناصر النص/الواجهة التي تريد تخصيص خطها، بينما يبقى `font` خيار الخط المدمج العام.

## 2. الفيديو الخارجي

اللغة تستخدم اسماً محايداً لمصدر الفيديو: `video_url`. لا يحتاج المطور إلى كتابة اسم المنصة في بناء Rin.

```rin
@view.Video=player width=100% height=220;
    video_url="https://example.com/video.mp4";
    ratio="16:9";
.end/view
```

ويقبل `video_url` روابط صفحات الفيديو الشائعة أيضاً؛ يقوم المضيف بتحويل روابط الصفحات المدعومة إلى مشغل مضمّن، بينما الروابط المباشرة للملفات تستخدم مشغل الفيديو الأصلي.

### فيديو محلي

للفيديو المحلي يمكن الاستمرار باستخدام `src`:

```rin
@view.Video=localVideo src="media/intro.mp4" width=100% height=220; .end/view
```

## 3. التوافق

- `src` يبقى مدعوماً للتوافق مع المشاريع القديمة.
- `video_url` هو الواجهة الموصى بها لمصادر الفيديو الخارجية.
- `font` يبقى مدعوماً للخطوط المدمجة (`sans`, `serif`, `mono`).
- `font_local` و`font_url` يضيفان مصادر خطوط مخصصة دون كسر النحو القديم.
