# template-strings.md — النصوص القالبية (متغيّرات داخل النص)

> كل مثال هنا جُرِّب فعلياً بمفسِّر Rin. مثال كامل قابل للتشغيل:
> [`examples/template_strings_demo.rin`](../examples/template_strings_demo.rin).

## الفكرة في ثلاث ثوانٍ

بدل أن تكتب:
```rin
print "مرحباً " + name + "، عمرك " + age + " سنة";
```
اكتب:
```rin
print `مرحباً ${name}، عمرك ${age} سنة`;
```

**القاعدتان الوحيدتان:**
1. النص بين علامتَي `` ` `` (backtick) بدل `" "`.
2. أي شيء تريد عرض قيمته يوضع داخل `${ ... }`.

## ماذا أكتب داخل `${ }`؟

أي تعبير Rin صحيح:

| ما تكتبه | مثال | الناتج (إن كان `age = 20`) |
|---|---|---|
| متغيّر | `` `${name}` `` | `ريم` |
| عملية حسابية | `` `${age + 1}` `` | `21` |
| استدعاء دالة | `` `${double(age)}` `` | `40` |
| عنصر مصفوفة | `` `${items[0]}` `` | أول عنصر |
| حقل قاموس | `` `${user["city"]}` `` | `بيروت` |
| مقارنة | `` `${age > 18}` `` | `true` |
| شرط ثلاثي | `` `${age >= 18 ? "بالغ" : "قاصر"}` `` | `بالغ` |
| قالب داخل قالب | `` `أ ${`ب ${name}`}` `` | `أ ب ريم` |

كل القيم (أرقام، منطقي، مصفوفات، `nil`...) تُحوَّل تلقائياً إلى نص بنفس طريقة `toString`،
فلا حاجة لتحويلها بنفسك.

## تنسيق القيم: `${القيمة:التنسيق}`

اكتب `:` ثم التنسيق بعد القيمة مباشرة:

| التنسيق | مثال | الناتج |
|---|---|---|
| `.2f` خانتان عشريتان | `` `${1234.5:.2f}` `` | `1234.50` |
| `,` فاصل آلاف | `` `${1234567:,d}` `` | `1,234,567` |
| `,.2f` الاثنان معاً | `` `${1234.5:,.2f}` `` | `1,234.50` |
| `05` أصفار بادئة (عرض 5) | `` `${7:05}` `` | `00007` |
| `.1%` نسبة مئوية | `` `${0.256:.1%}` `` | `25.6%` |
| `d` رقم صحيح (تقريب) | `` `${2.7:d}` `` | `3` |
| `>8` محاذاة يمين بعرض 8 | `` `[${"ريم":>8}]` `` | `[     ريم]` |
| `<8` محاذاة يسار | `` `[${"ريم":<8}]` `` | `[ريم     ]` |
| `^8` توسيط | `` `[${"ريم":^8}]` `` | `[  ريم   ]` |
| `upper` / `lower` | `` `${"hi":upper}` `` | `HI` |
| `trim` حذف المسافات من الطرفين | `` `[${"  x ":trim}]` `` | `[x]` |

**ترتيب أجزاء التنسيق الرقمي:** `[محاذاة][0][عرض][,][.دقة][نوع]` — كلها اختيارية.
الأرقام تُحاذى لليمين افتراضياً، والنصوص لليسار. العرض يُحسب بعدد الحروف (العربية تعمل بشكل صحيح).

> الشرط الثلاثي لا يتعارض مع التنسيق: `` `${age > 18 ? "بالغ" : "قاصر":>6}` `` —
> أول `:` تابعة للشرط، والأخيرة هي التنسيق.

## قيمة افتراضية: `${متغيّر ?? بديل}`

تعرض البديل فقط إذا كانت القيمة `nil`:
```rin
let nick = nil;
print `أهلاً ${nick ?? "زائر"}`;   // أهلاً زائر
```
يمكن جمعها مع التنسيق: `` `${price ?? 0:.2f}` ``.
(المتغيّر يجب أن يكون معرَّفاً؛ يكفي أن تكون قيمته `nil`. وإن كان داخل شرط ثلاثي استعمل أقواساً.)

## قيم جاهزة: `${#اسم}`

قيم تأتي من النظام بلا تعريف. تبدأ بـ `#` حتى لا تتعارض مع متغيّراتك (فلو عندك متغيّر اسمه `date` يبقى `${date}` هو متغيّرك):

| القيمة | تعطي | مثال |
|---|---|---|
| `#date` | تاريخ اليوم | `2026-10-05` |
| `#time` | الوقت الآن | `23:42:38` |
| `#datetime` | التاريخ والوقت | `2026-10-05 23:42:38` |
| `#year` `#month` `#day` | أرقام | `2026` `10` `5` |
| `#hour` `#minute` `#second` | أرقام | `23` `42` `38` |
| `#weekday` | رقم اليوم (0 = الأحد) | `1` |
| `#version` | إصدار Rin | `1.0.0` |
| `#line` | رقم السطر الحالي | `27` |
| `#file` | اسم الملف الحالي | `main.rin` |

يمكن تنسيقها أيضاً: `` `${#month:02}` `` ← `10`.

## عدة أسطر

يمكن للقالب أن يمتد على أكثر من سطر، وتبقى الأسطر كما كتبتها:
```rin
print `السطر الأول
السطر الثاني: ${name}`;
```

## كتابة `$` أو `` ` `` حرفياً (التهريب)

ضع `\` قبل الحرف:

| تكتب | يظهر |
|---|---|
| `` \${name} `` | `${name}` (لا يُستبدل) |
| `` \` `` | `` ` `` |
| `\\` | `\` |
| `\n` `\t` `\r` | سطر جديد / Tab / رجوع |

## النص العادي لا يتغيّر

النصوص المكتوبة بـ `" "` تبقى **حرفية تماماً** — لا يُفسَّر فيها `${}` ولا `{}`.
لذلك لن يتأثر أي كود قديم (JSON، HTML، قوالب `{{name}}`...):
```rin
let name = "ريم";
print "${name}";   // ${name}
print `${name}`;   // ريم
```

## الأخطاء الشائعة

| الخطأ | الرسالة |
|---|---|
| نسيان إغلاق القالب بـ `` ` `` | `unterminated template string` |
| `${}` فارغة | ``empty `${}` in template string`` |
| متغيّر غير معرَّف | `undefined variable` (مع اسم المتغيّر) |
| `${x:}` بلا تنسيق | `empty format after ":"` |
| تنسيق غير معروف | `invalid format ":zz"` مع أمثلة صحيحة |
| تنسيق رقمي على نص | `this format needs a number` |
| `${#xyz}` غير موجودة | `undefined variable` |

## كيف تعمل داخلياً؟ (اختياري)

يحوّل الـ Lexer كل قالب إلى دمج نصوص عادي قبل أن يصل إلى المحلل النحوي:

```
`مرحباً ${name}!`   ⟶   ("مرحباً " + #str(name) + "!")
```

- مع التنسيق: `${x:.2f}` ⟶ `#fmt(x, ".2f")`، ومع الافتراضي: `${a ?? b}` ⟶ `#default(a, b)`،
  ومع القيم الجاهزة: `${#date}` ⟶ `#now("date")`.
- `#str` هي نفس `toString` لكن باسم لا يمكن لمتغيّراتك حجبه (حتى لو سمّيت متغيّراً `str`).
- لا تغيير في المحلل أو المفسِّر، لذا تعمل الميزة تلقائياً في CLI وRinStudio وWebAssembly.
- يبدأ التعبير دائماً بنص (ولو فارغ) فتكون `+` دمجاً للنصوص وليست جمعاً للأرقام:
  `` `${1}${2}` `` تعطي `"12"` وليس `3`.
