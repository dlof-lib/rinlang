# حلقة Rin — مخزن دائري `ring.new`

الوجه الثاني لاسم **Rin**: *ring* بمعنى **حلقة**. مخزن بسعة ثابتة يدور على نفسه: عند الامتلاء يُزيح الأحدثُ الأقدمَ.
مثالي لـ «آخر N أحداث/قراءات/أسطر سجلّ» ومتوسطات متحرّكة بلا تضخّم الذاكرة. إضافة بحتة؛ الاختبار: `tests/print/ring_buffer.rin`.
(الوجه الأول: الإشارات `ring "t"` في [`ring.md`](./ring.md).)

```kotlin
let log = ring.new(3);          // سعة 3
ring.add(log, "a"); ring.add(log, "b"); ring.add(log, "c");
ring.add(log, "d");             // يُعيد "a" (المُزاح)
print ring.items(log);          // ["b", "c", "d"]  (من الأقدم إلى الأحدث)
```

| الدالة | المعنى |
|---|---|
| `ring.new(n)` | حلقة سعتها `n` (عدد صحيح ≥ 1) |
| `ring.add(r, v)` | يضيف `v`؛ يُعيد العنصر **المُزاح** عند الامتلاء وإلا `nil` (O(1)) |
| `ring.addAll(r, arr)` | يضيف كل عناصر المصفوفة بالترتيب؛ يُعيد الحلقة |
| `ring.items(r)` | مصفوفة جديدة من الأقدم إلى الأحدث |
| `ring.size(r)` · `ring.cap(r)` · `ring.full(r)` | العدد الحالي · السعة · هل امتلأت |
| `ring.first(r)` · `ring.last(r)` | الأقدم · الأحدث (`nil` إن فارغة) |
| `ring.at(r, i)` | الفهرس من الأقدم؛ السالب من الأحدث (`-1` = الأحدث)؛ خارج المدى `nil` |
| `ring.reset(r)` | يفرّغها ويُعيدها |

- الحلقة **قاموس عادي يُمرَّر بالمرجع** (`{kind: "ring", cap, head, size, buf}`): تعديلها داخل دالة يظهر لدى المستدعي. لا تعدّل حقولها يدوياً.
- تمرير شيء ليس حلقة يعطي خطأً واضحاً؛ وسعة غير صحيحة (`0` أو كسر) خطأ كذلك.
- ملاحظة: `ring.clear()` (بلا وسائط) تمسح **مستمعي الإشارات** لا الحلقات؛ لتفريغ حلقة استعمل `ring.reset(r)`.
