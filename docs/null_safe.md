# السلامة من nil — `?.` · `??` · `??=`

ثلاثة معاملات تجعل التعامل مع القيم الغائبة (`nil`) قصيراً وآمناً، خصوصاً مع JSON والكائنات المتداخلة. إضافة بحتة:
كل كود قديم يعمل كما هو، فهي كلها رموز **ملتصقة بلا مسافة** فلا تتعارض مع الشرط الثلاثي `c ? a : b`.
الاختبار: `tests/print/null_safe.rin`.

## 1) السلسلة الاختيارية `?.`
| الصيغة | المعنى |
|---|---|
| `a?.name` | `nil` إن كانت `a` هي nil، وإلا `a.name` |
| `a?.[i]` | `nil` إن كانت `a` هي nil، وإلا `a[i]` |
| `a?.(x)` | `nil` إن كانت `a` هي nil، وإلا نداء `a(x)` |
| `a?.m(x)` | استدعاء الدالة `m` على `a` إن لم تكن nil |

```kotlin
let o = {user: {name: "Rin", tags: ["x", "y"]}};
print o.user?.name;          // Rin
print o.admin?.name;         // nil   (بدل خطأ «cannot access property on nil»)
print o.admin?.name.size;    // nil   — السلسلة كلها تتوقف عند أول nil
print o.user?.tags?.[1];     // y
```
- **اختصار كامل للسلسلة**: عند أول `?.` فارغ يُتجاوز كل ما بعده في السلسلة نفسها (مثل JavaScript).
- الجهة اليسرى تُقيَّم **مرة واحدة** فقط.
- القيمة غير الفارغة تُعامَل عادياً: خاصية ناقصة على كائن موجود تعطي ما تعطيه `.` دائماً، ونوع لا يملك الخاصية يعطي نفس الخطأ.
- لا يُسمح بالإسناد: `a?.b = 1` خطأ.

## 2) القيمة الافتراضية `??`
`a ?? b` = `a` إن لم تكن `nil`، وإلا `b`. الطرف الأيمن **كسول** (لا يُقيَّم إلا عند الحاجة) والأيسر يُقيَّم مرة واحدة.
`0` و`false` و`""` **ليست** nil فتبقى كما هي.
```kotlin
print nick ?? "زائر";
print o.admin?.name ?? "—";       // السلسلة الاختيارية + الافتراضية
print 0 ?? 9;                     // 0
print a ?? b ?? "c";              // أول قيمة غير nil
```
دلالتها مطابقة لـ `a else b` (انظر [`else.md`](./else.md))؛ وهي نفس `??` الموجودة أصلاً في القوالب النصية `${x ?? "بديل"}`.
أولويتها أدنى من `or` وأعلى من `|>`: `a or b ?? c` = `(a or b) ?? c`.
مع الأنبوب استعمل أقواساً: `(x |> f) ?? 0`.

## 3) الإسناد الشرطي `??=`
`x ??= v` ≡ `x = x ?? v`: يُسنَد فقط إن كانت `x` هي nil، و`v` لا تُقيَّم إلا حينها. للمتغيّر و`arr[i]` و`obj.field`
(الهدف بسيط بلا آثار جانبية كما في `+=`).
```kotlin
let cfg = {};
cfg.port ??= 8080;     // يُضبط
cfg.port ??= 9090;     // يبقى 8080
```

## حدود معروفة
- المسار `--vm` (RinVM) لا يدعم هذه الصيغ بعد؛ المفسِّر الافتراضي يدعمها كلها.
- تنفيذاً: `a?.b.c` تُختزل إلى `__optchain(a, fun(t) { return t.b.c; })`، و`a ?? b` إلى `a != nil ? a : b` أو `__else(a, fun() { return b; })`.
