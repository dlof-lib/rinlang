# let-plus.md — `let` المطوَّر

> كل مثال هنا جُرِّب فعليًا عبر المفسِّر (انظر `tests/verification/let_*.rin` و`examples/let_plus_demo.rin`).

الصيغة القديمة `let x = 5;` تعمل **حرفيًا كما كانت**. الإضافات اختيارية بالكامل، وكلها تبدأ بما كان خطأً نحويًا سابقًا،
فلا يتغيّر معنى أي برنامج موجود.

| الإضافة | الصيغة |
|---|---|
| تفكيك مصفوفة | `let [a, b = 0, _, ...rest] = arr;` |
| تفكيك قاموس/كائن | `let {name, age = 0, city: town, ...others} = m;` |
| عدة تصريحات | `let a = 1, b = a + 1, [c, d] = pair;` |
| حارس `else` | `let v = find(k) else { return; };` |
| تفكيك في `for` | `for (let [k, v] in pairs) { ... }` |
| تبديل/إسناد تفكيكي | `[a, b] = [b, a];` |

## 1) تفكيك المصفوفة
```rin
let [a, b] = [1, 2];
let [x, y, z] = [10, 20];          // z = nil (خانة مفقودة)
let [p, q = 5, r = 7] = [1, nil];  // 1 5 7 — الافتراضي عند الغياب أو nil
let [first, ...others] = [1, 2, 3, 4];   // others = [2, 3, 4]
let [h, , t] = ["a", "b", "c"];    // خانة فارغة تتخطّى
let [_, second] = ["skip", "keep"];// _ يتخطّى أيضًا ولا يُعرَّف كمتغيّر
let [m, [n, o]] = [1, [2, 3]];     // تعشيش
let [d1, d2 = d1 * 2] = [4];       // الافتراضي يرى ما رُبط قبله
```
`...rest` يجب أن يكون الأخير، ويعطي مصفوفة فارغة إن لم يبقَ شيء. `...` وحدها (بلا اسم) خطأ نحوي.

## 2) تفكيك القاموس والكائن
```rin
let user = {"name": "Sara", "age": 30, "city": "Riyadh"};
let {name, age} = user;
let {city: town, missing = "n/a"} = user;   // key: اسم  لإعادة التسمية
let {name: nm, ...others} = user;           // others = باقي المفاتيح
let {"role": r} = user;                     // مفتاح نصي يحتاج اسمًا بعد ':'
let {profile: {lang = "ar", tz}} = data;    // تعشيش
class Pt { let x = 3; let y = 4; }
let {x, y} = Pt();                          // حقول الكائن (بلا ...rest)
```

## 3) عدة تصريحات
```rin
let a = 1, b = a + 1, c = b + 1;            // كل عنصر يرى ما قبله
let n: Number = 5, s: String = "x";          // النوع الاختياري لكل عنصر
for (let i = 0, j = 10; i < 3; i = i + 1) { ... }
```
لا يفتح نطاقًا جديدًا. حقل `class` يقبل `let` واحدة بسيطة فقط (خطأ E0013 غير ذلك).

## 4) `let ... else` — الحارس
```rin
fun f(k) {
    let v = find(k) else { return "missing " + k; };
    return "found " + v;
}
fun g(m) { let {id, name} = m else { return "bad shape"; }; return id + ":" + name; }
for (let item in items) { let v = item else { continue; }; total = total + v; }
```
- تُنفَّذ كتلة `else` إذا كانت القيمة `nil`، وفي النمط أيضًا إذا لم يطابق شكل القيمة.
- **يجب** أن تغادر الكتلة النطاق (`return` أو `break` أو `continue` أو `throw` أو `abort`)، وإلا **E0048**.
- `false` و`0` ليستا `nil`، فلا تُشغِّلان الكتلة.
- بدون `else`: النمط على `nil` أو شكل خاطئ يرمي **E0004** برسالة واضحة، والمتغيّر البسيط يقبل `nil` كما كان.

## 5) التفكيك في `for`
```rin
for (let [k, v] in [["a", 1], ["b", 2]]) { print k + "=" + v; }
for (let {id, tag = "-"} in rows) { print id + tag; }
```
عنصر لا يطابق النمط يعطي E0004. الصيغة `for (let [a, b] = pair; ...; ...)` تبقى C-style عادية.

## 6) الإسناد التفكيكي (التبديل)
```rin
[a, b] = [b, a];                    // الطرف الأيمن يُقيَّم كاملاً أولاً
[x, y, z] = [z, x, y];
[arr[0], arr[1]] = [arr[1], arr[0]];  // أهداف arr[i]
[p.x, p.y] = [p.y, p.x];              // وحقول الكائن
[p, q = 77] = [1];                     // افتراضي، و[p, _] لتخطّي خانة
```
يعمل مع المتغيرات الحيّة: `[hp, pos] = [500, 3]` يحترم `gauge` و`tape` و`bell` و`stone`، ويتراجع داخل `trial`.
> الإسناد التفكيكي للمصفوفات فقط (لا `{a, b} = m`) ولا يدعم `...rest`.

## قواعد عامة
- لا يُعرَّف شيء من النمط إلا بعد نجاحه كاملاً: فشل في منتصفه لا يترك نصف ارتباط.
- تكرار الاسم نفسه داخل نمط واحد: **E0002** وقت التحليل.
- `export let a = 1, b = 2;` و`export let [x, y] = pair;` يصدّران كل الأسماء.
- لا يُدعم النوع الاختياري داخل الأنماط (`let [a: Number] = ...` غير مدعوم).

## الأخطاء
| الكود | متى |
|---|---|
| E0004 | تفكيك `nil` أو شكل غير مطابق (مصفوفة مقابل قاموس) |
| E0002 | اسم مكرّر في نمط واحد |
| E0013 | `...rest` ليس أخيرًا، أو نمط في حقل `class` |
| E0048 | كتلة `let ... else` انتهت دون مغادرة النطاق |
