# label-define.md — `label` و`define` (تسمية وتعريف)

> كل مثال هنا جُرِّب فعليًا عبر المفسِّر (انظر `tests/verification/label_define_basic.rin`).

متغيّران من عائلة المتغيرات الحيّة ([`living-variables.md`](./living-variables.md)) يعطيان المتغيّر **هوية**: اسم عرض ووصفًا ووحدة.
هما **بيانات وصفية بحتة**: لا يغيّران الإسناد ولا القراءة، فالمتغيّر يبقى عدديًا أو نصيًا كما كان. كلمتان سياقيتان غير محجوزتين:
`let label = 1;` و`let define = 2;` ما زالا صالحين.

| الصيغة | الفكرة |
|---|---|
| `label x = v as TITLE [about TEXT] [unit TEXT];` | **تسمية**: اسم عرض يُقرأ بـ `x.label` (المعرّف الحقيقي يبقى `x.id`) |
| `define x = v as TEXT [label TITLE] [unit TEXT];` | **تعريف**: وصف يُقرأ بـ `x.about`، ووحدة `x.unit`، وتسمية اختيارية |

`as` يكتب الحقل الأساسي لنوعه (label ← التسمية، define ← الوصف). كل القيم المكتوبة نصوص، وإلا `E0004`.

```rin
label temp = 21 as "درجة الحرارة" about "قراءة المستشعر الداخلي" unit "°C";
print temp.label;     // درجة الحرارة
print temp.id;        // temp
print temp.unit;      // °C
temp = temp + 4;      // الإسناد عادي

define speed = 0 as "سرعة المركبة" unit "km/h";
print speed.label;    // speed   (الافتراضي: المعرّف)
print speed.info;     // {"id": "speed", "label": "speed", "about": "سرعة المركبة", "unit": "km/h", "value": 0}
```

## الخصائص (للقراءة فقط)
`x.label` (الافتراضي: المعرّف) · `x.about` (الافتراضي نص فارغ) · `x.unit` (الافتراضي `nil`) · `x.id` · `x.info` (خريطة فيها الحقول والقيمة الحالية).
وتظهر أيضًا في `x.vitals`. على أي متغيّر آخر لا تفعل هذه الأسماء شيئًا (فلا تحجب خاصية أو دالة بنفس الاسم).
حقل بيانات حقيقي بنفس الاسم (مفتاح `label` في قاموس) يغلب الخاصية.

## ملاحظات
- يعملان مع `bell` و`inc`/`dec` و`trial`. النوع واحد لكل متغيّر: لا يُجمعان مع `gauge`/`tape`/`accept`/`pre`/`post`.
- الأخطاء: `E0012` (بلا `as`) · `E0013` (حقل مكرّر أو في غير مكانه، مثل `about` مع `define`) · `E0004` (قيمة غير نصية).
- حدود: التسمية ثابتة من التصريح (لا تُغيَّر بالإسناد) · مترجم `rinc` (Rin → C) لا يدعم الصيغة بعد.
