# channel47 — لغة وصف البيانات والإعدادات

**الامتداد:** `.ch47` · **الإصدار:** 1.0 · **الترميز:** UTF-8 · **MIME:** `text/x-channel47`

لغة نصّية صغيرة وصارمة لوصف **بيانات المكتبات والحزم والأدوات** وإعداداتها في منظومة Rin
(بيانات `RinPM`، مخزن المكتبات، إعدادات الأدوات). تمثّل: **النصوص، الأرقام، القيم المنطقية، التواريخ،
المصفوفات، الجداول** — وتقرأ بالعين كما تُكتب باليد.

## لمحة سريعة
```channel47
channel47 1.0
kind        = "library"
name        = "rin.math"
version     = "1.2.0"
stable      = true
released    = 2026-10-15
keywords    = ["math", "رياضيات"]

table deps(name: text, version: text, optional: bool = false)
  "rin.core",  "^1.0.0"
  "rin.stats", "~0.4.0", true
end

[build]
ratio = 0.75
size  = 1_048_576
```

## المبادئ
1. **صارمة**: نصٌّ بلا اقتباس خطأ (لا تخمين). مفتاح مكرر خطأ. نوع خاطئ في خلية خطأ.
2. **حتمية**: لكل مستند معنى واحد، وله شكل قانوني واحد (`fmt`) يُنتج الفروقات نفسها في Git.
3. **أخطاء دقيقة**: `الملف:السطر:العمود` + رمز ثابت `C47xxx` + سهم تحت الموضع.
4. **عربية أولاً**: المفاتيح تقبل الحروف العربية (`مفتاح = 1`)، والرسائل بالعربية والإنجليزية (`--lang en`).

## بنية الملف
| العنصر | الصيغة |
|---|---|
| ترويسة (اختيارية) | `channel47 1.0` أول سطر غير فارغ. إصدار رئيسي غير 1 ← `C47002` |
| تعليق | `# ...` حتى آخر السطر |
| تعيين | `مفتاح = قيمة` · مفتاح منقّط `a.b = 1` · مفتاح مقتبس `"my key" = 1` |
| قسم | `[a.b]` — كل ما بعده يخصّه حتى القسم التالي |
| جدول | `table اسم(أعمدة) … end` |

المفتاح الصريح: `[^\W\d][\w-]*` (حروف يونيكود/`_`/`-`، لا يبدأ برقم). غير ذلك يُقتبس.

## الأنواع
| النوع | أمثلة | ملاحظات |
|---|---|---|
| **نص** `text` | `"سلام\n"` · `'خام\n'` · `"""متعدد الأسطر"""` | الهروب في `"` فقط: `\n \t \r \" \\ \0 \b \f \u{1F600}`. `'` حرفي بلا هروب. `"""`/`'''` يحذف السطر الأول إن كان فارغاً |
| **عدد صحيح** `int` | `42` `-7` `1_000` `0xFF` `0o17` `0b101` | 64 بت مُوقَّع؛ لا أصفار بادئة (`007` ← `C47024`) |
| **عدد عشري** `float` | `1.5` `-0.25` `1e-3` `6.02E23` | لا `NaN` ولا `Infinity` |
| **منطقي** `bool` | `true` `false` | بالحروف الصغيرة فقط |
| **فراغ** | `nil` | |
| **تاريخ** `date` | `2026-10-15` | يُتحقَّق من صحته (13 شهراً ← `C47022`) |
| **وقت** `time` | `09:30` `09:30:15.5` | |
| **تاريخ ووقت** `datetime` | `2026-10-15T09:30:00Z` · `...+03:00` · بلا منطقة = محلي | الفاصل `T` فقط |
| **مصفوفة** | `[1, "a", [2]]` | أي أنواع مختلطة؛ أسطر متعددة وتعليقات وفاصلة أخيرة مسموحة |
| **كائن مضمَّن** | `{ rpm = 60, burst = 10 }` | مغلق: لا يُوسَّع لاحقاً بـ`[قسم]` أو مفتاح منقّط |
| **جدول** | انظر أدناه | قائمة صفوف مُنمَّطة |

## الجداول
```channel47
table commands(name: text, summary: text, aliases: text[] = [], since: date?)
  "format", "تنسيق ملف",     ["fmt", "f"], 2026-01-10
  "check",  "فحص بلا تعديل", _,            _
  "watch",  "مراقبة المجلد", ["w"]
end
```
- **العمود**: `اسم: نوع` مع لواحق اختيارية بهذا الترتيب: `[]` (مصفوفة من النوع) ثم `?` (يقبل `nil`) ثم `= افتراضي`.
- **الأنواع**: `text int float bool date time datetime any` (غير ذلك ← `C47030`). `float` تقبل أعداداً صحيحة وتحوّلها.
- **الصف**: سطر قيم مفصولة بفاصلة. سطر ينتهي بفاصلة يكمل في التالي. الخلايا الناقصة في النهاية تأخذ الافتراضي، أو `nil` إن كان العمود `?`، وإلا `C47041`.
- **`_`** في خلية = «استعمل الافتراضي».
- **التحقق**: كل خلية تُفحص بنوع عمودها (`C47042`)، وعدد الخلايا لا يتجاوز الأعمدة (`C47040`)، ويجب إغلاق الجدول بـ`end` (`C47043`).
- **النتيجة**: قائمة قواميس بترتيب الأعمدة، مع بقاء تعريف الأعمدة (لإعادة الكتابة والتحقق).

## الأقسام والمسارات
- `[a.b]` يُنشئ `a` ضمنياً. تعريف القسم نفسه مرتين ← `C47012`. مفتاح مكرر ← `C47013`.
- لا مصفوفة أقسام `[[x]]` (← `C47014`): استعمل `table`.
- الكائن المضمَّن والجدول **مغلقان** بعد تعريفهما (`C47011`/`C47012`).

## الصيغة القانونية (`fmt`)
ترويسة `channel47 1.0` ← مفاتيح بسيطة ← جداول ← أقسام فرعية (`[a.b]`) · نص بين `"` · أعداد عشرية تحمل `.` دائماً ·
`Z` للـUTC · مصفوفات أقصر من 72 حرفاً في سطر وإلا سطر لكل عنصر · أعمدة الجداول محاذاة. التعليقات **لا تُحفظ** (النموذج: بيانات لا نص).
الكتابة ثم القراءة ثم الكتابة تعطي النص نفسه (idempotent).

## بيانات الحزم: `kind`
مفتاح `kind` يفعّل التحقق الدلالي (`channel47.py check`):

| kind | مطلوب | اختياري | جداول |
|---|---|---|---|
| `library` | `name` `version` `entry` | `exports` + المشترك | `deps(name, version)` |
| `package` | `name` `version` | `files` `entry` + المشترك | `deps` |
| `tool` | `name` `version` `bin` | `entry` + المشترك | `commands(name, summary)` `deps` |

**المشترك**: `description license authors[] homepage keywords[] released(date|datetime) permissions[] stable rin`.
- `name`: `^[a-z0-9][a-z0-9._-]{0,63}$` (نفس قاعدة معرّف RinPak) · `version`: إصدار دلالي `X.Y.Z[-pre][+build]`.
- مفتاح غير معروف في أعلى المستند ← تحذير `C47053` (لا يفشل). الأقسام الفرعية حرة (`[build]` …).
- `deps.version` نص قيد حر (`^1.0.0`، `~0.4.0`، `>=1.0.0`) تفسّره أداة الحزم.

## القواعد النحوية (EBNF مختصر)
```
document  = [header] { statement } ;
header    = "channel47" version NL ;
statement = section | table | assign ;
section   = "[" keypath "]" NL ;
assign    = keypath "=" value NL ;
table     = "table" keypath "(" column {"," column} ")" NL { row } "end" NL ;
column    = name ":" type ["[]"] ["?"] ["=" value] ;
row       = cell {"," cell} NL ;           (* سطر ينتهي بفاصلة يكمل *)
cell      = value | "_" ;
value     = string | number | bool | "nil" | date | time | datetime | array | object ;
array     = "[" [ value {"," value} [","] ] "]" ;
object    = "{" [ name "=" value {"," name "=" value} [","] ] "}" ;
```

## الأدوات
```bash
python3 tools/channel47.py check  examples/channel47/rin-math.library.ch47   # صياغة + بيان
python3 tools/channel47.py fmt    app.ch47 -w                               # تنسيق قانوني
python3 tools/channel47.py json   app.ch47                                  # → JSON
python3 tools/channel47.py from-json data.json                              # JSON → channel47
python3 tools/channel47.py get    app.ch47 net.timeout                      # قراءة مسار
python3 tools/channel47.py merge  defaults.ch47 user.ch47                   # طبقات (الثاني يغلب)
python3 tests/channel47_test.py                                             # 20 اختباراً (بايثون)
rin_run tests/channel47_rin_test.rin                                        # 57 فحصاً (Rin، من جذر المشروع)
```
- **JSON**: التواريخ تصير نصوص ISO-8601، والجداول قوائم قواميس. `from-json` لا يستنتج تواريخ من النصوص.
- **الدمج**: القواميس تُدمج بعمق؛ المصفوفات والجداول والقيم تُستبدل كاملة.

## داخل Rin: `lib/channel47.og.rin`
```rin
@import "lib/channel47.og.rin";
let r = c47_try(readFile("package.ch47"));
if (r.ok) { print c47_get(r.value, "deps", []); } else { print r.error.code + " @ " + str(r.error.line); }
```
| الدالة | الوظيفة |
|---|---|
| `c47_parse(src)` | يحلّل النص ويُرجع قاموساً؛ يرمي `{code, message, line, col}` عند الخطأ |
| `c47_try(src)` | `{ok, value, error}` بلا رمي |
| `c47_get(doc, "a.b", default)` · `c47_has` · `c47_merge(a, b)` | قراءة مسار / وجوده / دمج طبقات |
| `c47_check(doc, kind?)` | تحقق البيان: مصفوفة `{level, code, path}` (المطلوب + `name` + `version`) |

ملاحظات: الأعداد مزدوجة الدقة (أعداد صحيحة فوق 2^53 تفقد دقتها)، والتواريخ والأوقات تعود **نصوص ISO**، والجداول مصفوفات قواميس.
الكتابة (`fmt`/`from-json`) والتحقق الكامل بالجداول في أداة بايثون؛ قارئ Rin للقراءة والفحص الأساسي.
تنبيه لكتّاب المكتبات: `text` و`row` كلمتان محجوزتان في Rin فلا تُستعملان أسماء متغيّرات.

## حدود الإصدار 1.0
لا استيراد ملفات، لا استيفاء متغيّرات (`${...}`)، لا مدد زمنية، لا مصفوفة أقسام، ولا حفظ للتعليقات عند `fmt`. هذه إضافات محتملة في 1.x دون كسر الصيغة.
