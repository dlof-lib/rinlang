لغة برمجة كاملة، بلا حاسوب مطلوب

ابدأ من هاتفك، واكتب Rin من الصفر إلى تطبيق يعمل.

Rin لغة برمجة حقيقية بمحرّك C++‎17 خاص بها، تأتي ببيئة تطوير أندرويد كاملة — محرّر، مترجم، وتصدير APK — فلا تحتاج حاسوباً لتبدأ. ولها أيضاً حاويات @container منظِّمة، وقاعدة بيانات NoSQL، وأنابيب |> مدمجة في صلب اللغة نفسها.

ما الذي يجعل Rin مختلفة

ليست فقط متغيّرات ودوال وحلقات — Rin تضيف طبقة تنظيمية للبيانات والمنطق غير موجودة في أغلب اللغات، بصياغة واحدة تقرأها من الأعلى للأسفل.

01

الحاويات @container

بنية تعريفية تُجمِّع بيانات ومنطقاً مرتبطين ببعضهما في وحدة واحدة واضحة الحدود، بدل تفريقها بين متغيّرات ودوال متناثرة. الحاويات قابلة للتجميع داخل مجموعات @Containers.Group، وقابلة للتصدير كملف .rin جاهز أو نسخة مبسَّطة منه.

container.rin
@container=my_data
    text title = "بيانات رين";
    print title;

    Section=numbers
        let a = 10;
        let b = 4;
        print Addition(a, b);
    .end/Section
.end/container
02

قاعدة بيانات NoSQL مدمجة

مخزن وثائق (documents) بلا أي اتصال خارجي أو استيراد إضافي — أنشئ حاوية وثائق بـ @container.doc، ثم أدرج/استعلم عنها مباشرة بدوال اللغة الأساسية نفسها.

users.rin
@container.doc=users
    document id="u1" fields={ name: "سارة", age: 28 };
.end/container.doc

insertDoc("users", "u3", { name: "منى" });
print queryDocs("users", "city", "الرياض");
03

أنابيب |> لتسلسل العمليات

بدل تعشيش الاستدعاءات f(g(h(x))) أو متغيّرات وسيطة متكرّرة، الأنبوب يمرّر ناتج كل خطوة إلى التي تليها بترتيب القراءة الطبيعي — داخل حاويات @container.pipe المخصَّصة لهذا الغرض.

pipe.rin
@container.pipe=sales_pipeline
    let raw = [1, 2, 3, 4, 5];
    let result = raw |> normalize() |> mean();
    print result;
.end/container.pipe
04

ترجمة نصوص مدمجة في اللغة

translation تُسجِّل نص العنصر بأكثر من لغة داخل الحاوية نفسها، بلا حاجة لملفات .json منفصلة أو مكتبة i18n خارجية — مفيدة تحديداً لواجهات تحتاج عربية/إنجليزية معاً من اليوم الأول.

i18n.rin
@container=greeting
    Translations
        translation lang="ar" text="مرحبا";
        translation lang="en" text="Hello";
    .end/Translations
.end/container

نظام متكامل، لا لغة فقط

كل ما حول محرّك Rin مبني ليعمل معه بلا حواجز: من الكتابة على الهاتف، إلى التشغيل في المتصفح، إلى استدعاء نفس المحرّك من لغة أخرى تماماً.

بيئة تطوير أندرويد IDE

محرّر شيفرة كامل، تشغيل مباشر، وتصدير APK — كل ذلك من داخل الهاتف نفسه بلا حاسوب.

تصدير WebAssembly WASM

المحرّك نفسه (لا نسخة مصغَّرة) يُصدَّر إلى WebAssembly ليعمل داخل المتصفح مباشرة.

الربط مع لغات أخرى C ABI

مكتبة librin بواجهة C قياسية، مع أمثلة جاهزة لـ Python وNode.js لاستدعاء محرّك Rin من داخلهما.

مدير الحزم RinPM

تثبيت وحل تبعيات وقفل إصدارات لمكتبات Rin، بنفس منطق مديري الحزم المعتادة.

عُدّة صناعة اللغات langkit

لبنات جاهزة لبناء لغة برمجة مصغّرة خاصة بك فوق Rin: محلِّل لفظي، مُحلِّل تركيبي، وAST.

حاوية Rin المدمجة .rcl

صيغة حاوية/ضغط ثنائية خاصة بمشاريع ومكتبات Rin، مستقلة عن ZIP.

آخر ما وصل إلى المحرّك

محرّك Rin يتطوّر بشكل نشط. هذه أحدث الإضافات على المفسّر نفسه (rin_interpreter.cpp / rin_parser.cpp)، مبنية ومُختبَرة فعلياً قبل النشر.

إصلاح: كل closure داخل حلقة for كانت تشارك نفس المتغيّر

الآن لكل تكرارة بيئتها الخاصة، فتلتقط كل دالة مجهولة قيمة تكرارتها هي — لا القيمة الأخيرة للحلقة فقط.

قبل الإصلاح
print fns[0](); // 3
print fns[1](); // 3
print fns[2](); // 3
بعد الإصلاح
print fns[0](); // 0
print fns[1](); // 1
print fns[2](); // 2

ميزات جديدة: تعبيرات لامبدا، ونداء أي قيمة دالة مباشرة

fun(x) { return x; } أصبحت تعمل كتعبير في أي موضع (تُسنَد لمتغيّر، تُمرَّر وسيطاً، أو تُستدعى فوراً)، وأي تعبير ناتجه دالة — عنصر مصفوفة، أو نتيجة استدعاء آخر — أصبح قابلاً للاستدعاء مباشرة بدل رمي خطأ تحليل.

lambdas.rin
let arr = [fun(){return 1;}, fun(){return 2;}];
print arr[0]();                        // 1
print (fun(x){return x*10;})(4);         // 40 — نداء فوري (IIFE)

fun makeAdder(n) { return fun(x) { return x + n; }; }
print makeAdder(3)(4);                    // 7 — نداء متسلسل

ميزة جديدة: for (let x in iterable)

قبلها كان التكرار على مصفوفة أو قاموس يحتاج فهرساً عددياً يدوياً. الآن تعمل مباشرة على مصفوفة، أو قاموس (كل مفتاح)، أو نص (كل حرف).

forin.rin
for (let x in [10, 20, 30]) { print x; }      // 10 20 30

let m = {"a": 1, "b": 2};
for (let k in m) { print k + "=" + m[k]; }   // a=1  b=2

for (let c in "abc") { print c; }              // a b c
