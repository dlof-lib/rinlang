# `positive` و `=[×]=` — مفهوم الإيجابية

المعامل `=[×]=` يجمع ثلاث دلالات حسب موضعه، والدالة `positive(...)` هي صيغته السهلة بالأسماء.
كلها **إضافات بحتة**: `=[` لم تكن صيغة صالحة سابقاً، فلا يتغيّر أي كود قائم.

| الموضع | الصيغة | المعنى |
|---|---|---|
| اختبار (بلا طرف أيمن) | `x =[×]=` | `true` إذا كانت `x > 0` ≡ `positive(x)` |
| مقارنة (داخل تعبير/شرط) | `a =[×]= b` | `true` إذا كان الاثنان موجبين ≡ `positive(a, b)` |
| إسناد مشروط (عبارة وحدها) | `x =[×]= e;` | `x = x × e` **فقط إن كانت النتيجة موجبة**، وإلا تبقى `x` كما هي |

## المفاتيح السهلة (لوحة المفاتيح)
`×` صعبة الكتابة، فهذه كلها تُقرأ المعامل نفسه: `=[×]=` · `=[x]=` · `=[X]=` · `=[*]=`.

## `positive(...)`
- `positive(a, b, ...)` ← `true` إذا كانت **كل** القيم أعداداً أكبر من صفر.
- المصفوفة موجبة إذا كانت غير فارغة وكل عناصرها موجبة (تدخل المصفوفات المتداخلة).
- الصفر والنصوص و`nil` ← غير موجبة (`false`) بلا خطأ.

```rin
let x = 4;
x =[×]= 3;          // 12
x =[×]= -1;         // -12 سالبة ← تبقى 12
print x =[x]=;      // true
if (x =[×]= and y =[×]= 2) { ... }
print positive([1, 2, 3]);   // true
```

## قواعد
- الاختبار يُعرف بأن المعامل لا يتبعه تعبير (يتبعه `;` `)` `}` `]` `,` `and` `or` `?` `:` `else`).
- الإسناد المشروط لا يكون إلا عبارة مستقلة تنتهي بـ `;` وهدفها بسيط (متغيّر · `arr[i]` · `obj.field` بأسماء/أرقام فقط)؛ في أي مكان آخر يُقرأ `a =[×]= b` مقارنة.
- المعامل بأولوية `==`، فيعمل مع `and` و`or` كما تتوقع.
- يُفكَّك في المحلل إلى نداءات (`positive` · `__positive_cmp` · `__positive_keep`)، فيعمل على المفسّر وRinVM دون تغيير فيهما.
- الاختبار: `tests/print/positive.rin|.expected`.
