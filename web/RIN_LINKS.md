# Rin canonical links

Profile: `https://dlof-lib.github.io/rinlang/@username`

Library: `https://dlof-lib.github.io/rinlang/@username/library.og.rin`

- Username is the public publisher username.
- `.og.rin` is added exactly once.
- Spaces become `-`.
- Legacy `?@username/library.og.rin` links remain supported.
- GitHub Pages `404.html` routes deep links to the single `index.html` app.
