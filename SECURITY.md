# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 1.x | Yes |
| 0.x | No |

## Reporting

Report security vulnerabilities privately to the project maintainers before
public disclosure.

Include the affected version, component, reproduction steps, impact, and
possible mitigation.

Security reports may concern the interpreter, native runtime, JNI boundary,
filesystem access, archive extraction, HTTP/networking, memory safety,
parser behavior, packages, or extensions.
