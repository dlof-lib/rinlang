# Rin Programming Language

## Rin 1.0.0

Rin is a modern, lightweight, open-source programming language designed for
applications, automation, data processing, scripting, UI concepts and
Android/native runtime development.

### Release

- Language: Rin
- Version: 1.0.0
- Release type: Stable
- License: MIT
- SPDX: MIT
- Status: Open Source

### Core Concepts

Variables, functions, conditions, loops, arrays, maps, objects, containers,
pipelines, RinFlow, standard libraries, HTTP, storage, validation, UI/Loom
and Android/native runtime integration.
