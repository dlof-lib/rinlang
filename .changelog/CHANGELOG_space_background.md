# خلفية الفضاء والخلفيات المتحركة
- StarfieldModel: 140 نجمة، وميضات لامعة نادرة، نيزكان كحد أقصى، انجراف السدم.
- StarfieldDrawable: هالات ناعمة، 3 سدم، نيازك بذيل متدرّج، vignette؛ واجهة LiveBackground.
- AnimatedCropDrawable: رفع GIF / WebP متحرك / APNG (≤20MB) بقصّ مركزي وتعتيم.
- الإيقاف/التشغيل: زر ✦ أو `background stop|play`، ويتوقف تلقائياً عند إخفاء النافذة وعند ANIMATOR_DURATION_SCALE=0.
