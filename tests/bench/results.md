# نتائج القياس

بناء `-O2` بـ g++ على نواة واحدة، ثلاث تشغيلات لكل اختبار. التشغيل: `bash run.sh /path/to/rin fib str_cat map_big`
(يُشغَّل من داخل هذا المجلد).

| الاختبار | قبل | بعد |
|---|---|---|
| map_big (20 ألف إدراج + قراءة) | 1.17 / 1.46 / 1.64 ث | 0.06 / 0.07 / 0.06 ث |
| str_cat (60 ألف إلحاق) | 0.28 / 0.25 / 0.28 ث | 0.04 / 0.05 / 0.04 ث |
| fib(24) | 0.11 / 0.10 / 0.10 ث | 0.11 / 0.15 / 0.11 ث |
