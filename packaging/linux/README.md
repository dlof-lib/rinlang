# Rin Shell — Linux desktop entry

```sh
install -Dm644 rin-shell.desktop ~/.local/share/applications/rin-shell.desktop
install -Dm644 rin-shell.svg     ~/.local/share/icons/hicolor/scalable/apps/rin-shell.svg
```

`rin-shell.svg` is the same drawing as `assets/branding/shell/rin-shell.svg` (PNG sizes 48/192/512 are there too).
